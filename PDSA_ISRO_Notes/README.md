# Programming, Data Structures and Algorithms: Deep, Beginner-Friendly Notes

Read in order. Chapters 01 to 08 build C/C++ fluency (output-prediction questions), 09 to 14 cover data structures, and 15 to 21 cover algorithms. Every chapter has traced examples and practice questions with explanations.
