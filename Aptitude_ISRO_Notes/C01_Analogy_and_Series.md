# C01. Analogy and Number/Letter Series

> Both topics test one skill: **spotting the rule**. In analogies, **name the relationship in words** ("worker : workplace") before looking at options. In series, **run a fixed checklist** rather than staring at the numbers waiting for inspiration.

---

## 1. Analogies

A : B :: C : ? means "C relates to ? exactly as A relates to B".

| Relationship | Example |
|---|---|
| Synonym | Big : Large |
| Antonym | Hot : Cold |
| Part : whole | Wheel : Car |
| Worker : tool | Carpenter : Saw |
| Worker : product | Baker : Bread |
| Worker : workplace | Doctor : Hospital |
| Object : function | Knife : Cut |
| Cause : effect | Fire : Burn |
| Degree | Warm : Hot |
| Class : member | Fruit : Mango |
| Male : female | Lion : Lioness |
| Animal : home | Bee : Hive |

**Method:** make a sentence: "A doctor **works in** a hospital." Then "A teacher works in a **school**." If two options fit, make the sentence more specific.

**Letter analogies:** convert letters to positions (A = 1 ... Z = 26) and find the shift. BD : FH :: JL : ? Each letter +4 → **NP**.
Useful: **EJOTY** marks positions 5, 10, 15, 20, 25. Opposite letters add to 27 (A-Z, B-Y, C-X...).

**Number analogies:** find the operation. 4 : 16 :: 5 : 25 (square). 3 : 28 :: 5 : 126 (n³ + 1). 7 : 50 :: 9 : 82 (n² + 1).

## 2. Number series: the checklist

Run these in order:

1. **Constant difference** (AP): 3, 7, 11, 15 → +4.
2. **Constant ratio** (GP): 2, 6, 18, 54 → ×3.
3. **Differences of differences** (two-stage): 2, 6, 12, 20, 30 → diffs 4, 6, 8, 10 → next 42.
4. **Alternate positions** (two interleaved series): 1, 20, 4, 17, 9, 14, 16, ? → odd positions 1, 4, 9, 16 (squares); even positions 20, 17, 14 → **11**.
5. **Squares/cubes ± offset:** 3, 6, 11, 18, 27 (n² + 2); 0, 7, 26, 63 (n³ − 1).
6. **Primes:** 2, 3, 5, 7, 11, 13, **17**.
7. **Mixed operations:** 2, 5, 11, 23, 47 (×2 + 1) → 95. 5, 6, 14, 45, 184 (×1 + 1, ×2 + 2, ×3 + 3, ...) → 184 × 5 + 5 = **925**.
8. **Sum of previous terms** (Fibonacci-like): 4, 5, 9, 14, 23, 37 → **60**.
9. **Factorials:** 1, 1, 2, 6, 24, **120**.

> **Trap:** check at least three gaps before declaring a rule. 2, 6, 12, 20 looks "roughly +6" but the gaps grow.

### Quick-recognition list

- Squares: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169, 196, 225.
- Cubes: 1, 8, 27, 64, 125, 216, 343, 512, 729, 1000.
- n² − 1: 3, 8, 15, 24, 35, 48, 63, 80, 99, 120.
- n(n + 1): 2, 6, 12, 20, 30, 42.

### Wrong-number questions

Find the rule from most terms, then the one that breaks it. 1, 2, 6, 24, **96**, 720: factorials, 96 should be 120.

## 3. Letter series

Convert to numbers and use the same checklist.
- Z, W, T, Q → 26, 23, 20, 17 → 14 = **N**.
- B, E, I, N → +3, +4, +5 → +6 → 20 = **T**.
- ACE, GIK, MOQ → each group starts 6 later: **SUW**.
- AZ, BY, CX → **DW** (first letter forward, second backward).
