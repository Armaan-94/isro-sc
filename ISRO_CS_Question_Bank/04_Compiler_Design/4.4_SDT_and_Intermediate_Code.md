# 4.4 Syntax-Directed Translation and Intermediate Code

> 24 questions.

---

**Q1.** A synthesized attribute is computed from:
(a) the parent (b) the children (c) globals (d) unrelated subtrees
**Answer: (b).**

**Q2.** S-attributed vs L-attributed:
(a) same (b) every S-attributed SDD is L-attributed, not vice versa (c) the reverse (d) neither uses synthesized
**Answer: (b).**

**Q3.** An inherited attribute depends on:
(a) its children only (b) its parent and/or left siblings (c) constants (d) right nodes
**Answer: (b).** (In L-attributed definitions.)

**Q4.** Triples vs quadruples:
(a) triples easier to reorder (b) triples harder to reorder: results are referenced by position (c) identical (d) lexical only
**Answer: (b).** Indirect triples fix this with a list of pointers.

**Q5.** Three-address code allows per statement:
(a) three operators (b) at most one operator on the right, at most three addresses (c) no operators (d) exactly three variables
**Answer: (b).**

**Q6.** Backpatching:
(a) fixes source bugs (b) fills in jump targets later, allowing single-pass code for control flow (c) register allocation (d) quadruples to triples
**Answer: (b).**

**Q7.** TAC for a = b + c * d:
(a) t1 = b + c; t2 = t1 * d (b) t1 = c * d; t2 = b + t1; a = t2 (c) no temporaries (d) t1 = b * c
**Answer: (b).**

**Q8.** An AST differs from a parse tree by:
(a) more nodes (b) omitting grammar-only nodes (c) no operators (d) lexical only
**Answer: (b).**

**Q9.** Backpatching's motivation:
(a) lexing memory (b) single-pass code generation (c) none (d) dynamic typing
**Answer: (b).**

**Q10.** Postfix places operators:
(a) before (b) between (c) after operands, no parentheses needed (d) at the end once
**Answer: (c).**

**Q11.** Number of fields in a quadruple:
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (c).** op, arg1, arg2, result.

**Q12.** Number of fields in a triple:
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (b).**

**Q13.** TAC for a = b * −c + b * −c without optimisation uses how many temporaries?
(a) 3 (b) 4 (c) 5 (d) 6
**Answer: (c).** t1 = −c, t2 = b * t1, t3 = −c, t4 = b * t3, t5 = t2 + t4.

**Q14.** Using a DAG for the same expression, the number of distinct interior computations is:
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (b).** −c, b * (−c), and the sum; the common subexpression is shared.

**Q15.** A DAG is used in code generation mainly to:
(a) detect common subexpressions (b) parse (c) tokenise (d) link
**Answer: (a).**

**Q16.** Static single assignment (SSA) form means:
(a) each variable is assigned exactly once in the program text (b) one statement per line (c) no temporaries (d) single register
**Answer: (a).**

**Q17.** With rules E → E₁ + T {print('+')}, E → T, T → num {print(num.val)}, input 2 + 3 + 4 prints:
(a) 2 + 3 + 4 (b) 23+4+ (c) +2+34 (d) 234++
**Answer: (b).** The translation produces postfix.

**Q18.** Standard SDD for arithmetic (E.val = E₁.val + T.val etc.) evaluates 2 + 3 * 4 as:
(a) 20 (b) 14 (c) 24 (d) 9
**Answer: (b).** The grammar enforces precedence.

**Q19.** S-attributed definitions are naturally evaluated during:
(a) LR (bottom-up) parsing (b) lexing (c) linking (d) only after code generation
**Answer: (a).** At each reduction.

**Q20.** Attribute evaluation order is found by:
(a) a topological sort of the dependency graph (b) sorting attributes alphabetically (c) BFS of the parse tree always (d) random
**Answer: (a).** A cycle means the definition can't be evaluated.

**Q21.** Indirect triples:
(a) store a list of pointers to triples, making reordering easy (b) remove temporaries (c) are quadruples (d) are postfix
**Answer: (a).**

**Q22.** Intermediate code is usually generated in:
(a) the front end (b) the linker (c) the loader (d) the lexer
**Answer: (a).**

**Q23.** Postfix of a = b + c * d (as an expression a b c d * + =)?
(a) a b c d * + = (b) a b c + d * = (c) = a + b * c d (d) a b + c d * =
**Answer: (a).**

**Q24.** Annotated parse tree means:
(a) a parse tree showing attribute values at each node (b) a tree with comments (c) an AST without values (d) a DAG
**Answer: (a).**
