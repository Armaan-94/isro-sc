# 4.2 Top-Down Parsing: LL(1) and Recursive Descent

> 26 questions. Reference grammar G: E → TE', E' → +TE' | ε, T → FT', T' → *FT' | ε, F → (E) | id.

---

**Q1.** Recursive descent can't directly handle:
(a) right recursion (b) left recursion (c) rare ambiguity (d) many productions
**Answer: (b).** Infinite recursion without consuming input.

**Q2.** Eliminating A → Aα | β gives:
(a) A → βA', A' → αA' | ε (b) A → αA', A' → βA' | ε (c) A → Aβ | α (d) impossible
**Answer: (a).**

**Q3.** Left factoring is used when:
(a) left recursion exists (b) alternatives share a common prefix (c) no terminals (d) FOLLOW overlaps
**Answer: (b).**

**Q4.** The two Ls in LL(1):
(a) left-to-right scan, leftmost derivation (b) left recursion, left factoring (c) lower, lexical (d) left scan, lookahead
**Answer: (a).**

**Q5.** Guaranteed NOT LL(1):
(a) right-recursive (b) left-recursive or ambiguous (c) CNF (d) no start symbol
**Answer: (b).**

**Q6.** FOLLOW(A) is needed in the LL(1) table when:
(a) A is unused (b) A → ε exists (c) A is the start (d) never
**Answer: (b).**

**Q7.** Two productions in one LL(1) table cell means:
(a) input error (b) the grammar is not LL(1) (c) no start (d) lexer failure
**Answer: (b).**

**Q8.** FIRST(α):
(a) terminals following α (b) terminals that can begin strings derived from α (c) first alphabet letter (d) non-terminals
**Answer: (b).**

**Q9.** Backtracking top-down parsers are avoided because:
(a) can't parse CFGs (b) exponential worst case (c) no lookahead (d) regular only
**Answer: (b).**

**Q10.** Non-ε alternatives with overlapping FIRST sets:
(a) still LL(1) (b) not LL(1) (c) fixed elsewhere (d) left-recursive
**Answer: (b).**

**Q11.** In G, FIRST(E)?
(a) {+, ε} (b) {(, id} (c) {*, ε} (d) {), $}
**Answer: (b).** FIRST(E) = FIRST(T) = FIRST(F).

**Q12.** In G, FIRST(E')?
(a) {+, ε} (b) {+} (c) {(, id} (d) {), $}
**Answer: (a).**

**Q13.** In G, FOLLOW(E)?
(a) {), $} (b) {+, ), $} (c) {*, +, ), $} (d) {$}
**Answer: (a).** E is followed by ) in F → (E), and $ as start.

**Q14.** In G, FOLLOW(T)?
(a) {), $} (b) {+, ), $} (c) {*, +, ), $} (d) {+}
**Answer: (b).** FIRST(E') − {ε} plus FOLLOW(E') because E' can vanish.

**Q15.** In G, FOLLOW(F)?
(a) {+, ), $} (b) {*, +, ), $} (c) {*} (d) {), $}
**Answer: (b).**

**Q16.** In the LL(1) table for G, the entry M[E', )] is:
(a) E' → +TE' (b) E' → ε (c) error (d) T → FT'
**Answer: (b).** ) ∈ FOLLOW(E').

**Q17.** M[T', +] is:
(a) T' → *FT' (b) T' → ε (c) error (d) E' → +TE'
**Answer: (b).** + ∈ FOLLOW(T').

**Q18.** S → aSb | ε. FOLLOW(S)?
(a) {a} (b) {b, $} (c) {$} (d) {a, b}
**Answer: (b).**

**Q19.** S → AB, A → a | ε, B → b. FIRST(S)?
(a) {a} (b) {a, b} (c) {a, ε} (d) {b}
**Answer: (b).** A can vanish, so FIRST(B) is included.

**Q20.** E → E + T | T after removing left recursion:
(a) E → TE', E' → +TE' | ε (b) E → +TE (c) E → T + E (d) unchanged
**Answer: (a).**

**Q21.** S → aS | a is:
(a) LL(1) (b) not LL(1); left-factor to S → aS', S' → S | ε (c) left-recursive (d) ambiguous
**Answer: (b).** Both alternatives start with a.

**Q22.** S → aSa | ε. Is it LL(1)?
(a) yes (b) no: a ∈ FIRST(aSa) and a ∈ FOLLOW(S) (c) only with 2 lookahead (d) it's regular
**Answer: (b).** FIRST/FOLLOW conflict on the ε-production.

**Q23.** A predictive (table-driven) parser uses:
(a) an input buffer, a stack and a parsing table (b) only recursion (c) a DFA only (d) a queue
**Answer: (a).**

**Q24.** Top-down parsing produces a:
(a) leftmost derivation (b) rightmost derivation (c) reverse rightmost derivation (d) random derivation
**Answer: (a).**

**Q25.** An LL(1) grammar is always:
(a) ambiguous (b) unambiguous (c) left-recursive (d) not LR(1)
**Answer: (b).** Every LL(1) grammar is also LR(1).

**Q26.** For an LL(1) grammar, A → α | β where β ⇒* ε. Required condition?
(a) FIRST(α) ∩ FOLLOW(A) = ∅ (b) FIRST(α) = FOLLOW(A) (c) α ⇒* ε too (d) none
**Answer: (a).** Plus FIRST(α) ∩ FIRST(β) = ∅.
