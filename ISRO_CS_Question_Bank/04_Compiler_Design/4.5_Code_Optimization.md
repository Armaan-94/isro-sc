# 4.5 Code Optimization

> 24 questions.

---

**Q1.** Constant folding:
(a) replace a variable by its runtime value (b) evaluate constant expressions at compile time (c) remove unused variables (d) merge blocks
**Answer: (b).** x = 2 + 3 → x = 5.

**Q2.** CSE vs constant propagation:
(a) same (b) CSE reuses a repeated expression's value; constant propagation substitutes a known constant for a variable (c) loops vs blocks (d) floats only
**Answer: (b).**

**Q3.** A basic block has:
(a) many entries and exits (b) one entry (first instruction) and one exit (last) (c) a loop inside (d) no instructions
**Answer: (b).**

**Q4.** Leaders are:
(a) only the first instruction (b) the first instruction, every jump target, and every instruction right after a jump (c) arithmetic instructions (d) jump targets only
**Answer: (b).**

**Q5.** Loop-invariant code motion:
(a) unrolls the loop (b) moves unchanging computations outside the loop (c) reverses the loop (d) uses recursion
**Answer: (b).**

**Q6.** Strength reduction example:
(a) x * 2 → x << 1 (b) remove an unused assignment (c) merge blocks (d) variable → constant
**Answer: (a).**

**Q7.** Peephole optimisation works on:
(a) the AST (b) intermediate code only (c) generated target code, through a small sliding window (d) source text
**Answer: (c).**

**Q8.** Dead code elimination removes:
(a) code with syntax errors (b) code whose results are never used (c) comments (d) zero-trip loops found at runtime
**Answer: (b).**

**Q9.** CFG nodes and edges:
(a) variables, dependencies (b) basic blocks, possible control transfers (c) instructions only (d) functions, calls
**Answer: (b).**

**Q10.** Copy propagation is valuable mainly because it:
(a) speeds things alone (b) exposes dead code for later removal (c) removes the need for folding (d) works only in loops
**Answer: (b).**

**Q11.** Code:
```
1: i = 1
2: j = 1
3: t1 = 10 * i
4: t2 = t1 + j
5: if j <= 10 goto 3
6: i = i + 1
7: if i <= 10 goto 2
8: halt
```
Number of basic blocks?
(a) 3 (b) 4 (c) 5 (d) 6
**Answer: (c).** Leaders 1, 2, 3, 6, 8 → blocks {1}, {2}, {3–5}, {6–7}, {8}.

**Q12.** `x = 4; y = x * 2;` after constant propagation and folding:
(a) y = x * 2 (b) y = 8 (c) y = 4 * 2 (d) unchanged
**Answer: (b).**

**Q13.** `a = b + c; d = b + c;` (b, c unchanged) is improved by:
(a) strength reduction (b) common subexpression elimination (c) loop unrolling (d) peephole only
**Answer: (b).** d = a.

**Q14.** Loop unrolling mainly reduces:
(a) code size (b) loop-control overhead (tests and jumps) (c) correctness (d) register usage
**Answer: (b).** At the cost of larger code.

**Q15.** Combining two loops over the same range into one is:
(a) loop fusion (jamming) (b) loop fission (c) unrolling (d) invariant motion
**Answer: (a).**

**Q16.** Liveness analysis is a:
(a) forward data-flow problem (b) backward data-flow problem (c) lexical problem (d) parsing problem
**Answer: (b).** Reaching definitions and available expressions are forward.

**Q17.** Reaching definitions analysis answers:
(a) which assignments may reach a given point (b) which variables are live (c) register count (d) loop count
**Answer: (a).**

**Q18.** Algebraic simplification removes:
(a) x = x + 0 and x = x * 1 (b) loops (c) function calls (d) declarations
**Answer: (a).**

**Q19.** Basic block: a = b + c; b = a − d; c = b + c; d = a − d. Nodes in the DAG (including leaves b₀, c₀, d₀)?
(a) 5 (b) 6 (c) 7 (d) 8
**Answer: (b).** Leaves b₀, c₀, d₀; interior + (a), − (b and d share it), + (c).

**Q20.** Induction variable elimination applies to:
(a) loop variables that change by a fixed amount each iteration (b) constants (c) globals (d) pointers only
**Answer: (a).** Often combined with strength reduction.

**Q21.** Machine-dependent optimisations include:
(a) register allocation and instruction selection (b) constant folding (c) CSE (d) dead code elimination
**Answer: (a).**

**Q22.** Eliminating jumps to jumps is a:
(a) peephole optimisation (b) lexical step (c) parsing step (d) linking step
**Answer: (a).**

**Q23.** A conditional jump in the middle of a sequence of instructions:
(a) is allowed in one basic block (b) ends the basic block there (c) is removed (d) starts a new function
**Answer: (b).**

**Q24.** Optimisation must always:
(a) preserve the program's meaning (b) reduce code size (c) remove loops (d) change outputs for speed
**Answer: (a).**
