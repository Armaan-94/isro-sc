# 8.1 SDLC Process Models

> 24 questions.

---

**Q1.** Pure waterfall:
(a) unlimited iteration (b) each phase completes before the next, no built-in feedback (c) for changing requirements (d) incremental delivery
**Answer: (b).**

**Q2.** Cost of fixing defects:
(a) same at every phase (b) rises the later they are found (c) cheapest after deployment (d) only design matters
**Answer: (b).**

**Q3.** Spiral model's distinguishing feature:
(a) no testing until the end (b) explicit risk analysis in every cycle (c) no phases (d) frozen requirements
**Answer: (b).**

**Q4.** Defines and prioritises the product backlog:
(a) Scrum Master (b) Product Owner (c) development team (d) project manager
**Answer: (b).**

**Q5.** The Scrum Master is:
(a) a task-assigning manager (b) a facilitator who removes obstacles (c) the main coder (d) the product owner
**Answer: (b).**

**Q6.** A sprint is:
(a) unlimited (b) a fixed 2–4 week time-box producing a shippable increment (c) the final release (d) a daily meeting
**Answer: (b).**

**Q7.** Prototyping suits:
(a) stable requirements (b) unclear or evolving requirements (c) zero budget (d) maintenance only
**Answer: (b).**

**Q8.** Incremental model:
(a) delivers everything at the end (b) delivers working functionality in increments (c) no requirements phase (d) risk analysis every cycle
**Answer: (b).**

**Q9.** An Agile Manifesto value:
(a) documentation over working software (b) following a plan over change (c) working software over comprehensive documentation (d) contracts over collaboration
**Answer: (c).**

**Q10.** Daily standup:
(a) long monthly planning (b) short daily sync: done, next, blockers (c) performance review (d) only at sprint end
**Answer: (b).**

**Q11.** Best model for a large, high-risk project:
(a) waterfall (b) spiral (c) big bang (d) code-and-fix
**Answer: (b).**

**Q12.** Best model when requirements are fully known and stable:
(a) waterfall (b) prototyping (c) spiral (d) agile
**Answer: (a).**

**Q13.** The V-model pairs:
(a) each development phase with a corresponding testing phase (b) two waterfall projects (c) risk and cost (d) sprints and releases
**Answer: (a).** e.g. requirements ↔ acceptance testing, design ↔ integration testing.

**Q14.** RAD (Rapid Application Development) emphasises:
(a) quick development using reusable components and short cycles (b) heavy documentation (c) formal risk analysis (d) no user involvement
**Answer: (a).**

**Q15.** A throwaway prototype is:
(a) discarded after clarifying requirements (b) evolved into the final product (c) never shown to users (d) the final system
**Answer: (a).** An evolutionary prototype is refined into the product.

**Q16.** Pair programming and test-driven development are practices of:
(a) Extreme Programming (XP) (b) waterfall (c) spiral (d) V-model
**Answer: (a).**

**Q17.** In test-driven development, you write:
(a) the test before the code (b) code, then tests much later (c) no tests (d) tests only for UI
**Answer: (a).**

**Q18.** Number of quadrants in each spiral loop:
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (c).** Objectives, risk analysis, development/test, planning.

**Q19.** Big-bang model:
(a) little planning; all effort into coding; for tiny projects (b) heavy planning (c) risk-driven (d) incremental
**Answer: (a).**

**Q20.** Sprint retrospective is for:
(a) reviewing how the team worked and improving the process (b) demoing the product (c) planning the backlog (d) daily sync
**Answer: (a).** The sprint review demos the increment.

**Q21.** Kanban focuses on:
(a) visualising work and limiting work in progress (b) fixed sprints (c) heavy documentation (d) risk quadrants
**Answer: (a).**

**Q22.** Iterative vs incremental:
(a) iterative refines the whole system repeatedly; incremental adds pieces (b) identical (c) incremental refines (d) neither delivers software
**Answer: (a).**

**Q23.** SDLC phase that typically consumes the most cost over a product's lifetime:
(a) requirements (b) design (c) maintenance (d) coding
**Answer: (c).**

**Q24.** Customer involvement is highest in:
(a) agile and prototyping (b) waterfall (c) big bang (d) V-model
**Answer: (a).**
