# 8.2 Requirement Engineering and Software Metrics

> 24 questions. V(G) = E − N + 2P = decisions + 1 = number of regions. FP = UFP × (0.65 + 0.01 ΣFᵢ). Halstead volume V = N log₂ n.

---

**Q1.** "Respond within 2 seconds" is:
(a) functional (b) non-functional (c) a design constraint (d) UI only
**Answer: (b).**

**Q2.** Verification and validation:
(a) verification = right product (b) verification = building the product right; validation = building the right product (c) same (d) unrelated
**Answer: (b).**

**Q3.** Function points beat LOC because they are:
(a) faster (b) language-independent, measuring functionality (c) OOP only (d) complexity
**Answer: (b).**

**Q4.** E = 10, N = 8, P = 1. V(G)?
(a) 2 (b) 4 (c) 18 (d) 10
**Answer: (b).**

**Q5.** Cyclomatic complexity gives:
(a) number of bugs (b) the number of independent paths to test (c) LOC (d) compile time
**Answer: (b).**

**Q6.** Shortcut for V(G):
(a) variables + 1 (b) decision points + 1 (c) LOC/10 (d) function calls
**Answer: (b).**

**Q7.** Confirming requirements with stakeholders:
(a) elicitation (b) specification (c) validation (d) management
**Answer: (c).**

**Q8.** Non-functional requirement:
(a) reset password (b) support 10,000 concurrent users (c) monthly report (d) delete user
**Answer: (b).**

**Q9.** LOC is criticised mainly because it is:
(a) not automatable (b) language-dependent (c) always overestimates (d) unusable
**Answer: (b).**

**Q10.** The SRS is produced by:
(a) elicitation (b) specification (c) validation (d) management
**Answer: (b).**

**Q11.** A function with 3 separate if statements (no loops). V(G)?
(a) 3 (b) 4 (c) 6 (d) 8
**Answer: (b).**

**Q12.** A while loop containing one if statement. V(G)?
(a) 1 (b) 2 (c) 3 (d) 4
**Answer: (c).** Two decisions + 1.

**Q13.** E = 15, N = 12, single component. V(G)?
(a) 3 (b) 5 (c) 27 (d) 1
**Answer: (b).**

**Q14.** E = 20, N = 15, P = 2. V(G)?
(a) 5 (b) 7 (c) 9 (d) 3
**Answer: (c).** 20 − 15 + 4.

**Q15.** A planar flow graph has 5 regions (including the outer one). V(G)?
(a) 4 (b) 5 (c) 6 (d) 10
**Answer: (b).**

**Q16.** UFP = 100, sum of the 14 adjustment factors = 35. Adjusted FP?
(a) 65 (b) 100 (c) 135 (d) 35
**Answer: (b).** 100 × (0.65 + 0.35).

**Q17.** UFP = 100, ΣFᵢ = 70. FP?
(a) 100 (b) 135 (c) 170 (d) 65
**Answer: (b).** 100 × 1.35.

**Q18.** Function point counting uses:
(a) external inputs, outputs, inquiries, internal logical files, external interface files (b) LOC and comments (c) classes and methods (d) test cases
**Answer: (a).**

**Q19.** Halstead: n₁ = 10, n₂ = 6, N₁ = 40, N₂ = 24. Volume?
(a) 64 (b) 256 (c) 128 (d) 1024
**Answer: (b).** N = 64, n = 16, V = 64 × log₂ 16.

**Q20.** A good SRS is:
(a) correct, unambiguous, complete, consistent, verifiable (b) as short as possible (c) written in code (d) private to developers
**Answer: (a).**

**Q21.** Requirement elicitation techniques include:
(a) interviews, questionnaires, observation, workshops (b) compiling (c) unit testing (d) deployment
**Answer: (a).**

**Q22.** Verification typically uses:
(a) reviews, walkthroughs, inspections (b) user acceptance testing only (c) beta testing (d) marketing
**Answer: (a).**

**Q23.** A feasibility study checks:
(a) technical, economic and operational viability before committing (b) code style (c) test coverage (d) deployment scripts
**Answer: (a).**

**Q24.** Traceability matrix links:
(a) requirements to design, code and test cases (b) bugs to developers (c) costs to schedules (d) users to passwords
**Answer: (a).**
