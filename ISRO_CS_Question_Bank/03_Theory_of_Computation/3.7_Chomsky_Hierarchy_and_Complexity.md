# 3.7 Chomsky Hierarchy and Complexity Classes (P, NP, NP-Complete)

> 26 questions. Hierarchy: Regular ⊂ DCFL ⊂ CFL ⊂ CSL ⊂ Recursive ⊂ RE.

---

**Q1.** Most general Chomsky type:
(a) Type 0 (b) Type 1 (c) Type 2 (d) Type 3
**Answer: (a).** Type 3 (regular) is the most restricted.

**Q2.** Type 1 productions must satisfy:
(a) single non-terminal on the left (b) |α| ≤ |β| (non-contracting) (c) one terminal (d) nothing
**Answer: (b).**

**Q3.** Recogniser for context-sensitive languages:
(a) DFA (b) PDA (c) linear bounded automaton (d) unrestricted TM
**Answer: (c).**

**Q4.** NP stands for:
(a) not polynomial (b) nondeterministic polynomial (c) new problem (d) non-provable
**Answer: (b).** Solutions are verifiable in polynomial time.

**Q5.** Proven relationship:
(a) P = NP (b) P ⊆ NP (c) disjoint (d) NP ⊆ P
**Answer: (b).**

**Q6.** An NP-hard problem:
(a) must be in NP (b) need not be in NP (c) is polynomial (d) is smaller than NP-complete
**Answer: (b).**

**Q7.** Cook-Levin theorem:
(a) P = NP (b) P ≠ NP (c) SAT is NP-complete (d) all NP problems are polynomial
**Answer: (c).**

**Q8.** A polynomial algorithm for one NP-complete problem would imply:
(a) nothing (b) P = NP (c) it leaves NP (d) NP-hard becomes undecidable
**Answer: (b).**

**Q9.** Recursive languages sit:
(a) = Type 1 (b) = Type 0 (c) strictly between Type 1 and Type 0 (not a numbered type) (d) outside
**Answer: (c).**

**Q10.** NP-complete problem:
(a) sorting (b) shortest path (c) SAT (d) binary search
**Answer: (c).**

**Q11.** Type 3 grammars are recognised by:
(a) finite automata (b) PDAs (c) LBAs (d) TMs
**Answer: (a).**

**Q12.** Type 2 grammars are recognised by:
(a) finite automata (b) PDAs (c) LBAs (d) TMs
**Answer: (b).**

**Q13.** Correct chain:
(a) Regular ⊂ CFL ⊂ CSL ⊂ RE (b) CFL ⊂ Regular (c) CSL ⊂ CFL (d) RE ⊂ CSL
**Answer: (a).**

**Q14.** If A ≤ₚ B and B ∈ P, then:
(a) A ∈ P (b) A is NP-complete (c) B ∈ NP-hard (d) nothing
**Answer: (a).**

**Q15.** A is NP-complete, A ≤ₚ B and B ∈ NP. Then B is:
(a) in P (b) NP-complete (c) undecidable (d) regular
**Answer: (b).**

**Q16.** 2-SAT and 3-SAT are respectively:
(a) both NP-complete (b) P and NP-complete (c) NP-complete and P (d) both P
**Answer: (b).**

**Q17.** Shortest path vs longest simple path:
(a) both P (b) P and NP-hard (c) both NP-complete (d) NP-hard and P
**Answer: (b).**

**Q18.** Euler circuit vs Hamiltonian cycle:
(a) both P (b) P and NP-complete (c) NP-complete and P (d) both NP-complete
**Answer: (b).**

**Q19.** Graph 2-colouring vs 3-colouring:
(a) both P (b) P and NP-complete (c) both NP-complete (d) NP-complete and P
**Answer: (b).** 2-colouring = bipartiteness.

**Q20.** MST vs travelling salesman (decision):
(a) both P (b) P and NP-complete (c) both NP-complete (d) NP-complete and P
**Answer: (b).**

**Q21.** Fractional vs 0/1 knapsack (decision):
(a) both P (b) P and NP-complete (c) both NP-complete (d) NP-complete and P
**Answer: (b).**

**Q22.** The halting problem is:
(a) in NP (b) NP-hard but not in NP (c) in P (d) NP-complete
**Answer: (b).** It's undecidable.

**Q23.** NP-complete problems:
(a) vertex cover, clique, subset sum, Hamiltonian cycle (b) sorting, searching (c) MST, Dijkstra (d) matrix multiplication
**Answer: (a).**

**Q24.** Co-NP contains problems whose:
(a) "no" answers have polynomially verifiable certificates (b) "yes" answers are verifiable (c) solutions are exponential (d) solutions are undecidable
**Answer: (a).** e.g. tautology checking.

**Q25.** Every NP-complete problem is:
(a) NP-hard (b) in P (c) undecidable (d) not in NP
**Answer: (a).**

**Q26.** Every regular language is also:
(a) DCFL, CFL, CSL, recursive and RE (b) only regular (c) not context-free (d) non-recursive
**Answer: (a).**
