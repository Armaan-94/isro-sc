# 3.1 Finite Automata: DFA and NFA

> 28 questions. "Minimal DFA" means complete (with a dead state if needed) unless stated otherwise.

---

**Q1.** In a DFA, the number of next states for a given state and symbol is:
(a) zero or one (b) exactly one (c) any number (d) the alphabet size
**Answer: (b).**

**Q2.** Compared with DFAs, NFAs:
(a) recognise more languages (b) recognise exactly the regular languages too (c) can't have ε-moves (d) always need fewer states
**Answer: (b).**

**Q3.** Subset construction on an n-state NFA gives at most:
(a) n (b) 2n (c) 2ⁿ (d) n² states
**Answer: (c).**

**Q4.** An ε-transition lets the automaton:
(a) consume one symbol (b) change state without consuming input (c) reject (d) loop forever
**Answer: (b).**

**Q5.** Two DFA states can be merged when they are:
(a) both final (b) equivalent on every possible future input (c) reached in the same number of steps (d) same name
**Answer: (b).**

**Q6.** Before minimising a DFA, remove:
(a) final states (b) self-loop states (c) unreachable states (d) the start state
**Answer: (c).**

**Q7.** A DFA accepts a string if it ends in:
(a) any state (b) a state in F (c) the start state (d) a dead state
**Answer: (b).**

**Q8.** A dead (trap) state:
(a) accepts (b) absorbs undefined transitions to make the DFA complete (c) is the new start (d) reduces states
**Answer: (b).**

**Q9.** The minimal DFA of a regular language is unique:
(a) only for finite languages (b) up to renaming states (c) never (d) only for unary alphabets
**Answer: (b).** Myhill-Nerode.

**Q10.** Main practical benefit of NFAs:
(a) more power (b) easier, more compact construction (c) faster execution (d) no start state
**Answer: (b).**

**Q11.** Minimal DFA states for strings over {a, b} ending in "ab"?
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (b).** Track "nothing useful", "seen a", "seen ab".

**Q12.** Minimal DFA for strings over {a, b} where the number of a's is divisible by 3?
(a) 2 (b) 3 (c) 4 (d) 6
**Answer: (b).** States = count mod 3.

**Q13.** Minimal DFA for binary numbers divisible by 5 (read MSB first)?
(a) 3 (b) 4 (c) 5 (d) 6
**Answer: (c).** One state per remainder. Divisible by 3 needs 3.

**Q14.** Minimal complete DFA for strings over {a, b} of length exactly 2?
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (c).** Lengths 0, 1, 2 and a dead state for length > 2.

**Q15.** Minimal complete DFA for strings over {a, b} starting with a?
(a) 2 (b) 3 (c) 4 (d) 1
**Answer: (b).** Start, accepting sink, dead state.

**Q16.** Minimal DFA for strings over {a, b} containing "aa"?
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (b).** No progress, one a seen, "aa" found (accepting sink).

**Q17.** Strings over {a, b} whose 3rd symbol from the end is a. Minimal NFA and DFA states?
(a) 3 and 6 (b) 4 and 8 (c) 4 and 16 (d) 3 and 8
**Answer: (b).** The k-th-from-end language needs k + 1 NFA states but 2ᵏ DFA states (remember the last k symbols).

**Q18.** Strings with an even number of a's and an even number of b's. Minimal DFA?
(a) 2 (b) 3 (c) 4 (d) 8
**Answer: (c).** Parity pairs (even/odd, even/odd).

**Q19.** Strings over {a, b} with length divisible by 3. Minimal DFA?
(a) 2 (b) 3 (c) 4 (d) 9
**Answer: (b).**

**Q20.** A DFA accepts ε if and only if:
(a) it has a dead state (b) its start state is final (c) it has an ε-move (d) it has a self-loop
**Answer: (b).**

**Q21.** Product construction for DFAs with m and n states gives at most:
(a) m + n (b) mn (c) 2ᵐ⁺ⁿ (d) max(m, n) states
**Answer: (b).** Used for intersection, union and difference.

**Q22.** In a Moore machine, output depends on:
(a) state only (b) state and current input (c) input only (d) nothing
**Answer: (a).** Mealy: state and input.

**Q23.** For an input of length n, a Moore machine produces output of length:
(a) n (b) n + 1 (c) n − 1 (d) 2n
**Answer: (b).** It emits an output for the start state too. A Mealy machine gives n.

**Q24.** A DFA is a 5-tuple. Which is NOT a component?
(a) Q (b) Σ (c) stack alphabet Γ (d) q₀
**Answer: (c).** Γ belongs to a PDA.

**Q25.** Converting an NFA with ε-moves to a DFA first requires computing:
(a) ε-closures (b) the complement (c) the pumping length (d) a CFG
**Answer: (a).**

**Q26.** Minimal DFA for the empty language ∅ over {a, b}?
(a) 0 states (b) 1 state (non-final, self-loops) (c) 2 states (d) undefined
**Answer: (b).** Similarly, Σ* needs 1 final state.

**Q27.** Strings over {0, 1} with at least two 1s. Minimal DFA?
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (b).** Count of 1s: 0, 1, ≥2.

**Q28.** Every finite language is:
(a) regular (b) context-free but not regular (c) undecidable (d) not regular
**Answer: (a).**
