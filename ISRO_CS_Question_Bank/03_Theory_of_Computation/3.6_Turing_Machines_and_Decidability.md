# 3.6 Turing Machines and Decidability

> 26 questions. Recursive = decidable (always halts). RE = semi-decidable (halts on "yes").

---

**Q1.** A TM's tape is more powerful than a PDA's stack because:
(a) it's read once (b) the head moves both ways and can reread/rewrite any visited cell (c) it's bounded (d) read-only
**Answer: (b).**

**Q2.** An RE language has a TM that:
(a) halts on every input (b) accepts every string in L but may loop on strings not in L (c) rejects non-members in finite time (d) never halts
**Answer: (b).**

**Q3.** Recursive vs RE:
(a) same (b) recursive ⊂ RE (strict) (c) RE ⊂ recursive (d) disjoint
**Answer: (b).**

**Q4.** L and its complement are both RE. Then L is:
(a) undecidable (b) recursive (c) impossible (d) only L RE
**Answer: (b).** Run both machines in parallel; one must halt.

**Q5.** The halting problem is:
(a) decidable (b) undecidable (c) not RE (d) undecidable only for NTMs
**Answer: (b).**

**Q6.** "Undecidable" means:
(a) every instance is unknowable (b) no single algorithm answers every instance correctly (c) TMs can't halt (d) undefined
**Answer: (b).**

**Q7.** Rice's theorem:
(a) all TM properties decidable (b) every non-trivial property of the language a TM recognises is undecidable (c) only state counts (d) only DTMs
**Answer: (b).**

**Q8.** Proving B undecidable by reduction: show that
(a) B is solvable (b) a decider for B would decide the halting problem (c) B has many solutions (d) B ⊆ decidable set
**Answer: (b).**

**Q9.** Church-Turing thesis:
(a) every function is computable (b) any effectively computable function is TM-computable (c) only recursive languages are computable (d) NTMs are stronger
**Answer: (b).** A thesis, not a theorem.

**Q10.** Possible outcomes of a TM run: accept, reject or:
(a) error (b) loop forever (c) switch machines (d) probabilistic
**Answer: (b).**

**Q11.** The halting problem is:
(a) recursive (b) RE but not recursive (c) not RE (d) regular
**Answer: (b).** Simulate; if it halts, say yes.

**Q12.** The complement of the halting problem is:
(a) recursive (b) RE (c) not RE (d) context-free
**Answer: (c).**

**Q13.** Recursive languages are closed under complement. RE languages are:
(a) also closed under complement (b) not closed under complement (c) closed only for finite (d) undefined
**Answer: (b).** RE is closed under union and intersection.

**Q14.** Multi-tape and nondeterministic TMs compared to a single-tape DTM:
(a) more powerful (b) equally powerful (maybe faster) (c) weaker (d) incomparable
**Answer: (b).**

**Q15.** Decidable question:
(a) does TM M halt on w? (b) does TM M have more than 5 states? (c) is L(M) empty? (d) does L(M) contain ε?
**Answer: (b).** It's about the machine's description, not its language, so Rice doesn't apply.

**Q16.** "Does M halt on w within 100 steps?" is:
(a) undecidable (b) decidable (c) RE only (d) not RE
**Answer: (b).** Just simulate 100 steps.

**Q17.** The Post Correspondence Problem (over an alphabet of size ≥ 2) is:
(a) decidable (b) undecidable (c) in P (d) regular
**Answer: (b).** For a unary alphabet it's decidable.

**Q18.** For regular languages, which is undecidable?
(a) membership (b) emptiness (c) equivalence (d) none of these
**Answer: (d).** All standard questions are decidable for regular languages.

**Q19.** For CFGs, undecidable:
(a) membership (b) emptiness (c) equivalence of two grammars (d) finiteness
**Answer: (c).** Also ambiguity and universality.

**Q20.** A universal Turing machine:
(a) simulates any TM given its encoding and input (b) halts always (c) recognises only regular languages (d) is a DFA
**Answer: (a).**

**Q21.** Some languages are not RE because:
(a) TMs are countable but languages are uncountable (b) all languages are RE (c) alphabets are infinite (d) TMs are uncountable
**Answer: (a).** Diagonalisation.

**Q22.** Every context-sensitive language is:
(a) recursive (b) non-RE (c) regular (d) undecidable
**Answer: (a).**

**Q23.** Membership for CFLs is:
(a) undecidable (b) decidable (e.g., CYK) (c) RE only (d) not RE
**Answer: (b).**

**Q24.** Whether a CFG is ambiguous is:
(a) decidable (b) undecidable (c) in P (d) regular
**Answer: (b).**

**Q25.** Intersection of two RE languages is:
(a) RE (b) not RE (c) recursive (d) regular
**Answer: (a).** Run both; accept if both accept.

**Q26.** A language is recursive if and only if:
(a) some TM accepts it (b) some TM decides it, halting on all inputs (c) it's context-free (d) its complement is not RE
**Answer: (b).**
