# 3.4 Context-Free Grammars and Pushdown Automata

> 26 questions.

---

**Q1.** The left side of every CFG production is:
(a) any string (b) exactly one non-terminal (c) two non-terminals (d) terminals only
**Answer: (b).**

**Q2.** A grammar is ambiguous if:
(a) a string has several derivation orders (b) some string has two or more distinct parse trees (c) it's recursive (d) no CNF
**Answer: (b).** Equivalently, two leftmost derivations.

**Q3.** CNF productions:
(a) A → BC or A → a (b) A → aα (c) A → αBβ (d) A → ε only
**Answer: (a).** Plus S → ε if needed.

**Q4.** Derivation steps in CNF for a string of length n?
(a) n (b) n − 1 (c) 2n − 1 (d) 2n
**Answer: (c).** n − 1 steps of type A → BC and n steps of type A → a.

**Q5.** A PDA is an NFA plus:
(a) multiple starts (b) an unbounded stack (c) no finals (d) a tape
**Answer: (b).**

**Q6.** PDA acceptance by final state vs empty stack:
(a) final only (b) empty only (c) equivalent in power (d) neither
**Answer: (c).** For nondeterministic PDAs.

**Q7.** DPDA vs PDA:
(a) equal (b) DPDA strictly weaker (c) DPDA stronger (d) neither recognises CFLs
**Answer: (b).** {ww^R} needs nondeterminism.

**Q8.** Ambiguous naive grammar:
(a) A → aA | ε (b) E → E + E | E * E | id (c) S → aSb | ε (d) A → AB | a
**Answer: (b).**

**Q9.** GNF productions:
(a) A → Bα (b) A → aα (terminal then non-terminals) (c) two terminals (d) start with S
**Answer: (b).** A length-n string needs exactly n steps.

**Q10.** For most ambiguous grammars:
(a) the language is inherently ambiguous (b) an equivalent unambiguous grammar exists, though some languages are inherently ambiguous (c) no CNF (d) not context-free
**Answer: (b).**

**Q11.** Derivation steps in CNF for a string of length 5?
(a) 5 (b) 8 (c) 9 (d) 10
**Answer: (c).**

**Q12.** S → aSb | ε generates:
(a) a*b* (b) {aⁿbⁿ : n ≥ 0} (c) (ab)* (d) palindromes
**Answer: (b).**

**Q13.** S → aSa | bSb | a | b | ε generates:
(a) all strings (b) palindromes over {a, b} (c) even-length strings (d) {ww}
**Answer: (b).**

**Q14.** S → SS | (S) | ε generates:
(a) balanced parentheses (b) any parentheses (c) only "()" (d) nothing
**Answer: (a).**

**Q15.** Parse trees for id + id * id with E → E + E | E * E | id?
(a) 1 (b) 2 (c) 3 (d) 4
**Answer: (b).**

**Q16.** A PDA for {aⁿbⁿ}:
(a) pushes on a, pops on b, accepts when the stack is back to its bottom marker (b) uses no stack (c) pushes on b (d) needs two stacks
**Answer: (a).**

**Q17.** {wcw^R : w ∈ {a, b}*} is:
(a) a deterministic CFL (b) not context-free (c) regular (d) inherently ambiguous
**Answer: (a).** The marker c tells the PDA when to switch from pushing to popping. {ww^R} (no marker) is not deterministic.

**Q18.** The CYK membership algorithm:
(a) runs in O(n³) and needs CNF (b) O(n) (c) works on any grammar directly (d) is for regular languages
**Answer: (a).**

**Q19.** A PDA with two stacks is as powerful as:
(a) a DFA (b) a PDA (c) a Turing machine (d) an LBA only
**Answer: (c).**

**Q20.** A right-linear grammar (A → aB | a) generates:
(a) regular languages (b) all CFLs (c) recursive languages (d) only finite languages
**Answer: (a).**

**Q21.** The grammar A → Aα | β is:
(a) left-recursive (b) right-recursive (c) in CNF (d) ambiguous
**Answer: (a).** Rewrite as A → βA', A' → αA' | ε for top-down parsing.

**Q22.** A non-terminal that can never derive a terminal string is:
(a) useless (b) nullable (c) the start symbol (d) left-recursive
**Answer: (a).** Unreachable symbols are also useless.

**Q23.** A non-terminal that can derive ε is called:
(a) useless (b) nullable (c) unit (d) terminal
**Answer: (b).**

**Q24.** A → B (single non-terminal on the right) is a:
(a) unit production (b) ε-production (c) terminal production (d) CNF production
**Answer: (a).** Removed during CNF conversion.

**Q25.** Languages accepted by DPDAs are closed under:
(a) complement (b) union (c) intersection (d) concatenation
**Answer: (a).** DCFLs are closed under complement but not union or intersection. General CFLs are the opposite for union.

**Q26.** Every regular language is:
(a) context-free (b) not context-free (c) inherently ambiguous (d) finite
**Answer: (a).**
