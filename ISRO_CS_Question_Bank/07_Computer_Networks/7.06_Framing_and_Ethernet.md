# 7.6 Data Link Layer: Framing and Ethernet

**Notes:** [06 Data Link Layer Framing and Ethernet](../../CN_Cybersecurity_ISRO_Notes/06_Data_Link_Layer_Framing_and_Ethernet.md)

> 20 questions.

---

**Q1.** Bit stuffing prevents:
(a) compression (b) the flag 01111110 appearing inside data (c) errors (d) eavesdropping
**Answer: (b).**

**Q2.** Minimum Ethernet frame (excluding preamble and SFD):
(a) 46 B (b) 60 B (c) 64 B (d) 1500 B
**Answer: (c).**

**Q3.** First byte's LSB = 1 in a MAC address:
(a) unicast (b) multicast (c) broadcast (d) invalid
**Answer: (b).**

**Q4.** Ethernet reliability is provided by:
(a) physical layer (b) CRC automatically (c) higher layers like TCP (d) preamble
**Answer: (c).**

**Q5.** CRC is placed at the end because:
(a) convention (b) it's computed after the rest of the frame is known (c) part of preamble (d) addresses first
**Answer: (b).**

**Q6.** Manchester provides clocking by:
(a) separate clock (b) a mid-bit transition every bit (c) high voltage only (d) encryption
**Answer: (b).**

**Q7.** Bit-stuffed output of 11111111 (eight 1s)?
(a) 111110111 (b) 11111111 (c) 1111101111 (d) 111111011
**Answer: (a).** A 0 after the first five 1s.

**Q8.** Bit-stuffed output of 0111111 (a 0 then six 1s)?
(a) 01111101 (b) 0111111 (c) 01111110 (d) 011111011
**Answer: (a).** 0, five 1s, stuffed 0, then the sixth 1.

**Q9.** Byte stuffing inserts:
(a) an extra 0 bit (b) an escape (ESC) byte before flag/ESC bytes in data (c) a CRC (d) padding
**Answer: (b).**

**Q10.** Ethernet data field range:
(a) 0–1500 B (b) 46–1500 B (c) 64–1518 B (d) 46–1518 B
**Answer: (b).**

**Q11.** A frame carries 30 bytes of data. Padding added?
(a) 0 (b) 16 bytes (c) 34 bytes (d) 46 bytes
**Answer: (b).**

**Q12.** Maximum Ethernet frame (excluding preamble and SFD):
(a) 1500 B (b) 1518 B (c) 1526 B (d) 64 B
**Answer: (b).** 14 B header + 1500 + 4 B CRC.

**Q13.** MAC address length:
(a) 32 bits (b) 48 bits (c) 64 bits (d) 128 bits
**Answer: (b).**

**Q14.** Ethernet broadcast address:
(a) 00:00:00:00:00:00 (b) FF:FF:FF:FF:FF:FF (c) 01:00:5E:00:00:00 (d) 7F:00:00:01
**Answer: (b).**

**Q15.** A source MAC address is always:
(a) unicast (b) multicast (c) broadcast (d) any
**Answer: (a).**

**Q16.** The preamble's purpose:
(a) error detection (b) bit synchronisation (c) addressing (d) length
**Answer: (b).** 7 bytes of 1010...; SFD ends with 11.

**Q17.** Ethernet is:
(a) connection-oriented and reliable (b) connectionless and unreliable (c) circuit-switched (d) token-based
**Answer: (b).**

**Q18.** PPP authentication protocols:
(a) PAP and CHAP (b) ARP and RARP (c) FTP and TFTP (d) SMTP and POP
**Answer: (a).**

**Q19.** The minimum frame size is tied to:
(a) CSMA/CD collision detection (Tfr ≥ 2Tp) (b) DNS (c) TCP window (d) MTU of IP
**Answer: (a).**

**Q20.** Fixed-size framing (e.g., ATM cells) needs:
(a) flags (b) no delimiters; the size defines the boundary (c) byte stuffing (d) bit stuffing
**Answer: (b).**
