# 7.1 Introduction to Networks: Topologies, Switching, Media, OSI

**Notes:** [01 Introduction to Computer Networks](../../CN_Cybersecurity_ISRO_Notes/01_Introduction_to_Computer_Networks.md)

> 26 questions.

---

**Q1.** Mesh topology with 8 nodes needs how many links?
(a) 8 (b) 16 (c) 28 (d) 56
**Answer: (c).** n(n − 1)/2.

**Q2.** Single point of failure at a central device:
(a) bus (b) ring (c) star (d) mesh
**Answer: (c).**

**Q3.** Packet switching is preferred mainly for:
(a) fixed delay (b) guaranteed order (c) better bandwidth utilisation (d) no per-packet overhead
**Answer: (c).**

**Q4.** X.25's data link protocol:
(a) PLP (b) LAPB (c) X.21 (d) TCP
**Answer: (b).**

**Q5.** Blocked by a building:
(a) radio (b) microwave only (c) microwave and infrared (line of sight) (d) none
**Answer: (c).**

**Q6.** Encryption belongs to which OSI layer?
(a) application (b) presentation (c) session (d) transport
**Answer: (b).**

**Q7.** The true birth of "the Internet" is usually dated to:
(a) 1969 UCLA–SRI message (b) TCP/IP adoption in 1983 (c) NSFNET 1986 (d) WWW 1991
**Answer: (b).**

**Q8.** City-wide network owned by an ISP:
(a) LAN (b) MAN (c) WAN (d) PAN
**Answer: (b).**

**Q9.** "Packet switching guarantees in-order delivery":
(a) true (b) false; packets may take different paths (c) Internet only (d) circuit also reorders
**Answer: (b).**

**Q10.** Logical (IP) addressing and routing:
(a) data link (b) network (c) transport (d) physical
**Answer: (b).**

**Q11.** Mesh with 5 devices: links and ports per device?
(a) 10 links, 4 ports (b) 20, 5 (c) 5, 4 (d) 10, 5
**Answer: (a).**

**Q12.** Links in a star of n devices (excluding the hub's own links count twice):
(a) n (b) n − 1 (c) n(n − 1)/2 (d) 1
**Answer: (a).** One cable from each device to the hub.

**Q13.** Port (service-point) addresses are added at the:
(a) network layer (b) transport layer (c) data link layer (d) session layer
**Answer: (b).**

**Q14.** Device working at layer 1 / 2 / 3 respectively:
(a) hub, switch, router (b) switch, hub, router (c) router, switch, hub (d) hub, router, switch
**Answer: (a).**

**Q15.** PDU names for transport, network, data link, physical:
(a) segment, packet, frame, bits (b) frame, packet, segment, bits (c) packet, segment, frame, bits (d) bits, frame, packet, segment
**Answer: (a).**

**Q16.** Dialog control and synchronisation checkpoints:
(a) session layer (b) presentation layer (c) transport layer (d) application layer
**Answer: (a).**

**Q17.** Number of OSI layers:
(a) 4 (b) 5 (c) 7 (d) 8
**Answer: (c).** The TCP/IP model has 4 (or 5 in some texts).

**Q18.** Walkie-talkie communication is:
(a) simplex (b) half-duplex (c) full-duplex (d) multiplex
**Answer: (b).**

**Q19.** Telephone conversation:
(a) simplex (b) half-duplex (c) full-duplex (d) broadcast
**Answer: (c).**

**Q20.** Jitter is:
(a) total delay (b) variation in packet delay (c) packet loss (d) bandwidth
**Answer: (b).**

**Q21.** Fiber optics transmit using:
(a) electrical current (b) light by total internal reflection (c) radio waves (d) microwaves
**Answer: (b).** Immune to electromagnetic interference.

**Q22.** A break in the main cable halts the whole network in:
(a) star (b) bus (c) mesh (d) tree branch
**Answer: (b).**

**Q23.** Circuit switching phases:
(a) setup, data transfer, teardown (b) route, send (c) send only (d) store and forward
**Answer: (a).**

**Q24.** Message switching uses:
(a) store-and-forward of whole messages (b) dedicated circuits (c) packets (d) virtual circuits only
**Answer: (a).**

**Q25.** As data moves down the stack at the sender, each layer:
(a) adds its header (encapsulation) (b) removes headers (c) encrypts (d) does nothing
**Answer: (a).**

**Q26.** The five components of data communication:
(a) message, sender, receiver, medium, protocol (b) CPU, RAM, disk, bus, OS (c) router, switch, hub, cable, modem (d) IP, TCP, UDP, HTTP, DNS
**Answer: (a).**
