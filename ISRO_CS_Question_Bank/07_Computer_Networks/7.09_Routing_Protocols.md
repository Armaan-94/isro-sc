# 7.9 Network Layer: Routing Protocols (DVR, LSR, RIP, OSPF, BGP)

> 22 questions. Table T for longest-prefix questions: 192.168.0.0/16 → if1; 192.168.1.0/24 → if2; 192.168.1.128/25 → if3; default → if4.

---

**Q1.** In distance vector routing a router shares information with:
(a) all routers (b) only immediate neighbours (c) the backbone (d) nobody
**Answer: (b).**

**Q2.** Count-to-infinity occurs in ___ and is reduced by ___:
(a) LSR, Dijkstra (b) DVR, split horizon (c) OSPF, flooding (d) flooding, hop count
**Answer: (b).**

**Q3.** RIP hop count 16 means:
(a) 16 hops (b) unreachable (c) default route (d) loop
**Answer: (b).**

**Q4.** Algorithms for LSR and DVR:
(a) Dijkstra for DVR (b) Bellman-Ford for both (c) Dijkstra for LSR, Bellman-Ford for DVR (d) none
**Answer: (c).**

**Q5.** OSPF converges faster than RIP because:
(a) hop count (b) each router has full topology and computes consistent shortest paths (c) lower hop limit (d) no algorithm
**Answer: (b).**

**Q6.** Two matching entries /24 and /28. Which is used?
(a) /24 (b) /28 (c) both (d) default
**Answer: (b).** Longest prefix match.

**Q7.** OSPF's metric:
(a) hop count (b) configurable cost (bandwidth etc.) (c) max 15 (d) UDP 520
**Answer: (b).**

**Q8.** Correct description of link state routing:
(a) tells the whole network about everything (b) floods information about its own links to all routers (c) shares nothing (d) single subnet
**Answer: (b).**

**Q9.** Router A: neighbour B at cost 2 advertises distance 3 to D; neighbour C at cost 5 advertises distance 1 to D. A's distance to D and next hop?
(a) 5 via B (b) 6 via C (c) 1 via C (d) 3 via B
**Answer: (a).** min(2 + 3, 5 + 1).

**Q10.** Table T, destination 192.168.1.200:
(a) if1 (b) if2 (c) if3 (d) if4
**Answer: (c).** Matches all three; /25 is longest.

**Q11.** Table T, destination 192.168.1.50:
(a) if1 (b) if2 (c) if3 (d) if4
**Answer: (b).** Not in .128/25.

**Q12.** Table T, destination 192.168.2.5:
(a) if1 (b) if2 (c) if3 (d) if4
**Answer: (a).**

**Q13.** Table T, destination 10.0.0.1:
(a) if1 (b) if2 (c) if3 (d) if4
**Answer: (d).** Default route.

**Q14.** RIP runs over:
(a) TCP 179 (b) UDP 520 (c) directly over IP (d) ICMP
**Answer: (b).** Updates every 30 s.

**Q15.** OSPF runs:
(a) over UDP (b) directly over IP (protocol 89) (c) over TCP (d) over HTTP
**Answer: (b).**

**Q16.** BGP is:
(a) an inter-domain path-vector protocol over TCP port 179 (b) intra-domain link state (c) distance vector over UDP (d) a DNS protocol
**Answer: (a).**

**Q17.** Intra-domain protocols:
(a) RIP and OSPF (b) BGP (c) DNS (d) ARP
**Answer: (a).**

**Q18.** Poison reverse means advertising a route back to the neighbour it was learned from with:
(a) infinite cost (b) zero cost (c) real cost (d) nothing
**Answer: (a).** A stronger form of split horizon.

**Q19.** Flooding:
(a) sends a packet out every interface except the incoming one (b) uses a routing table (c) never duplicates packets (d) is used by DNS
**Answer: (a).** Robust but wasteful; needs hop limits.

**Q20.** OSPF divides a large AS into:
(a) areas connected through a backbone area (b) VLANs (c) subnets only (d) zones of RIP
**Answer: (a).**

**Q21.** Dynamic routing tables:
(a) update automatically as topology changes (b) are configured manually (c) never change (d) store MAC addresses
**Answer: (a).**

**Q22.** In link state routing, every router has:
(a) the same link-state database but computes its own shortest-path tree (b) a different database (c) no database (d) only neighbour info
**Answer: (a).**
