# 7.5 Data Link Layer: Error Control (Hamming Distance, Hamming Code, CRC, Checksum)

**Notes:** [05 Data Link Layer Error Control](../../CN_Cybersecurity_ISRO_Notes/05_Data_Link_Layer_Error_Control.md)

> 24 questions. Detect s errors: d_min ≥ s + 1. Correct t errors: d_min ≥ 2t + 1. Hamming code: 2ʳ ≥ k + r + 1.

---

**Q1.** Hamming distance between 10110 and 11100?
(a) 1 (b) 2 (c) 3 (d) 4
**Answer: (b).** XOR = 01010.

**Q2.** d_min = 5. Maximum errors corrected?
(a) 5 (b) 4 (c) 2 (d) 3
**Answer: (c).**

**Q3.** d_min = 5. Maximum errors detected?
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (c).**

**Q4.** Hamming code with r = 4. n and k?
(a) 15, 11 (b) 16, 12 (c) 15, 10 (d) 14, 10
**Answer: (a).**

**Q5.** Parity bit positions in Hamming(7, 4):
(a) 1, 2, 3 (b) 1, 2, 4 (c) 4, 5, 6 (d) 1, 4, 7
**Answer: (b).** Powers of two.

**Q6.** Simple parity misses:
(a) 1 flipped bit (b) 3 flipped bits (c) an even number of flipped bits (d) no errors
**Answer: (c).**

**Q7.** CRC receiver accepts when the remainder is:
(a) the generator (b) the dataword (c) all zeros (d) 1011
**Answer: (c).**

**Q8.** Stronger detection used in hardware at the data link layer:
(a) parity (b) checksum (c) CRC (d) Hamming
**Answer: (c).**

**Q9.** Dataword 1001, generator 1011. Transmitted codeword?
(a) 1001110 (b) 1001011 (c) 1001000 (d) 1001101
**Answer: (a).** Remainder of 1001000 ÷ 1011 is 110.

**Q10.** Dataword 1101, generator 1011. Transmitted codeword?
(a) 1101001 (b) 1101010 (c) 1101110 (d) 1101000
**Answer: (a).** Remainder 001.

**Q11.** Generator 10011 (x⁴ + x + 1). Number of CRC bits appended?
(a) 3 (b) 4 (c) 5 (d) 2
**Answer: (b).** Degree of the generator.

**Q12.** A CRC with generator of degree r always detects burst errors of length:
(a) ≤ r (b) > r only (c) exactly 2r (d) none
**Answer: (a).**

**Q13.** d_min = 4 lets a code:
(a) detect 3 errors or correct 1 error (b) correct 2 errors (c) detect 4 errors (d) correct 3
**Answer: (a).**

**Q14.** Redundant bits needed for 7 data bits (Hamming SEC)?
(a) 3 (b) 4 (c) 5 (d) 7
**Answer: (b).** 2⁴ = 16 ≥ 7 + 4 + 1; total 11 bits.

**Q15.** Hamming(7, 4) syndrome (P4 P2 P1) = 101. Error position?
(a) 3 (b) 5 (c) 6 (d) 7
**Answer: (b).** The syndrome is the position in binary.

**Q16.** 1's-complement sum of 10110011 and 01011100, then complemented. Checksum?
(a) 11101111 (b) 00010000 (c) 00001111 (d) 11110000
**Answer: (a).** 179 + 92 = 271 = 1 00001111; wrap the carry: 00010000; complement: 11101111.

**Q17.** At the receiver, adding all words including the checksum (1's complement) gives, if no error:
(a) all 1s (complement = 0) (b) all 0s always (c) the checksum (d) random
**Answer: (a).**

**Q18.** Internet checksum uses:
(a) 1's-complement arithmetic (b) 2's complement (c) XOR only (d) polynomial division
**Answer: (a).**

**Q19.** d_min of simple parity code:
(a) 1 (b) 2 (c) 3 (d) 4
**Answer: (b).**

**Q20.** Forward error correction is preferred when:
(a) retransmission is costly or impossible (live streams, deep-space links) (b) channels are perfect (c) ARQ is cheap (d) never
**Answer: (a).**

**Q21.** A burst error of length 5 means:
(a) exactly 5 bits flipped (b) the first and last corrupted bits are 5 positions apart inclusive (c) 5 frames lost (d) 5 parity bits
**Answer: (b).**

**Q22.** Two-dimensional parity can always detect:
(a) any single error, and correct it (b) all 4-bit errors (c) nothing (d) only odd errors
**Answer: (a).** Row and column parity locate a single bad bit; some 4-bit rectangular patterns slip through.

**Q23.** With k data bits and n code bits, number of valid codewords:
(a) 2ⁿ (b) 2ᵏ (c) 2ⁿ − 2ᵏ (d) n − k
**Answer: (b).**

**Q24.** Cyclic code property:
(a) any cyclic shift of a codeword is also a codeword (b) all codewords are palindromes (c) codewords sum to zero (d) parity at the end
**Answer: (a).**
