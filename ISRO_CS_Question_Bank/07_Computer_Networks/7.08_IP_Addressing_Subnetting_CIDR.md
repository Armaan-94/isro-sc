# 7.8 Network Layer: IP Addressing, Subnetting, CIDR, Supernetting

**Notes:** [08 Network Layer IP Addressing Subnetting CIDR](../../CN_Cybersecurity_ISRO_Notes/08_Network_Layer_IP_Addressing_Subnetting_CIDR.md)

> 30 questions. Hosts per subnet = 2ʰ − 2. Network address = IP AND mask. Broadcast = IP OR (NOT mask). A CIDR block's size is a power of 2 and its first address is divisible by that size.

---

**Q1.** Usable hosts in a Class B network?
(a) 65,536 (b) 65,534 (c) 16,384 (d) 254
**Answer: (b).**

**Q2.** 192.168.10.0/24 into 8 equal subnets. Mask and usable hosts?
(a) /26, 62 (b) /27, 30 (c) /28, 14 (d) /27, 32
**Answer: (b).**

**Q3.** VLSM on 14.24.74.0/24 for 120, 60, 10 hosts (largest first). Broadcast of the 60-host subnet?
(a) .127 (b) .191 (c) .207 (d) .255
**Answer: (b).** 120 → /25 (.0–.127); 60 → /26 (.128–.191).

**Q4.** VLSM allocates the largest first so that:
(a) order doesn't matter (b) each block starts on an address divisible by its size (c) router memory (d) small blocks get low addresses
**Answer: (b).**

**Q5.** 167.199.170.82/27: size, first, last?
(a) 16, .64–.79 (b) 32, .64–.95 (c) 64, .0–.63 (d) 32, .82–.113
**Answer: (b).**

**Q6.** Is 100.1.2.20–100.1.2.35 a valid CIDR block?
(a) yes, /28 (b) yes, /27 (c) no: 20 isn't divisible by 16 (d) not contiguous
**Answer: (c).**

**Q7.** Aggregate 128.56.24.0/24 to 128.56.27.0/24:
(a) /23 (b) 128.56.24.0/22 (c) /16 (d) /25
**Answer: (b).**

**Q8.** A private range:
(a) 11.0.0.0/8 (b) 172.16.0.0–172.31.255.255 (c) 192.169.0.0/16 (d) 127.0.0.0/8
**Answer: (b).** Also 10.0.0.0/8 and 192.168.0.0/16.

**Q9.** FLSM's main disadvantage:
(a) no CIDR (b) wastes addresses when subnet needs differ (c) not for Class C (d) more routes
**Answer: (b).**

**Q10.** 127.0.0.1 is:
(a) public (b) loopback (c) gateway (d) broadcast
**Answer: (b).**

**Q11.** Class of 172.16.5.1?
(a) A (b) B (c) C (d) D
**Answer: (b).** First octet 128–191.

**Q12.** Class of 224.0.0.5?
(a) B (b) C (c) D (multicast) (d) E
**Answer: (c).**

**Q13.** Usable hosts in a /26?
(a) 64 (b) 62 (c) 30 (d) 126
**Answer: (b).**

**Q14.** Usable hosts in a /30?
(a) 4 (b) 2 (c) 0 (d) 1
**Answer: (b).** Used for point-to-point links.

**Q15.** Smallest subnet mask for 500 hosts?
(a) /24 (b) /23 (c) /22 (d) /25
**Answer: (b).** 2⁹ − 2 = 510.

**Q16.** 192.168.1.130/26: network and broadcast?
(a) .128 and .191 (b) .64 and .127 (c) .130 and .193 (d) .0 and .255
**Answer: (a).**

**Q17.** 10.1.1.100/27: network and broadcast?
(a) .96 and .127 (b) .64 and .95 (c) .100 and .131 (d) .96 and .128
**Answer: (a).** Blocks of 32: 96–127.

**Q18.** With /26, are 192.168.1.65 and 192.168.1.130 on the same subnet?
(a) yes (b) no: .64 and .128 subnets (c) can't say (d) only with routing
**Answer: (b).**

**Q19.** A /24 split into /27 subnets. How many?
(a) 4 (b) 8 (c) 16 (d) 32
**Answer: (b).**

**Q20.** Class C with mask 255.255.255.240. Subnets and hosts per subnet?
(a) 16 and 14 (b) 8 and 30 (c) 16 and 16 (d) 4 and 62
**Answer: (a).**

**Q21.** Addresses in a /20 block?
(a) 1024 (b) 2048 (c) 4096 (d) 8192
**Answer: (c).** 2¹².

**Q22.** Limited broadcast address:
(a) 0.0.0.0 (b) 255.255.255.255 (c) 127.0.0.1 (d) network address with host bits all 1
**Answer: (b).** (d) is a directed broadcast.

**Q23.** Directed broadcast of network 200.1.2.0/24:
(a) 200.1.2.0 (b) 200.1.2.255 (c) 255.255.255.255 (d) 200.1.255.255
**Answer: (b).**

**Q24.** Default mask for Class A:
(a) 255.0.0.0 (b) 255.255.0.0 (c) 255.255.255.0 (d) 255.255.255.255
**Answer: (a).**

**Q25.** Usable Class A network numbers:
(a) 128 (b) 126 (c) 127 (d) 256
**Answer: (b).** 0 and 127 are reserved.

**Q26.** /26 subnet mask in dotted decimal:
(a) 255.255.255.192 (b) 255.255.255.224 (c) 255.255.255.128 (d) 255.255.255.240
**Answer: (a).**

**Q27.** Is 150.10.20.64–150.10.20.127 a valid block?
(a) yes, /26 (b) yes, /25 (c) no (d) yes, /27
**Answer: (a).** 64 addresses starting at a multiple of 64.

**Q28.** Can 100.1.2.0/25, 100.1.2.128/26 and 100.1.3.192/26 be aggregated into one supernet?
(a) yes (b) no: not contiguous (c) yes, /23 (d) yes, /24
**Answer: (b).**

**Q29.** Which devices have IP addresses?
(a) hosts and routers (b) hubs (c) repeaters (d) switches (layer 2)
**Answer: (a).**

**Q30.** IPv6 address length:
(a) 32 bits (b) 64 bits (c) 128 bits (d) 48 bits
**Answer: (c).**
