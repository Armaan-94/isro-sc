# 7.15 Hash, MAC, Digital Signatures, Authentication and Security Tools

> 24 questions.

---

**Q1.** Insecure due to collisions:
(a) SHA-256 (b) SHA-3 (c) MD5 (d) SHA-512
**Answer: (c).**

**Q2.** MAC vs hash:
(a) variable output (b) MAC needs a shared secret key (c) hash reversible (d) same
**Answer: (b).**

**Q3.** A digital signature encrypts the digest with the sender's:
(a) public key (b) private key (c) shared key (d) session key
**Answer: (b).**

**Q4.** Does a digital signature give confidentiality?
(a) yes (b) no, only the digest is signed (c) text only (d) gives nothing
**Answer: (b).**

**Q5.** Issues and signs certificates:
(a) RA only (b) Certificate Authority (c) KDC (d) IDS
**Answer: (b).**

**Q6.** Kerberos is based on:
(a) PKI certificates (b) a KDC with symmetric cryptography (c) digital signatures (d) firewalls
**Answer: (b).**

**Q7.** Only detects and alerts:
(a) firewall (b) IPS (c) IDS (d) VPN
**Answer: (c).**

**Q8.** Inspects HTTP/FTP payloads:
(a) packet filter (b) circuit-level gateway (c) application-level gateway (proxy) (d) stateful firewall
**Answer: (c).**

**Q9.** SSL/TLS:
(a) firewall types (b) disk encryption (c) protocols for encrypted communication; TLS succeeds SSL (d) OTP factors
**Answer: (c).**

**Q10.** Output sizes of MD5, SHA-1, SHA-256:
(a) 128, 160, 256 bits (b) 160, 128, 256 (c) 128, 256, 512 (d) 64, 128, 256
**Answer: (a).**

**Q11.** Birthday attack: expected work to find a collision in an n-bit hash:
(a) 2ⁿ (b) about 2ⁿ/² (c) n² (d) n
**Answer: (b).** For 128 bits, about 2⁶⁴.

**Q12.** Avalanche effect:
(a) a small input change gives a completely different hash (b) hashes grow with input (c) hashes repeat (d) slow hashing
**Answer: (a).**

**Q13.** To send a message that is both confidential and signed, the sender:
(a) signs with own private key, encrypts with receiver's public key (b) signs with receiver's public key (c) encrypts with own public key (d) signs with own public key
**Answer: (a).**

**Q14.** A receiver verifies a signature using the:
(a) sender's public key (b) sender's private key (c) receiver's private key (d) CA's private key
**Answer: (a).**

**Q15.** A certificate is verified using the:
(a) CA's public key (b) CA's private key (c) user's private key (d) shared key
**Answer: (a).** The CA signs with its private key.

**Q16.** MAC provides:
(a) integrity and authentication, but not non-repudiation (b) all three (c) confidentiality (d) availability
**Answer: (a).** Both parties share the key, so either could have created it.

**Q17.** HMAC combines:
(a) a hash function with a secret key (b) two hashes (c) RSA and AES (d) a hash with a certificate
**Answer: (a).**

**Q18.** 2FA requires:
(a) exactly two different factors (e.g., password + OTP) (b) two passwords (c) two devices (d) biometrics only
**Answer: (a).** MFA = two or more.

**Q19.** A VPN mainly provides:
(a) an encrypted tunnel over a public network (b) virus scanning (c) packet filtering (d) faster internet
**Answer: (a).**

**Q20.** A stateful firewall:
(a) tracks connection state to allow return traffic (b) inspects only single packets (c) checks app content (d) blocks everything
**Answer: (a).**

**Q21.** IPS vs IDS:
(a) IPS detects and blocks; IDS only alerts (b) identical (c) IDS blocks (d) IPS only logs
**Answer: (a).**

**Q22.** Hashing provides:
(a) integrity checking, not confidentiality (b) encryption (c) authentication of sender (d) availability
**Answer: (a).** There's no "decryption" of a hash.

**Q23.** Kerberos enables:
(a) single sign-on with mutual authentication, without sending passwords over the network (b) public-key encryption (c) packet filtering (d) DNS security
**Answer: (a).**

**Q24.** Certificate fields include:
(a) subject, public key, issuer, serial number, validity period, CA signature (b) private key (c) password (d) session key
**Answer: (a).** A certificate never contains the private key.
