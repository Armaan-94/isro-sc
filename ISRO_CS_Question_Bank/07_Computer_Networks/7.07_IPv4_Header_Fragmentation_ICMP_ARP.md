# 7.7 Network Layer: IPv4 Header, Fragmentation, ICMP, ARP

**Notes:** [07 Network Layer IPv4 Protocol](../../CN_Cybersecurity_ISRO_Notes/07_Network_Layer_IPv4_Protocol.md)

> 24 questions. Header length = HLEN × 4. Fragment offset = starting data byte / 8. Fragment data sizes (except the last) must be multiples of 8.

---

**Q1.** HLEN = 0110. Header length?
(a) 6 B (b) 20 B (c) 24 B (d) 30 B
**Answer: (c).**

**Q2.** Total length 1500, HLEN 5. Payload?
(a) 1500 (b) 1480 (c) 1475 (d) 1420
**Answer: (b).**

**Q3.** 3000-byte payload, 1000 bytes of data per fragment. Offset of the 3rd fragment?
(a) 100 (b) 200 (c) 250 (d) 1000
**Answer: (c).** Starts at byte 2000.

**Q4.** DF = 1 and datagram larger than MTU:
(a) fragmented anyway (b) dropped, ICMP error sent (c) queued (d) M set
**Answer: (b).**

**Q5.** Header checksum recomputed at every hop because:
(a) payload changes (b) TTL changes (c) addresses change (d) never
**Answer: (b).**

**Q6.** Diskless machine learns its IP from its MAC using:
(a) ARP (b) RARP (c) ICMP (d) IGMP
**Answer: (b).**

**Q7.** TTL reaches 0:
(a) destination unreachable (b) redirect (c) time exceeded (d) parameter problem
**Answer: (c).**

**Q8.** No ICMP error is generated for:
(a) TTL expiry (b) a datagram carrying an ICMP error (c) bad checksum (d) unreachable port
**Answer: (b).**

**Q9.** IGMP supports:
(a) unicast (b) broadcast (c) multicast (d) anycast
**Answer: (c).**

**Q10.** 4000 bytes of data, MTU 1500 (20-byte header). Fragments and offsets?
(a) 3; 0, 185, 370 (b) 3; 0, 187, 375 (c) 2; 0, 185 (d) 4; 0, 125, 250, 375
**Answer: (a).** Data per fragment 1480 (multiple of 8): 1480, 1480, 1040.

**Q11.** 4000 bytes of data, MTU allowing 1400 bytes of data per fragment. Offsets?
(a) 0, 175, 350 (b) 0, 140, 280 (c) 0, 1400, 2800 (d) 0, 180, 360
**Answer: (a).**

**Q12.** In Q11, the total length field of the last fragment?
(a) 1200 (b) 1220 (c) 1420 (d) 4020
**Answer: (b).** 1200 data + 20 header.

**Q13.** Fragment offset 100 means its data starts at byte:
(a) 100 (b) 800 (c) 12.5 (d) 1000
**Answer: (b).**

**Q14.** Fragments of the same datagram share the same:
(a) identification value (b) offset (c) total length (d) M bit
**Answer: (a).**

**Q15.** Reassembly happens at:
(a) every router (b) the final destination only (c) the first router (d) the source
**Answer: (b).**

**Q16.** The last fragment has:
(a) M = 0 (b) M = 1 (c) DF = 1 (d) offset 0
**Answer: (a).**

**Q17.** Protocol field values for ICMP, TCP, UDP:
(a) 1, 6, 17 (b) 6, 17, 1 (c) 17, 1, 6 (d) 2, 6, 17
**Answer: (a).**

**Q18.** Maximum IPv4 datagram size:
(a) 1500 B (b) 65,535 B (c) 64 KB + 20 (d) 4096 B
**Answer: (b).** 16-bit total length field.

**Q19.** ping uses:
(a) ICMP echo request/reply (b) UDP only (c) TCP SYN (d) ARP
**Answer: (a).**

**Q20.** traceroute works by:
(a) increasing TTL one hop at a time and reading Time Exceeded messages (b) ARP broadcasts (c) DNS lookups (d) TCP handshakes
**Answer: (a).**

**Q21.** ARP request and reply are:
(a) broadcast request, unicast reply (b) both broadcast (c) both unicast (d) multicast
**Answer: (a).**

**Q22.** The IPv4 header checksum covers:
(a) header only (b) header and data (c) data only (d) nothing
**Answer: (a).**

**Q23.** IPv4 service model:
(a) reliable, connection-oriented (b) best-effort, connectionless (c) circuit-switched (d) guaranteed delivery
**Answer: (b).**

**Q24.** Minimum and maximum IPv4 header sizes:
(a) 20 and 60 bytes (b) 20 and 40 (c) 0 and 60 (d) 40 and 60
**Answer: (a).**
