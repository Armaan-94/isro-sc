# 7.12 Application Layer Protocols

> 28 questions. Ports: FTP 20/21, SSH 22, Telnet 23, SMTP 25, DNS 53, DHCP 67/68, TFTP 69, HTTP 80, POP3 110, IMAP 143, SNMP 161, HTTPS 443.

---

**Q1.** FTP uses:
(a) one connection on 21 (b) control on 21 and data on 20 (c) UDP 21 (d) UDP 20
**Answer: (b).**

**Q2.** Only sends (pushes) mail:
(a) POP3 (b) IMAP4 (c) SMTP (d) HTTP
**Answer: (c).**

**Q3.** Multi-device mail with server-side folders:
(a) POP3 delete (b) POP3 keep (c) IMAP4 (d) SMTP
**Answer: (c).**

**Q4.** HTTP is stateless; servers recognise returning clients by:
(a) sequence numbers (b) cookies (c) URL path (d) DNS caching
**Answer: (b).**

**Q5.** HTTPS adds:
(a) speed only (b) confidentiality, integrity, authentication (c) a second connection (d) persistence
**Answer: (b).**

**Q6.** Holds the final name-to-IP mapping:
(a) root (b) TLD (c) authoritative name server (d) local cache only
**Answer: (c).**

**Q7.** Telnet was replaced by:
(a) FTP (b) SSH (c) HTTP (d) SNMP
**Answer: (b).**

**Q8.** DHCP message order:
(a) offer, discover, request, ack (b) discover, offer, request, ack (c) discover, request, offer, ack (d) request, discover, ack, offer
**Answer: (b).**

**Q9.** Self-assigned address when no DHCP server answers:
(a) 0.0.0.0 (b) 127.0.0.1 (c) 169.254.x.x (d) 255.255.255.255
**Answer: (c).**

**Q10.** GSM shares a channel by:
(a) CDMA (b) FDMA (c) TDMA (d) OFDM
**Answer: (c).** Within frequency channels (FDMA + TDMA).

**Q11.** GPRS introduced:
(a) the SIM card (b) packet-switched, always-on data (c) video calling (d) digital voice
**Answer: (b).**

**Q12.** HTML vs XML:
(a) HTML stores data (b) HTML has fixed display tags; XML has custom tags describing data (c) XML not on the web (d) identical
**Answer: (b).**

**Q13.** VoIP call setup and teardown:
(a) RTP (b) SIP (c) TCP (d) HTTP
**Answer: (b).** RTP carries the media.

**Q14.** PPP's advantage over plain Ethernet for dial-up/DSL:
(a) bandwidth (b) built-in authentication (PAP/CHAP) (c) MAC addresses (d) native encryption
**Answer: (b).**

**Q15.** DNS queries normally use:
(a) UDP port 53 (b) TCP port 80 (c) UDP port 67 (d) TCP port 25
**Answer: (a).** Zone transfers use TCP 53.

**Q16.** DHCP server and client ports:
(a) 67 and 68 (b) 68 and 67 (c) 53 and 54 (d) 20 and 21
**Answer: (a).**

**Q17.** SNMP uses:
(a) UDP 161 (b) TCP 161 (c) UDP 69 (d) TCP 23
**Answer: (a).**

**Q18.** TFTP uses:
(a) UDP 69 (b) TCP 21 (c) UDP 53 (d) TCP 69
**Answer: (a).**

**Q19.** Webmail: browser to mail server uses ___; server to server uses ___:
(a) HTTP; SMTP (b) SMTP; HTTP (c) POP3; IMAP (d) FTP; SMTP
**Answer: (a).**

**Q20.** MIME allows email to carry:
(a) non-ASCII text and binary attachments (b) only plain ASCII (c) encryption only (d) routing info
**Answer: (a).**

**Q21.** A web page has a base HTML file and 10 images, using non-persistent HTTP. TCP connections opened?
(a) 1 (b) 10 (c) 11 (d) 20
**Answer: (c).** One per object.

**Q22.** Default connection type since HTTP/1.1:
(a) non-persistent (b) persistent (c) UDP (d) circuit-switched
**Answer: (b).**

**Q23.** A DNS label can be at most:
(a) 63 characters (b) 255 characters (c) 128 characters (d) 32 characters
**Answer: (a).** The tree has at most 128 levels.

**Q24.** .in, .uk, .us are:
(a) generic domains (b) country domains (c) inverse domains (d) private domains
**Answer: (b).**

**Q25.** Reverse DNS (IP to name) uses the:
(a) inverse domain (b) generic domain (c) country domain (d) root only
**Answer: (a).**

**Q26.** A URL's parts:
(a) protocol, host, port, path (b) IP, MAC, port (c) host only (d) path and query only
**Answer: (a).**

**Q27.** Bcc recipients are visible to:
(a) To and Cc recipients (b) nobody else among the recipients (c) everyone (d) only other Bcc recipients
**Answer: (b).**

**Q28.** Search engine vs web browser:
(a) the same thing (b) a browser is the client application; a search engine is a website used through it (c) a search engine is a browser plug-in (d) a browser indexes pages
**Answer: (b).**
