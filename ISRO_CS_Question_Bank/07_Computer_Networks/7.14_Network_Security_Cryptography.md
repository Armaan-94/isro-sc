# 7.14 Network Security Fundamentals and Cryptography

**Notes:** [14 Network Security and Cryptography](../../CN_Cybersecurity_ISRO_Notes/14_Network_Security_and_Cryptography.md)

> 26 questions. RSA: n = pq, φ = (p − 1)(q − 1), ed ≡ 1 (mod φ), C = Mᵉ mod n.

---

**Q1.** Not guaranteed by cryptography alone:
(a) confidentiality (b) integrity (c) availability (d) authentication
**Answer: (c).**

**Q2.** Resending a captured valid login message:
(a) masquerade (b) replay (c) traffic analysis (d) modification
**Answer: (b).**

**Q3.** 10 users with pairwise symmetric keys. Keys needed?
(a) 10 (b) 45 (c) 90 (d) 100
**Answer: (b).**

**Q4.** Integrity + authentication + non-repudiation:
(a) symmetric encryption (b) digital signature (c) checksum (d) VPN
**Answer: (b).**

**Q5.** Traffic analysis is passive because:
(a) unencrypted data (b) no data is modified (c) targets availability (d) modifies headers
**Answer: (b).**

**Q6.** Kerckhoffs's principle: secure even if:
(a) the key is public (b) the algorithm is public, key secret (c) both public (d) no key
**Answer: (b).**

**Q7.** DES effective key length:
(a) 64 (b) 56 (c) 48 (d) 32 bits
**Answer: (b).**

**Q8.** Diffie-Hellman is:
(a) a block cipher (b) bulk encryption (c) a key-exchange method (d) a signature scheme
**Answer: (c).**

**Q9.** Best for real-time streams (no padding):
(a) block cipher in ECB (b) stream cipher (c) AES-CBC (d) RSA
**Answer: (b).**

**Q10.** 10 users with public-key cryptography. Keys in total (public + private)?
(a) 10 (b) 20 (c) 45 (d) 90
**Answer: (b).** One pair per user.

**Q11.** RSA with p = 3, q = 11, e = 3. Private key d?
(a) 3 (b) 7 (c) 11 (d) 13
**Answer: (b).** φ = 20; 3 × 7 = 21 ≡ 1 (mod 20).

**Q12.** Same keys; encrypt M = 4. Ciphertext?
(a) 12 (b) 31 (c) 64 (d) 4
**Answer: (b).** 4³ = 64; 64 mod 33 = 31.

**Q13.** RSA with p = 5, q = 11, e = 3. d?
(a) 7 (b) 27 (c) 13 (d) 37
**Answer: (b).** φ = 40; 3 × 27 = 81 = 2 × 40 + 1.

**Q14.** Diffie-Hellman with p = 23, g = 5, private values a = 6, b = 15. Shared secret?
(a) 2 (b) 8 (c) 19 (d) 15
**Answer: (a).** A = 5⁶ mod 23 = 8; B = 5¹⁵ mod 23 = 19; 19⁶ mod 23 = 2 = 8¹⁵ mod 23.

**Q15.** Caesar cipher with shift 3 applied to HELLO:
(a) KHOOR (b) IFMMP (c) EBIIL (d) JGNNQ
**Answer: (a).**

**Q16.** AES block size and key sizes:
(a) 128-bit block; 128/192/256-bit keys (b) 64-bit block; 56-bit key (c) 256-bit block (d) 128-bit block; 64-bit key
**Answer: (a).** 10, 12 or 14 rounds.

**Q17.** DES block size and number of rounds:
(a) 64 bits, 16 rounds (b) 128 bits, 10 rounds (c) 64 bits, 8 rounds (d) 56 bits, 16 rounds
**Answer: (a).**

**Q18.** RSA's security rests on:
(a) difficulty of factoring large numbers (b) discrete logarithms only (c) hash collisions (d) secrecy of the algorithm
**Answer: (a).** Diffie-Hellman relies on discrete logarithms.

**Q19.** Symmetric encryption's biggest problem:
(a) slow speed (b) secure key distribution and scalability (c) can't encrypt bulk data (d) needs certificates
**Answer: (b).**

**Q20.** Asymmetric cryptography is mainly used for:
(a) bulk data encryption (b) key exchange and digital signatures (c) hashing (d) compression
**Answer: (b).** Bulk data uses symmetric ciphers.

**Q21.** Diffie-Hellman alone is vulnerable to:
(a) man-in-the-middle (b) brute force only (c) replay only (d) nothing
**Answer: (a).** It provides no authentication.

**Q22.** Impersonating a user with stolen credentials:
(a) masquerade (b) replay (c) traffic analysis (d) DoS
**Answer: (a).**

**Q23.** A DDoS attack threatens:
(a) availability (b) confidentiality (c) integrity (d) non-repudiation
**Answer: (a).**

**Q24.** Passive attacks are best handled by:
(a) prevention (encryption) (b) detection only (c) nothing (d) firewalls only
**Answer: (a).** Active attacks are easier to detect than prevent.

**Q25.** Non-repudiation of origin ensures:
(a) the sender can't deny sending (b) the receiver can't deny receiving (c) data is secret (d) data arrives
**Answer: (a).**

**Q26.** Cryptology =
(a) cryptography + cryptanalysis (b) only encryption (c) only code breaking (d) hashing
**Answer: (a).**
