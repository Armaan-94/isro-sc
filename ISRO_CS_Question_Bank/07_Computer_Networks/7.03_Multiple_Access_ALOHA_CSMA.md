# 7.3 Data Link Layer: Multiple Access (ALOHA, CSMA, Controlled Access, Channelization)

**Notes:** [03 Data Link Layer Multiple Access](../../CN_Cybersecurity_ISRO_Notes/03_Data_Link_Layer_Multiple_Access.md)

> 24 questions. Pure ALOHA S = G e⁻²ᴳ (max 18.4% at G = 0.5). Slotted ALOHA S = G e⁻ᴳ (max 36.8% at G = 1). CSMA/CD: Tfr ≥ 2Tp.

---

**Q1.** Pure ALOHA vulnerable time:
(a) Tfr (b) 2Tfr (c) 0.5Tfr (d) 4Tfr
**Answer: (b).**

**Q2.** Slotted vs pure ALOHA maximum throughput:
(a) same (b) half (c) double (d) 4×
**Answer: (c).**

**Q3.** "CSMA guarantees no collisions":
(a) true (b) false: propagation delay still allows collisions (c) wireless only (d) slotted only
**Answer: (b).**

**Q4.** CSMA/CD needs Tfr ≥ 2Tp so that:
(a) bandwidth drops (b) the sender is still transmitting when a collision returns (c) encryption (d) clocks sync
**Answer: (b).**

**Q5.** Designed because collisions can't be detected:
(a) CSMA/CD (b) CSMA/CA (c) pure ALOHA (d) TDMA
**Answer: (b).** Wireless.

**Q6.** Polling: a secondary with nothing to send replies:
(a) SEL (b) ACK (c) NAK (d) token
**Answer: (c).**

**Q7.** All stations transmit simultaneously over the full band, separated by codes:
(a) FDMA (b) TDMA (c) CDMA (d) polling
**Answer: (c).**

**Q8.** CSMA/CA back-off timer when the channel turns busy:
(a) restarts (b) pauses, then resumes (c) transmits anyway (d) discards
**Answer: (b).**

**Q9.** 200-bit frames on a 200 kbps channel. Pure ALOHA vulnerable time?
(a) 1 ms (b) 2 ms (c) 0.5 ms (d) 4 ms
**Answer: (b).** Tfr = 1 ms.

**Q10.** Same channel; the system offers 1000 frames/s (G = 1) under pure ALOHA. Successful frames per second?
(a) 368 (b) about 135 (c) 184 (d) 1000
**Answer: (b).** S = e⁻² ≈ 0.135.

**Q11.** Same load (G = 1) under slotted ALOHA?
(a) about 368 (b) 135 (c) 184 (d) 500
**Answer: (a).** S = e⁻¹ ≈ 0.368.

**Q12.** CSMA/CD, 10 Mbps, 2500 m cable, 2 × 10⁸ m/s. Minimum frame size?
(a) 125 bits (b) 250 bits (c) 500 bits (d) 64 bits
**Answer: (b).** Tp = 12.5 µs; 2Tp = 25 µs × 10 Mbps.

**Q13.** CSMA/CD, 1 Gbps, 1 km, 2 × 10⁸ m/s. Minimum frame size?
(a) 1250 bytes (b) 125 bytes (c) 10,000 bytes (d) 64 bytes
**Answer: (a).** 2Tp = 10 µs → 10,000 bits.

**Q14.** Classic Ethernet minimum frame size:
(a) 46 bytes (b) 64 bytes (c) 1500 bytes (d) 1518 bytes
**Answer: (b).**

**Q15.** Binary exponential back-off after the 3rd collision chooses K from:
(a) 0–3 (b) 0–7 (c) 0–15 (d) 1–8
**Answer: (b).** 0 to 2ᵏ − 1 slots.

**Q16.** Highest collision risk among persistence strategies:
(a) 1-persistent (b) non-persistent (c) p-persistent (d) all equal
**Answer: (a).**

**Q17.** Wastes idle time but has the lowest collision chance:
(a) 1-persistent (b) non-persistent (c) p-persistent (d) ALOHA
**Answer: (b).**

**Q18.** Two CDMA chip sequences are suitable if their inner product is:
(a) 0 (orthogonal) (b) 1 (c) −1 (d) the sequence length
**Answer: (a).**

**Q19.** Each station gets the full bandwidth only in its time slot:
(a) FDMA (b) TDMA (c) CDMA (d) ALOHA
**Answer: (b).**

**Q20.** Token passing:
(a) only the token holder transmits (b) anyone transmits anytime (c) uses frequency bands (d) uses codes
**Answer: (a).**

**Q21.** LLC and MAC are sublayers of:
(a) the network layer (b) the data link layer (c) the physical layer (d) the transport layer
**Answer: (b).**

**Q22.** CSMA vulnerable time:
(a) Tfr (b) 2Tfr (c) propagation time Tp (d) zero
**Answer: (c).**

**Q23.** In wireless networks, CSMA/CA uses explicit ACKs because:
(a) collisions can't be sensed by the sender (b) faster (c) no frames are lost (d) tradition
**Answer: (a).**

**Q24.** CSMA/CD efficiency approximately:
(a) 1/(1 + 6.44a), a = Tp/Tt (b) 1/(1 + 2a) (c) 0.184 (d) a/(1 + a)
**Answer: (a).**
