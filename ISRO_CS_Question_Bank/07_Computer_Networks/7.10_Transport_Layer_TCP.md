# 7.10 Transport Layer: Services and TCP

> 24 questions. TCP numbers bytes. SYN and FIN each consume one sequence number.

---

**Q1.** TCP header length field = 10. Header size?
(a) 10 B (b) 20 B (c) 40 B (d) 60 B
**Answer: (c).**

**Q2.** Random ISN prevents:
(a) memory use (b) confusion with old segments and sequence prediction attacks (c) reserved 0 (d) checksum issues
**Answer: (b).**

**Q3.** Flag for immediate delivery in chat apps:
(a) RST (b) URG (c) PSH (d) FIN
**Answer: (c).**

**Q4.** Bandwidth 2³² bytes/s. Wrap-around time?
(a) 1 s (b) 2 s (c) 4 s (d) never
**Answer: (a).**

**Q5.** Loss detected by 3 duplicate ACKs indicates:
(a) stronger congestion (b) milder congestion; later segments arrive (c) failure (d) no difference
**Answer: (b).**

**Q6.** Pseudo-header protocol value for TCP:
(a) 17 (b) 6 (c) 1 (d) 89
**Answer: (b).**

**Q7.** Maximum window without scaling:
(a) 4095 (b) 65,535 B (c) 1 GB (d) unlimited
**Answer: (b).**

**Q8.** TCP resembles GBN in ___ and SR in ___:
(a) cumulative ACKs; buffering out-of-order segments (b) only stop-and-wait (c) only SR (d) only GBN
**Answer: (a).**

**Q9.** 5000-byte file in 1000-byte segments; first byte 10001. Sequence number of the 4th segment?
(a) 13001 (b) 14001 (c) 13000 (d) 10004
**Answer: (a).** 10001, 11001, 12001, 13001, 14001.

**Q10.** A segment with sequence number 2001 carries 500 bytes. Next segment's sequence number?
(a) 2500 (b) 2501 (c) 2502 (d) 2001
**Answer: (b).**

**Q11.** Receiver got bytes 1000–1999 correctly. ACK number?
(a) 1999 (b) 2000 (c) 1000 (d) 2001
**Answer: (b).** Next byte expected.

**Q12.** Client ISN = 100. After the handshake, its first data byte has sequence number:
(a) 100 (b) 101 (c) 102 (d) 0
**Answer: (b).** SYN consumed 100.

**Q13.** 1 Gbps link (1.25 × 10⁸ bytes/s). Wrap-around time approximately?
(a) 3.4 s (b) 34 s (c) 340 s (d) 0.34 s
**Answer: (b).** 2³²/1.25 × 10⁸ ≈ 34.4 s, shorter than a 180 s lifetime, so risky.

**Q14.** Well-known ports range:
(a) 0–1023 (b) 1024–49151 (c) 49152–65535 (d) 0–65535
**Answer: (a).**

**Q15.** A TCP connection is uniquely identified by:
(a) source IP and destination IP (b) source IP, source port, destination IP, destination port (c) port only (d) MAC addresses
**Answer: (b).**

**Q16.** Three-way handshake order:
(a) SYN, SYN+ACK, ACK (b) SYN, ACK, FIN (c) ACK, SYN, SYN (d) FIN, ACK, SYN
**Answer: (a).**

**Q17.** SYN flooding is a:
(a) DoS attack exhausting half-open connection resources (b) routing loop (c) congestion control method (d) checksum error
**Answer: (a).**

**Q18.** TCP's minimum and maximum header size:
(a) 20 and 60 bytes (b) 8 and 20 (c) 20 and 40 (d) 40 and 60
**Answer: (a).**

**Q19.** TCP is:
(a) connection-oriented, reliable, full-duplex byte stream (b) connectionless (c) message-oriented like UDP (d) half-duplex
**Answer: (a).**

**Q20.** Fast retransmit is triggered by:
(a) 3 duplicate ACKs (b) a timeout (c) a RST (d) a FIN
**Answer: (a).**

**Q21.** Transport layer delivery is:
(a) process-to-process (b) host-to-host (c) node-to-node (d) router-to-router
**Answer: (a).**

**Q22.** RST flag means:
(a) reset/abort the connection (b) resend (c) urgent data (d) end of data
**Answer: (a).**

**Q23.** TCP termination usually needs:
(a) four segments (FIN, ACK in each direction), sometimes three when ACK and FIN combine (b) one segment (c) two segments always (d) no segments
**Answer: (a).**

**Q24.** The TCP checksum covers:
(a) header, data and a pseudo-header from IP (b) header only (c) data only (d) nothing
**Answer: (a).**
