# 2.11 Queues and Linked Lists

**Notes:** [11 Queues and Linked Lists](../../PDSA_ISRO_Notes/11_Queues_and_Linked_Lists.md)

> 26 questions.

---

**Q1.** Full vs empty is hard to tell in a circular queue with only front and rear because:
(a) circular queues can't be full (b) front == rear can mean different states without a counter or sentinel (c) modulo is undefined (d) no ambiguity
**Answer: (b).** Fixes: a count variable, or sacrificing one slot.

**Q2.** A linear (non-circular) array queue is wasteful because:
(a) no enqueue (b) dequeued front slots are never reused (c) O(n) enqueue (d) only 2 elements
**Answer: (b).**

**Q3.** Best structure for a priority queue (O(log n) insert and extract)?
(a) sorted array (b) unsorted list (c) heap (d) stack
**Answer: (c).**

**Q4.** The cost of backward traversal in a doubly linked list:
(a) O(n) random access (b) one extra prev pointer per node (c) can't insert at head (d) becomes non-linear
**Answer: (b).**

**Q5.** Main advantage of a header linked list:
(a) less memory (b) no special cases for empty list or head operations (c) O(1) random access (d) no next pointer
**Answer: (b).**

**Q6.** Iterative reversal with prev, current, next. After the loop, set:
(a) *head = current (b) *head = next (c) *head = prev (d) *head = NULL
**Answer: (c).** current is NULL; prev is the old last node.

**Q7.** List 1→2→3→4→5→6. Output of fun(head)?
```c
void fun(node *s) {
    if (s == NULL) return;
    printf("%d ", s->data);
    if (s->next != NULL) fun(s->next->next);
    printf("%d ", s->data);
}
```
(a) 1 4 6 6 4 1 (b) 1 3 5 1 3 5 (c) 1 2 3 5 (d) 1 3 5 5 3 1
**Answer: (d).**

**Q8.** For `while (head->next != NULL) { print(head->data); head = head->next; }`, which statement is FALSE?
(a) it crashes on an empty list (b) it skips the last node (c) it's wrong because it reassigns the local head (d) none
**Answer: (c).** Changing the local copy of head is harmless.

**Q9.** Needs an explicit stop condition instead of a NULL check:
(a) singly (b) doubly (c) circular (d) none
**Answer: (c).**

**Q10.** Circular queue of 5 array slots that keeps one slot empty to tell full from empty. Maximum elements?
(a) 3 (b) 4 (c) 5 (d) 6
**Answer: (b).**

**Q11.** Circular queue, N = 6, front index 4, rear index 1 (inclusive). Number of elements?
(a) 3 (b) 4 (c) 5 (d) 2
**Answer: (b).** (R − F + N) mod N + 1 = 3 + 1. Elements at 4, 5, 0, 1.

**Q12.** A deque allows:
(a) insert and delete at both ends (b) only front deletion (c) only rear insertion (d) priority order
**Answer: (a).** Input-restricted deques insert at one end only; output-restricted delete at one end only.

**Q13.** Inserting at the end of a singly linked list without a tail pointer:
(a) O(1) (b) O(log n) (c) O(n) (d) O(n²)
**Answer: (c).**

**Q14.** Deleting a node given only a pointer to it (not the last node) can be done in:
(a) O(1), by copying the next node's data in and deleting the next node (b) O(n) only (c) impossible (d) O(log n)
**Answer: (a).**

**Q15.** Floyd's cycle detection (slow and fast pointers) uses:
(a) O(n) time, O(n) space (b) O(n) time, O(1) space (c) O(n²) time (d) O(log n)
**Answer: (b).**

**Q16.** Finding the middle of a linked list in one pass:
(a) count then walk (b) slow pointer moves 1, fast moves 2; when fast ends, slow is at the middle (c) impossible (d) binary search
**Answer: (b).**

**Q17.** Merging two sorted lists of lengths m and n:
(a) O(m + n) (b) O(mn) (c) O(m log n) (d) O(1)
**Answer: (a).**

**Q18.** Pointer assignments to insert a node between two nodes of a doubly linked list?
(a) 2 (b) 3 (c) 4 (d) 6
**Answer: (c).** new→prev, new→next, prev→next, next→prev.

**Q19.** Binary search on a sorted singly linked list:
(a) O(log n) (b) O(n), since reaching the middle takes linear time (c) O(1) (d) impossible
**Answer: (b).**

**Q20.** Reversing a singly linked list takes:
(a) O(1) (b) O(log n) (c) O(n) (d) O(n²)
**Answer: (c).**

**Q21.** A queue is used in:
(a) recursion (b) BFS and CPU round-robin scheduling (c) expression evaluation (d) undo
**Answer: (b).**

**Q22.** A stack implemented with two queues: cost of push if pop is to be O(1)?
(a) O(1) (b) O(n) (c) O(log n) (d) O(n²)
**Answer: (b).** One of the two operations must be O(n).

**Q23.** Linked list vs array:
(a) linked list has O(1) random access (b) linked list has dynamic size and O(1) insertion at a known position, but no random access (c) arrays always use more memory (d) identical
**Answer: (b).**

**Q24.** Insert at head of a singly linked list:
(a) head = new; new→next = head; (b) new→next = head; head = new; (c) head→next = new; (d) new = head;
**Answer: (b).** The order matters; (a) loses the list.

**Q25.** Last node of a circular singly linked list points to:
(a) NULL (b) the first node (c) itself (d) the middle
**Answer: (b).**

**Q26.** Sequence: enqueue 1, 2, 3; dequeue; enqueue 4; dequeue. Front element now?
(a) 1 (b) 2 (c) 3 (d) 4
**Answer: (c).** Dequeues remove 1 then 2; queue is [3, 4].
