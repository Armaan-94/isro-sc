# 2.15 Algorithm Analysis: Asymptotic Notation and Recurrences

> 32 questions. Master theorem: T(n) = aT(n/b) + f(n), p = log_b a. Case 1: f smaller → Θ(nᵖ). Case 2: f = Θ(nᵖ) → Θ(nᵖ log n). Case 3: f larger → Θ(f).

---

**Q1.** `for (i = 1; i <= n; i *= 3)`:
(a) O(n) (b) O(log n) (c) O(√n) (d) O(n log n)
**Answer: (b).**

**Q2.** `for (i = 2; i <= n; i = i * i)`:
(a) O(log n) (b) O(√n) (c) O(log log n) (d) O(n)
**Answer: (c).** i = 2, 4, 16, 256...: the exponent doubles.

**Q3.** `for (i = 1; i < n; i = i + n/2)`:
(a) O(n) (b) O(log n) (c) O(1) (d) O(√n)
**Answer: (c).** About 2 iterations whatever n is.

**Q4.** `rec(n) = rec(n−1) + rec(n−1) + n`. Time and space?
(a) O(n), O(n) (b) O(2ⁿ), O(n) (c) O(2ⁿ), O(2ⁿ) (d) O(n²), O(n)
**Answer: (b).** Space = maximum stack depth, not total calls.

**Q5.** `rec(n) = 2 * rec(n−1) + n`. Calls per invocation and T(n)?
(a) two, O(2ⁿ) (b) one, O(n) (c) one, O(n²) (d) two, O(n²)
**Answer: (b).** The 2 only scales the returned value.

**Q6.** T(n) = 8T(n/2) + n²?
(a) Θ(n²) (b) Θ(n² log n) (c) Θ(n³) (d) Θ(n log n)
**Answer: (c).** p = 3 > 2: case 1.

**Q7.** T(n) = T(n/3) + n?
(a) Θ(n) (b) Θ(n log n) (c) Θ(log n) (d) Θ(1)
**Answer: (a).** p = 0: case 3.

**Q8.** T(n) = T(√n) + 1?
(a) Θ(log n) (b) Θ(log log n) (c) Θ(√n) (d) Θ(1)
**Answer: (b).** n = 2ᵐ gives S(m) = S(m/2) + 1 = Θ(log m).

**Q9.** Tight (upper and lower) bound notation:
(a) O (b) Ω (c) Θ (d) little-o
**Answer: (c).**

**Q10.** Worst-case analysis is preferred because:
(a) faster to compute (b) average-case needs the input distribution; worst case is a guarantee (c) they're always equal (d) average case is invalid
**Answer: (b).**

**Q11.** T(n) = 2T(n/2) + n?
(a) Θ(n) (b) Θ(n log n) (c) Θ(n²) (d) Θ(log n)
**Answer: (b).** Case 2 (merge sort).

**Q12.** T(n) = 2T(n/2) + 1?
(a) Θ(log n) (b) Θ(n) (c) Θ(n log n) (d) Θ(1)
**Answer: (b).** p = 1, f = n⁰: case 1.

**Q13.** T(n) = T(n/2) + 1?
(a) Θ(1) (b) Θ(log n) (c) Θ(n) (d) Θ(n log n)
**Answer: (b).** Binary search.

**Q14.** T(n) = T(n − 1) + n?
(a) Θ(n) (b) Θ(n log n) (c) Θ(n²) (d) Θ(2ⁿ)
**Answer: (c).** n + (n − 1) + ... + 1.

**Q15.** T(n) = 2T(n − 1) + 1?
(a) Θ(n) (b) Θ(n²) (c) Θ(2ⁿ) (d) Θ(n log n)
**Answer: (c).** Tower of Hanoi: 2ⁿ − 1.

**Q16.** T(n) = 4T(n/2) + n?
(a) Θ(n) (b) Θ(n log n) (c) Θ(n²) (d) Θ(n³)
**Answer: (c).**

**Q17.** T(n) = 4T(n/2) + n²?
(a) Θ(n²) (b) Θ(n² log n) (c) Θ(n³) (d) Θ(n log n)
**Answer: (b).** Case 2.

**Q18.** T(n) = 7T(n/2) + n² (Strassen)?
(a) Θ(n²) (b) Θ(n^2.81) (c) Θ(n³) (d) Θ(n² log n)
**Answer: (b).** log₂ 7 ≈ 2.807.

**Q19.** T(n) = 3T(n/4) + n log n?
(a) Θ(n) (b) Θ(n log n) (c) Θ(n^0.79) (d) Θ(n log² n)
**Answer: (b).** log₄ 3 ≈ 0.79 < 1: case 3.

**Q20.** T(n) = 2T(n/2) + n log n?
(a) Θ(n log n) (b) Θ(n log² n) (c) Θ(n²) (d) Θ(n)
**Answer: (b).** Extended case 2: an extra log factor.

**Q21.** T(n) = T(2n/3) + 1?
(a) Θ(1) (b) Θ(log n) (c) Θ(n) (d) Θ(n^(2/3))
**Answer: (b).**

**Q22.** Nested `for i = 1..n, for j = 1..i` runs the body:
(a) n times (b) n(n + 1)/2 times, Θ(n²) (c) n log n (d) 2n
**Answer: (b).**

**Q23.** `for i = 1..n { for (j = 1; j < n; j *= 2) }`:
(a) O(n) (b) O(n log n) (c) O(n²) (d) O(log² n)
**Answer: (b).**

**Q24.** `for (i = n; i > 0; i /= 2) for (j = 0; j < i; j++)`:
(a) O(n) (b) O(n log n) (c) O(log n) (d) O(n²)
**Answer: (a).** n + n/2 + n/4 + ... < 2n.

**Q25.** Fastest growing:
(a) 2ⁿ (b) n! (c) nⁿ (d) n¹⁰
**Answer: (c).** n¹⁰ < 2ⁿ < n! < nⁿ for large n.

**Q26.** log(n!) is:
(a) Θ(n) (b) Θ(n log n) (c) Θ(log n) (d) Θ(n²)
**Answer: (b).** Stirling's approximation.

**Q27.** Which is true?
(a) 2ⁿ⁺¹ = O(2ⁿ) (b) 2²ⁿ = O(2ⁿ) (c) n² = O(n log n) (d) n! = O(2ⁿ)
**Answer: (a).** 2ⁿ⁺¹ = 2 · 2ⁿ, a constant factor. 2²ⁿ = 4ⁿ is not.

**Q28.** 1 + 1/2 + 1/3 + ... + 1/n is:
(a) Θ(1) (b) Θ(log n) (c) Θ(n) (d) Θ(√n)
**Answer: (b).** Harmonic series.

**Q29.** f(n) = n log n, g(n) = n^1.5. Then:
(a) f = O(g) (b) f = Ω(g) (c) f = Θ(g) (d) unrelated
**Answer: (a).** log n grows slower than any positive power of n.

**Q30.** `for (i = 1; i * i <= n; i++)`:
(a) O(n) (b) O(√n) (c) O(log n) (d) O(1)
**Answer: (b).**

**Q31.** Transpose symmetry:
(a) f = O(g) ⟺ g = Ω(f) (b) f = O(g) ⟺ g = O(f) (c) f = Θ(g) ⟺ f = o(g) (d) none
**Answer: (a).**

**Q32.** Order of growth (smallest first):
(a) log n, √n, n, n log n, n², 2ⁿ (b) √n, log n, n, n², n log n, 2ⁿ (c) log n, n, √n, n log n, 2ⁿ, n² (d) n, log n, √n, n², n log n, 2ⁿ
**Answer: (a).**
