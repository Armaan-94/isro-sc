# 2.7 OOP with C++: Classes, Objects, Constructors and Overloading

> 26 questions.

---

**Q1.** The only default difference between struct and class in C++:
(a) struct can't have functions (b) struct members default to public, class to private (c) struct can't have constructors (d) struct can't be inherited
**Answer: (b).** Default inheritance mode differs the same way.

**Q2.** A reference vs a pointer:
(a) a reference can be reseated (b) a reference must be initialised and can't be reseated; a pointer can be reassigned (c) a reference has its own memory like a pointer (d) no difference
**Answer: (b).**

**Q3.** A static member function:
(a) accesses static and non-static members (b) accesses only static members directly; it has no this pointer (c) needs an object to be called (d) is virtual
**Answer: (b).**

**Q4.** The compiler's default copy constructor, for a raw pointer member, does:
(a) a deep copy (b) a shallow copy of the address (c) refuses to compile (d) converts to a reference
**Answer: (b).** Two objects then share (and may double-free) the same memory.

**Q5.** Which operator can't be overloaded?
(a) + (b) == (c) sizeof (d) []
**Answer: (c).** Also ., ::, ?: and .*.

**Q6.** Must be overloaded as a member function, never a friend:
(a) + (b) − (c) [] (d) *
**Answer: (c).** Also =, () and ->.

**Q7.** Function overloading is resolved:
(a) at compile time by argument types/count (b) at runtime (c) only with virtual (d) by the linker randomly
**Answer: (a).** Static polymorphism.

**Q8.** A class defines only MyClass(int x). `MyClass obj;` gives:
(a) compiles using an implicit default constructor (b) compile error: no default constructor (c) x = 0 (d) garbage x
**Answer: (b).**

**Q9.** A friend function is:
(a) a member with private access (b) a non-member granted access to private/protected members (c) inherited (d) mutual
**Answer: (b).** Friendship isn't mutual, inherited or transitive.

**Q10.** Output?
```cpp
class Counter {
    static int count;
public:
    Counter() { count++; }
    static int getCount() { return count; }
};
int Counter::count = 0;
int main() { Counter a, b, c; cout << Counter::getCount(); }
```
(a) 0 (b) 1 (c) 3 (d) error
**Answer: (c).** One shared copy, incremented three times.

**Q11.** The this pointer holds:
(a) the class's address (b) the address of the current object (c) the base class (d) the vtable
**Answer: (b).** Not available inside static member functions.

**Q12.** The scope resolution operator ::x accesses:
(a) the local x (b) the global x hidden by a local x (c) a member of another object (d) a macro
**Answer: (b).** Also used to define members outside the class.

**Q13.** The inline keyword:
(a) forces inlining (b) is a request the compiler may ignore (e.g., recursion, loops) (c) makes the function static (d) is only for virtual functions
**Answer: (b).** Functions defined inside a class body are implicitly inline.

**Q14.** Why must the copy constructor take its parameter by reference?
(a) speed only (b) passing by value would itself call the copy constructor: infinite recursion (c) it's a style rule (d) to allow modification
**Answer: (b).** Typically `ClassName(const ClassName &obj)`.

**Q15.** Can a destructor be overloaded?
(a) yes (b) no, it takes no arguments (c) only if virtual (d) only in templates
**Answer: (b).**

**Q16.** Can a constructor be virtual?
(a) yes (b) no (c) only pure virtual (d) only in abstract classes
**Answer: (b).** A destructor can (and often should) be virtual.

**Q17.** Each constructor prints "C" and the destructor prints "D". Output of `{ X a, b; }`?
(a) CDCD (b) CCDD (c) CDDC (d) CC
**Answer: (b).** Both are constructed, then destroyed in reverse order at the end of the scope.

**Q18.** `X a; X b = a; X c(a);` How many copy-constructor calls?
(a) 0 (b) 1 (c) 2 (d) 3
**Answer: (c).** b and c are initialised from a. (`b = a;` later would use operator=, not the copy constructor.)

**Q19.** The copy constructor is NOT called when:
(a) passing an object by value (b) returning an object by value (c) initialising from another object (d) assigning one existing object to another
**Answer: (d).** That uses the assignment operator.

**Q20.** new vs malloc in C++:
(a) identical (b) new calls the constructor and returns a typed pointer; malloc does neither (c) malloc calls the constructor (d) new can't allocate arrays
**Answer: (b).** delete calls the destructor; free doesn't.

**Q21.** Default access of class members:
(a) public (b) protected (c) private (d) friend
**Answer: (c).**

**Q22.** Encapsulation means:
(a) bundling data with the functions that operate on it and restricting direct access (b) inheritance (c) overloading (d) templates
**Answer: (a).** Abstraction is exposing only the essential interface.

**Q23.** Operator overloading can change an operator's:
(a) precedence (b) number of operands (c) behaviour for user-defined types (d) associativity
**Answer: (c).**

**Q24.** Functions that differ only in return type:
(a) are valid overloads (b) are a compile error (c) are resolved at runtime (d) become virtual
**Answer: (b).** The parameter lists must differ.

**Q25.** How many copies of a non-static data member exist with 5 objects?
(a) 1 (b) 5 (c) 0 (d) depends
**Answer: (b).** One per object. A static member has exactly 1.

**Q26.** C++ was created by:
(a) Dennis Ritchie (b) Bjarne Stroustrup (c) James Gosling (d) Ken Thompson
**Answer: (b).** C by Ritchie; Java by Gosling.
