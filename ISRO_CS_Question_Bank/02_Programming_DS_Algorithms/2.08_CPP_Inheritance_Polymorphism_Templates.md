**Q1.** Output?
```cpp
class Base { public: Base() { cout << "B"; } ~Base() { cout << "b"; } };
class Derived : public Base { public: Derived() { cout << "D"; } ~Derived() { cout << "d"; } };
int main() { Derived obj; }
```
(a) BDbd (b) DBbd (c) BDdb (d) DBdb
**Answer: (c).** Construct base first; destroy in reverse.

**Q2.** Ambiguity problem vs diamond problem:
(a) same thing (b) ambiguity is a name clash between unrelated bases (fix with ::); diamond is duplicate copies of a shared ancestor (fix with virtual inheritance) (c) fixes swapped (d) neither fixable
**Answer: (b).**

**Q3.** Output?
```cpp
class Animal { public: virtual void sound() { cout << "Generic"; } };
class Cat : public Animal { public: void sound() override { cout << "Meow"; } };
Animal *p = new Cat(); p->sound();
```
(a) Generic (b) Meow (c) error (d) UB
**Answer: (b).** Dynamic dispatch through the vtable.

**Q4.** Why make a polymorphic base's destructor virtual?
(a) speed (b) otherwise `delete basePtr` skips the derived destructor and leaks (c) required for all classes (d) prevents slicing
**Answer: (b).**

**Q5.** A class with at least one pure virtual function is:
(a) concrete (b) friend (c) abstract (d) static
**Answer: (c).**

**Q6.** A derived class implements only some inherited pure virtual functions. It is:
(a) concrete (b) still abstract (c) an error (d) given no-op defaults
**Answer: (b).**

**Q7.** Object slicing happens when:
(a) using a base pointer to a derived object (b) a derived object is assigned by value to a base object (c) the base has a virtual destructor (d) multiple inheritance
**Answer: (b).**

**Q8.** Base has only Base(int); Derived() doesn't call it. `Derived d;` gives:
(a) fine (b) compile error: no Base() (c) prints 0 (d) crash
**Answer: (b).** Use `Derived() : Base(5) { }`.

**Q9.** Overriding does NOT require:
(a) inheritance (b) same signature (c) a virtual base function (d) a static function
**Answer: (d).** Static functions can't be virtual.

**Q10.** Virtual inheritance solves:
(a) ambiguity (b) the diamond problem (c) slicing (d) overloading conflicts
**Answer: (b).**

**Q11.** STL component that traverses containers:
(a) algorithm (b) iterator (c) template (d) functor
**Answer: (b).**

**Q12.** Compile-time polymorphism:
(a) needs virtual (b) is overloading, resolved before running (c) is slower (d) applies only to operators
**Answer: (b).**

**Q13.** A base class's private members under public inheritance are:
(a) public in the derived class (b) protected (c) not accessible in the derived class (d) private but accessible
**Answer: (c).** Under any inheritance mode.

**Q14.** A protected base member under public inheritance becomes:
(a) public (b) protected (c) private (d) inaccessible
**Answer: (b).**

**Q15.** A public base member under private inheritance becomes:
(a) public (b) protected (c) private (d) inaccessible
**Answer: (c).**

**Q16.** Multilevel A → B → C; constructors print upper-case and destructors lower-case letters. Output of `C obj;`?
(a) ABCcba (b) CBAabc (c) ABCabc (d) CBAcba
**Answer: (a).**

**Q17.** Pure virtual function syntax:
(a) virtual void f() = 0; (b) virtual void f() {} (c) void f() = virtual; (d) pure void f();
**Answer: (a).**

**Q18.** Can you declare a pointer to an abstract class?
(a) no (b) yes, and point it to a concrete derived object (c) only static (d) only references
**Answer: (b).** You just can't instantiate the abstract class itself.

**Q19.** Can an abstract class have constructors and data members?
(a) no (b) yes (c) only data (d) only constructors
**Answer: (b).** They run when a derived object is created.

**Q20.** The vtable is created per ___, the vptr is stored per ___:
(a) object, class (b) class, object (c) function, class (d) program, object
**Answer: (b).**

**Q21.** Output?
```cpp
class A { public: void f() { cout << "A"; } };
class B : public A { public: void f() { cout << "B"; } };
A *p = new B(); p->f();
```
(a) A (b) B (c) AB (d) error
**Answer: (a).** f isn't virtual, so the call is bound at compile time to the pointer's static type.

**Q22.** Late (dynamic) binding requires:
(a) overloading (b) virtual functions called through a base pointer or reference (c) templates (d) friend functions
**Answer: (b).**

**Q23.** Templates are instantiated:
(a) at runtime (b) at compile time (c) at link time only (d) by the OS
**Answer: (b).**

**Q24.** std::map is typically implemented as:
(a) a hash table (b) a balanced BST (red-black tree), O(log n) operations (c) an array (d) a linked list
**Answer: (b).** std::unordered_map is the hash table.

**Q25.** Multiple inheritance means:
(a) one derived class from two or more base classes (b) a chain of classes (c) many derived classes from one base (d) a mix of types
**Answer: (a).** (b) is multilevel, (c) hierarchical, (d) hybrid.

**Q26.** Can friend functions be virtual?
(a) yes (b) no, they aren't members (c) only in abstract classes (d) only if static
**Answer: (b).**
