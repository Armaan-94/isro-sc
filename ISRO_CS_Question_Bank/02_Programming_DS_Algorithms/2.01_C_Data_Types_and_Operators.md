# 2.1 C Fundamentals: Data Types and Operators

**Notes:** [01 C Fundamentals Data Types Operators](../../PDSA_ISRO_Notes/01_C_Fundamentals_Data_Types_Operators.md)

> 30 questions. Assume a typical 32-bit int, 2's complement, and the common exam convention for signed wraparound.

---

**Q1.** Output?
```c
int a = 2, b;
b = a && !a;
printf("%d", b);
```
(a) 0 (b) 1 (c) 2 (d) compile error
**Answer: (a).** !2 = 0, so 2 && 0 = 0.

**Q2.** Output?
```c
int a = -1, b = 2, c;
c = ++a && ++b;
printf("%d%d%d", a, b, c);
```
(a) 020 (b) 121 (c) 023 (d) 122
**Answer: (a).** ++a makes a = 0 (false), so && short-circuits and ++b never runs.

**Q3.** Output?
```c
int a = 0, b = 2, c;
c = ++a || ++b;
printf("%d%d%d", a, b, c);
```
(a) 121 (b) 021 (c) 122 (d) 020
**Answer: (a).** ++a = 1 (true), so || short-circuits; b stays 2.

**Q4.** Output?
```c
int a = 1, b = 1;
int c = a || --b;
int d = a-- && --b;
printf("a=%d, b=%d, c=%d, d=%d", a, b, c, d);
```
(a) a=0, b=1, c=1, d=0 (b) a=0, b=0, c=1, d=0 (c) a=1, b=1, c=1, d=1 (d) all 0
**Answer: (b).** First line: --b is skipped (c = 1). Second: a-- yields 1 (then a = 0), so --b runs: b = 0, d = 1 && 0 = 0.

**Q5.** Output?
```c
int x = 10, y = 5, z = 2;
int r = x > y ? y > z ? 1 : z > x ? 2 : 4 : 6;
printf("%d", r);
```
(a) 1 (b) 2 (c) 4 (d) 6
**Answer: (a).** ?: is right-associative; x > y and y > z are both true.

**Q6.** int k = 9 / 2; k = ?
(a) 4.5 (b) 4 (c) 5 (d) 4.0
**Answer: (b).** Integer division truncates toward zero.

**Q7.** -5 % 2 in C?
(a) 1 (b) −1 (c) −3 (d) 3
**Answer: (b).** The result takes the sign of the dividend.

**Q8.** a holds 5. After `x = sizeof(a = 10);`, a is:
(a) 10 (b) 5 (c) compile error (d) 0
**Answer: (b).** sizeof doesn't evaluate its operand (except for VLAs).

**Q9.** ~5 (32-bit, 2's complement)?
(a) −5 (b) −6 (c) 6 (d) 10
**Answer: (b).** ~x = −(x + 1).

**Q10.** In `a() && b() || c()`, if a() returns non-zero, which are guaranteed to run?
(a) only a (b) a and b (c) a, b and c (d) b and c
**Answer: (b).** It parses as (a() && b()) || c(); c() runs only if b() returns 0.

**Q11.** signed char x = 127; value of (char)(x + 1)?
(a) 128 (b) −128 (c) −1 (d) 0
**Answer: (b).** Wraps around (exam convention).

**Q12.** How do you compute 3² in C?
(a) 3 ** 2 (b) 3 ^ 2 (c) pow(3, 2) (d) both (a) and (b)
**Answer: (c).** ^ is bitwise XOR; ** doesn't exist.

**Q13.** Output?
```c
double d = 5 / 2;
printf("%.1f", d);
```
(a) 2.5 (b) 2.0 (c) 3.0 (d) error
**Answer: (b).** 5/2 is integer division (2) before conversion to double.

**Q14.** After `int a = 5; int b = a++ * 2;` the values of a and b are:
(a) 6, 12 (b) 6, 10 (c) 5, 10 (d) 5, 12
**Answer: (b).** Post-increment uses the old value.

**Q15.** After `int a = 5; int b = ++a * 2;`, b = ?
(a) 10 (b) 12 (c) 11 (d) 6
**Answer: (b).**

**Q16.** sizeof('A') in C (32-bit int)?
(a) 1 (b) 2 (c) 4 (d) 8
**Answer: (c).** In C, a character constant has type int. (In C++ it's char, size 1.)

**Q17.** `unsigned int x = -1; printf("%u", x);` (32-bit)?
(a) −1 (b) 0 (c) 4294967295 (d) 65535
**Answer: (c).** −1 converts to 2³² − 1.

**Q18.** 7 >> 1 and 1 << 4?
(a) 3 and 16 (b) 3.5 and 8 (c) 14 and 16 (d) 3 and 8
**Answer: (a).**

**Q19.** 5 & 3, 5 | 3, 5 ^ 3?
(a) 1, 7, 6 (b) 1, 7, 2 (c) 3, 5, 6 (d) 0, 8, 6
**Answer: (a).** 101 & 011 = 001; | = 111; ^ = 110.

**Q20.** int x = 3 + 4 * 2; x = ?
(a) 14 (b) 11 (c) 10 (d) 24
**Answer: (b).**

**Q21.** 10 % 3 * 2 = ?
(a) 2 (b) 4 (c) 1 (d) 0
**Answer: (a).** % and * have equal precedence, left to right: (10 % 3) * 2.

**Q22.** `printf("%d", 3 > 2 > 1);` prints:
(a) 1 (b) 0 (c) error (d) 3
**Answer: (b).** (3 > 2) is 1; then 1 > 1 is 0.

**Q23.** int i = 5; i = i << 2; i = ?
(a) 10 (b) 20 (c) 7 (d) 25
**Answer: (b).** Left shift by 2 multiplies by 4.

**Q24.** int x = (1, 2, 3); x = ?
(a) 1 (b) 3 (c) 6 (d) error
**Answer: (b).** The comma operator yields its last operand.

**Q25.** Valid C identifier?
(a) 2nd (b) int (c) _count (d) my-var
**Answer: (c).** Must start with a letter or underscore; no keywords; no hyphens.

**Q26.** char c = 'A' + 2; c = ?
(a) 'B' (b) 'C' (c) 67 only as int (d) error
**Answer: (b).** Characters are stored as ASCII codes (65 + 2 = 67 = 'C').

**Q27.** float f = 1 / 3; printf("%f", f) prints:
(a) 0.333333 (b) 0.000000 (c) 1.000000 (d) error
**Answer: (b).** 1/3 is integer division (0).

**Q28.** int a = 10, b = 3; a / b * b + a % b = ?
(a) 9 (b) 10 (c) 11 (d) 13
**Answer: (b).** Always equals a for integers: 9 + 1.

**Q29.** !0 + !5 = ?
(a) 0 (b) 1 (c) 2 (d) 5
**Answer: (b).** 1 + 0.

**Q30.** Which operators are right-to-left associative?
(a) unary, ?:, assignment (b) * / % (c) + − (d) relational
**Answer: (a).**
