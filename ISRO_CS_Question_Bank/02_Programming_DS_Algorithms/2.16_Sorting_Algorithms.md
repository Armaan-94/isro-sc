# 2.16 Sorting Algorithms

> 30 questions. Keep the table in mind: Merge Θ(n log n) always and stable; Quick O(n²) worst; Heap O(n log n), O(1) space, unstable; Insertion O(n) best.

---

**Q1.** Best case of bubble sort (with the early-exit flag)?
(a) O(n log n) (b) O(n) (c) O(n²) (d) O(log n)
**Answer: (b).** One pass with no swaps.

**Q2.** Insertion sort using binary search to find the position. Worst case?
(a) O(n) (b) O(n log n) (c) O(n²) (d) O(n log² n)
**Answer: (c).** Fewer comparisons, but shifting is still O(n) per insertion.

**Q3.** Lowest worst-case time:
(a) quick (b) bubble (c) merge (d) selection
**Answer: (c).**

**Q4.** (GATE) After the first quicksort partition, an 8-element array is 2 5 1 7 9 12 11 10. The pivot:
(a) could be 7 or 9 (b) 7 only (c) 9 only (d) neither
**Answer: (a).** Both satisfy "everything left ≤ pivot < everything right".

**Q5.** Quicksort worst-case recurrence:
(a) T(n − 2) + n (b) T(n − 1) + n, O(n²) (c) 2T(n/2) + n (d) T(n/10) + T(9n/10) + n
**Answer: (b).**

**Q6.** Typically NOT stable:
(a) insertion (b) merge (c) quick (d) bubble
**Answer: (c).** Heap and selection sort are also unstable.

**Q7.** Best for an almost-sorted array:
(a) quick (b) heap (c) merge (d) insertion
**Answer: (d).**

**Q8.** Fewest swaps (when swaps are expensive):
(a) heap (b) selection (c) insertion (d) merge
**Answer: (b).** At most n − 1 swaps.

**Q9.** All elements identical. Fastest of these?
(a) insertion (b) heap (c) merge (d) selection
**Answer: (a).** O(n): no shifting at all.

**Q10.** Counting sort beats Ω(n log n) because:
(a) it compares secretly (b) it isn't comparison-based (c) the bound is false (d) only sorted input
**Answer: (b).** O(n + k) for keys in range k.

**Q11.** Merge sort vs heap sort trade-off:
(a) none (b) heap sort for low memory; merge sort for stability and external/linked data (c) merge always slower (d) heap never used
**Answer: (b).**

**Q12.** Number of swaps bubble sort performs on 3, 1, 2?
(a) 1 (b) 2 (c) 3 (d) 0
**Answer: (b).** Swaps = inversions: (3, 1), (3, 2).

**Q13.** Inversions in 5, 4, 3, 2, 1?
(a) 5 (b) 10 (c) 15 (d) 20
**Answer: (b).** n(n − 1)/2.

**Q14.** Insertion sort comparisons on a reverse-sorted array of 5?
(a) 5 (b) 10 (c) 15 (d) 4
**Answer: (b).** 1 + 2 + 3 + 4.

**Q15.** Worst-case comparisons to merge sorted lists of sizes m and n?
(a) m + n (b) m + n − 1 (c) mn (d) max(m, n)
**Answer: (b).** Best case min(m, n).

**Q16.** Bubble sort on 5, 1, 4, 2, 8 (ascending). After the first pass?
(a) 1, 4, 2, 5, 8 (b) 1, 2, 4, 5, 8 (c) 1, 5, 4, 2, 8 (d) 5, 1, 4, 2, 8
**Answer: (a).** The 5 bubbles to just before 8.

**Q17.** Selection sort on 64, 25, 12, 22, 11. After the first pass?
(a) 11, 25, 12, 22, 64 (b) 11, 12, 22, 25, 64 (c) 25, 12, 22, 11, 64 (d) 11, 64, 25, 12, 22
**Answer: (a).** Swap the minimum (11) with the first element.

**Q18.** Insertion sort on 12, 11, 13, 5, 6. After inserting the 2nd and 3rd elements?
(a) 11, 12, 13, 5, 6 (b) 5, 11, 12, 13, 6 (c) 11, 12, 5, 13, 6 (d) 5, 6, 11, 12, 13
**Answer: (a).**

**Q19.** Radix sort with d digits, base k:
(a) O(n log n) (b) O(d(n + k)) (c) O(n²) (d) O(nk)
**Answer: (b).** Uses a stable sort (counting sort) per digit.

**Q20.** Sort used for data too big for RAM (external sorting):
(a) quick (b) merge (c) heap (d) selection
**Answer: (b).**

**Q21.** In-place sorts:
(a) merge, counting (b) heap, quick, insertion (c) radix only (d) merge only
**Answer: (b).**

**Q22.** Minimum comparisons (worst case) to sort 3 elements?
(a) 2 (b) 3 (c) 4 (d) 6
**Answer: (b).** ⌈log₂ 3!⌉ = ⌈log₂ 6⌉.

**Q23.** Stable sorts:
(a) merge, insertion, bubble, counting (b) quick, heap (c) selection, heap (d) all
**Answer: (a).**

**Q24.** Quicksort with the median as pivot every time:
(a) O(n²) (b) O(n log n) (c) O(n) (d) O(log n)
**Answer: (b).**

**Q25.** Quicksort's worst case on sorted input with last-element pivot can be avoided by:
(a) using a random or median-of-three pivot (b) more memory (c) making it stable (d) nothing
**Answer: (a).**

**Q26.** Heap sort time in every case:
(a) O(n) (b) O(n log n) (c) O(n²) (d) O(log n)
**Answer: (b).**

**Q27.** Merge sort extra space on arrays:
(a) O(1) (b) O(log n) (c) O(n) (d) O(n²)
**Answer: (c).**

**Q28.** Selection sort on an already sorted array:
(a) O(n) (b) O(n log n) (c) O(n²) (d) O(1)
**Answer: (c).** It still scans the rest every pass.

**Q29.** Number of passes bubble sort needs in the worst case for n elements:
(a) n (b) n − 1 (c) log n (d) n/2
**Answer: (b).**

**Q30.** Average-case stack space of quicksort:
(a) O(1) (b) O(log n) (c) O(n) (d) O(n²)
**Answer: (b).** O(n) in the worst case.
