# 2.5 C Storage Classes, Scoping, Structures, Unions and Enums

**Notes:** [05 C Storage Classes Structures Unions Enums](../../PDSA_ISRO_Notes/05_C_Storage_Classes_Structures_Unions_Enums.md)

> 26 questions. Assume char 1, int 4, double 8 bytes with natural alignment.

---

**Q1.** Output?
```c
void f() { static int i = 1; printf("%d ", i); i++; }
int main() { f(); f(); f(); }
```
(a) 1 1 1 (b) 1 2 3 (c) 0 1 2 (d) 3 3 3
**Answer: (b).** A static local is initialised once and keeps its value.

**Q2.** Same function without static (int i = 1). Output?
(a) 1 1 1 (b) 1 2 3 (c) 0 1 2 (d) garbage
**Answer: (a).** auto variables are re-created on each call.

**Q3.** Default value is garbage and & can't be applied:
(a) auto (b) static (c) extern (d) register
**Answer: (d).**

**Q4.** Output?
```c
int x = 10;
int f() { return x; }
int g() { int x = 20; return f(); }
int main() { printf("%d", g()); }
```
(a) 10 (b) 20 (c) error (d) UB
**Answer: (a).** C uses static (lexical) scoping.

**Q5.** Under dynamic scoping, the same program would print:
(a) 10 (b) 20 (c) 30 (d) 0
**Answer: (b).** f would find the most recent x on the call stack (g's).

**Q6.** Output?
```c
int i = 1;
{ int i = 2;
  { int i = 3; printf("%d ", i); }
  printf("%d ", i); }
printf("%d", i);
```
(a) 1 2 3 (b) 3 2 1 (c) 3 3 3 (d) 1 1 1
**Answer: (b).** Each block has its own i.

**Q7.** Default value of a global int?
(a) garbage (b) 0 (c) 1 (d) −1
**Answer: (b).** Globals and statics are zero-initialised.

**Q8.** A static global variable is visible:
(a) everywhere (b) only in its own file (c) only in main (d) nowhere
**Answer: (b).**

**Q9.** `extern int x;` does:
(a) define and allocate x (b) only declare x (defined elsewhere) (c) make x constant (d) make x static
**Answer: (b).**

**Q10.** sizeof(struct { char c; int i; })?
(a) 5 (b) 8 (c) 4 (d) 1
**Answer: (b).** 3 padding bytes after c.

**Q11.** sizeof(struct { char a; double d; char b; })?
(a) 10 (b) 16 (c) 24 (d) 17
**Answer: (c).** a at 0, pad to 8, d at 8–15, b at 16, pad to 24 (a multiple of 8).

**Q12.** Same members ordered { double d; char a; char b; }. sizeof?
(a) 10 (b) 16 (c) 24 (d) 12
**Answer: (b).** 8 + 1 + 1 = 10, padded to 16. Ordering members largest-first saves space.

**Q13.** sizeof(struct { char a; char b; int c; })?
(a) 6 (b) 8 (c) 12 (d) 10
**Answer: (b).**

**Q14.** sizeof(union { int i; float f; char s[20]; })?
(a) 28 (b) 20 (c) 4 (d) 0
**Answer: (b).** Largest member.

**Q15.** sizeof(union { int i; double d; })?
(a) 4 (b) 8 (c) 12 (d) 16
**Answer: (b).**

**Q16.** enum Color { RED, GREEN = 20, BLUE }. Values?
(a) 0, 20, 21 (b) 0, 20, 1 (c) 1, 20, 21 (d) 0, 1, 2
**Answer: (a).**

**Q17.** enum { A, B = 5, C, D = 2, E }. Values of C and E?
(a) 6 and 3 (b) 2 and 4 (c) 6 and 7 (d) 3 and 3
**Answer: (a).** A = 0, B = 5, C = 6, D = 2, E = 3.

**Q18.** Accessing a member through a struct pointer p:
(a) p.x (b) p->x (c) p::x (d) &p.x
**Answer: (b).** Same as (*p).x.

**Q19.** Dynamic scoping resolves names using:
(a) program text at compile time (b) the runtime call stack (c) the heap (d) the linker
**Answer: (b).**

**Q20.** An auto local variable is destroyed when:
(a) the program ends (b) control leaves its block (c) another function is called (d) never
**Answer: (b).**

**Q21.** Valid self-referential structure:
(a) struct node { int d; struct node next; }; (b) struct node { int d; struct node *next; }; (c) both (d) neither
**Answer: (b).** A struct can't contain itself (infinite size), only a pointer to itself.

**Q22.** In a union, after writing member i and then reading member f:
(a) you get the value written (b) you get i's bits reinterpreted (c) a compile error (d) zero
**Answer: (b).** All members share the same memory.

**Q23.** Whole-structure assignment `s2 = s1;`:
(a) is illegal (b) copies every member (c) copies only the first member (d) compares them
**Answer: (b).** Comparison with == is not allowed for structs, though.

**Q24.** Lifetime of a static local variable:
(a) the block (b) the whole program run (c) one call (d) until free()
**Answer: (b).** Its scope is still the block.

**Q25.** A register variable that the CPU can't hold in a register:
(a) causes an error (b) silently behaves like auto (c) becomes static (d) becomes global
**Answer: (b).**

**Q26.** Languages using static (lexical) scoping:
(a) C, C++, Java, Python (b) only Lisp (c) only Perl (d) none
**Answer: (a).**
