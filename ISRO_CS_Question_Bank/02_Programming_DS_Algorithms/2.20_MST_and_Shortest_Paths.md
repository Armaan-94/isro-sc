# 2.20 Graph Algorithms: MST and Shortest Paths

> 26 questions. Reference graph G: A-B = 2, A-C = 3, B-C = 1, B-D = 4, C-D = 5, C-E = 6, D-E = 2.

---

**Q1.** MST edges for a connected graph with 12 vertices?
(a) 12 (b) 11 (c) 13 (d) depends
**Answer: (b).** n − 1.

**Q2.** Total MST weight of G?
(a) 7 (b) 9 (c) 11 (d) 13
**Answer: (b).** BC 1, AB 2, DE 2, BD 4.

**Q3.** Dijkstra is unsuitable when the graph has:
(a) many vertices (b) cycles (c) negative edge weights (d) disconnected parts
**Answer: (c).**

**Q4.** Dijkstra from A in G. Distance to E?
(a) 6 (b) 8 (c) 9 (d) 11
**Answer: (b).** A→B→D→E = 2 + 4 + 2.

**Q5.** Handles negative edges and detects negative cycles:
(a) Dijkstra (b) Prim (c) Kruskal (d) Bellman-Ford
**Answer: (d).**

**Q6.** "Adding the same constant to every edge never changes the shortest path." This is:
(a) true (b) false: paths with more edges are penalised more (c) true for undirected only (d) true for negative constants
**Answer: (b).** Direct edge 10 vs three edges of 3 (total 9). Add 1: 11 vs 12; the shortest path flips.

**Q7.** NOT greedy:
(a) Prim (b) Kruskal (c) Huffman (d) Bellman-Ford
**Answer: (d).**

**Q8.** NOT dynamic programming:
(a) Bellman-Ford (b) Floyd-Warshall (c) 0/1 knapsack (d) Prim
**Answer: (d).**

**Q9.** Kruskal suits sparse graphs and array-based Prim suits dense graphs because:
(a) Kruskal fails on dense graphs (b) Kruskal costs O(E log E); simple Prim costs O(V²) regardless of E (c) Prim fails on sparse (d) no difference
**Answer: (b).**

**Q10.** In Kruskal's run on G, which edge is skipped?
(a) BC (b) AB (c) AC (d) BD
**Answer: (c).** A and C are already connected through B.

**Q11.** Kruskal detects cycles using:
(a) DFS every time (b) union-find (disjoint sets) (c) a heap (d) a stack
**Answer: (b).**

**Q12.** Kruskal time:
(a) O(V²) (b) O(E log E) (c) O(VE) (d) O(V³)
**Answer: (b).** Dominated by sorting the edges.

**Q13.** Prim with a binary heap:
(a) O(E log V) (b) O(V³) (c) O(E²) (d) O(V)
**Answer: (a).** O(V²) with an adjacency matrix and a plain array.

**Q14.** Bellman-Ford relaxes all edges how many times?
(a) V (b) V − 1 (c) E (d) log V
**Answer: (b).** One extra pass detects negative cycles. Total O(VE).

**Q15.** If all edge weights are distinct, the MST is:
(a) unique (b) never unique (c) undefined (d) the same as the shortest-path tree
**Answer: (a).**

**Q16.** "Adding the same constant to every edge never changes the MST." This is:
(a) true (b) false
**Answer: (a).** Every spanning tree has exactly n − 1 edges, so all totals shift by the same amount. (Contrast with Q6.)

**Q17.** Cut property: the lightest edge crossing any cut:
(a) belongs to some MST (b) is never in an MST (c) is the heaviest in the MST (d) forms a cycle
**Answer: (a).** Cycle property: the unique heaviest edge on a cycle is in no MST.

**Q18.** Square P-Q-R-S with PQ = 1, QR = 2, RS = 3, SP = 4, diagonals PR = 5, QS = 6. MST weight?
(a) 6 (b) 7 (c) 10 (d) 3
**Answer: (a).** PQ + QR + RS.

**Q19.** Doubling every edge weight changes the shortest path?
(a) yes (b) no, only the total doubles (c) only with negative edges (d) sometimes
**Answer: (b).**

**Q20.** Shortest paths in an unweighted graph are best found by:
(a) Dijkstra (b) BFS (c) Floyd-Warshall (d) Kruskal
**Answer: (b).** O(V + E).

**Q21.** Dijkstra with a binary heap:
(a) O(V²) (b) O((V + E) log V) (c) O(VE) (d) O(V³)
**Answer: (b).** O(V²) with an array; O(E + V log V) with a Fibonacci heap.

**Q22.** All-pairs shortest paths in a dense graph with negative edges (no negative cycles):
(a) Dijkstra once (b) Floyd-Warshall (c) BFS (d) Prim
**Answer: (b).**

**Q23.** Dijkstra from A in G: order in which vertices are finalised?
(a) A, B, C, D, E (b) A, C, B, D, E (c) A, B, D, C, E (d) A, B, C, E, D
**Answer: (a).** Distances 0, 2, 3, 6, 8.

**Q24.** With distinct edge weights, the shortest path between two vertices is:
(a) always unique (b) never unique (c) unique only in trees (d) not necessarily unique
**Answer: (d).** Different paths can still have equal totals (e.g., 1 + 4 = 2 + 3). (The MST, however, is unique.)

**Q25.** A minimum spanning tree exists only for:
(a) connected graphs (b) directed graphs (c) DAGs (d) complete graphs
**Answer: (a).** A disconnected graph has a minimum spanning forest.

**Q26.** Prim's algorithm grows:
(a) a forest that merges (b) a single tree from a start vertex (c) shortest paths (d) a matching
**Answer: (b).** Kruskal grows a forest.
