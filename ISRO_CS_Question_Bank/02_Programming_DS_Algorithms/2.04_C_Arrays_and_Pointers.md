# 2.4 C Arrays and Pointers

> 30 questions. Assume int = 4 bytes and pointers = 8 bytes (64-bit) unless stated.

---

**Q1.** int arr[5] starts at 2000. Address of arr[3]?
(a) 2003 (b) 2012 (c) 2008 (d) 2016
**Answer: (b).** 2000 + 3 × 4.

**Q2.** arr[i] is exactly:
(a) &arr + i (b) *(arr + i) (c) *arr + i (d) arr * i
**Answer: (b).**

**Q3.** Compile error?
(a) int *p = arr; p = p + 1; (b) int arr[5]; arr = arr + 1; (c) p = &arr[2]; (d) p++;
**Answer: (b).** An array name can't be assigned to.

**Q4.** int *p holds 5000. p − 2 refers to:
(a) 4998 (b) 4992 (c) 5008 (d) 4996
**Answer: (b).** Scaled by sizeof(int).

**Q5.** `char *p = "Hello"; p[0] = 'h';` is:
(a) fine (b) undefined behaviour (literal may be read-only) (c) always a compile error (d) makes a copy
**Answer: (b).** `char p[] = "Hello";` would be safe.

**Q6.** Output?
```c
void junk(int *i, int j) { *i = *i * *i; j = j * j; }
int main() { int i = 4, j = 2; junk(&i, j); printf("%d %d", i, j); }
```
(a) 16 4 (b) 4 2 (c) 16 2 (d) 4 4
**Answer: (c).** i by address, j by value.

**Q7.** int **k declares:
(a) an array of 2 ints (b) a pointer to a pointer to int (c) a double int (d) invalid syntax
**Answer: (b).**

**Q8.** int arr[4] = {7}; arr[1], arr[2], arr[3] are:
(a) garbage (b) 7, 7, 7 (c) 0, 0, 0 (d) error
**Answer: (c).** Partial initialisation zero-fills the rest.

**Q9.** The key difference between an array name arr and a pointer p = arr:
(a) none (b) arr can't be reassigned; p can (c) p can only point to arrays (d) arr uses less memory
**Answer: (b).** Also sizeof(arr) gives the whole array; sizeof(p) gives the pointer size.

**Q10.** `int a[] = {1, 2, 3, 4, 5}; int *p = a;` *(p + 2) = ?
(a) 2 (b) 3 (c) 4 (d) address
**Answer: (b).**

**Q11.** `int a[] = {10, 20}; int *p = a; int x = *p++;` Afterwards:
(a) x = 10, p points to a[1] (b) x = 11, p at a[0] (c) x = 20 (d) x = 10, a[0] = 11
**Answer: (a).** Postfix ++ binds tighter than *: *(p++).

**Q12.** `int a[] = {10, 20}; int *p = a; (*p)++;` Then:
(a) p points to a[1] (b) a[0] = 11 (c) a[1] = 21 (d) error
**Answer: (b).**

**Q13.** int arr[10]; sizeof(arr) / sizeof(arr[0]) = ?
(a) 1 (b) 4 (c) 10 (d) 40
**Answer: (c).**

**Q14.** Inside `void f(int arr[])`, sizeof(arr) equals:
(a) the whole array's size (b) the size of a pointer (c) 0 (d) the number of elements
**Answer: (b).** The parameter is really an int *.

**Q15.** int a[3][4] at base 1000, row-major. Address of a[1][2]?
(a) 1012 (b) 1024 (c) 1020 (d) 1028
**Answer: (b).** 1000 + (1 × 4 + 2) × 4.

**Q16.** int a[3][4] at base 1000. a + 1 points to:
(a) 1004 (b) 1016 (c) 1012 (d) 1048
**Answer: (b).** a + 1 skips one whole row of 4 ints.

**Q17.** `char s[] = "hello";` sizeof(s) and strlen(s)?
(a) 5, 5 (b) 6, 5 (c) 5, 6 (d) 8, 5
**Answer: (b).** sizeof counts the '\0'.

**Q18.** `char *s = "hello";` sizeof(s) on a 64-bit system?
(a) 5 (b) 6 (c) 8 (d) 4
**Answer: (c).** Size of the pointer.

**Q19.** int a[10]; &a[5] − &a[1] = ?
(a) 16 (b) 4 (c) 5 (d) 20
**Answer: (b).** Pointer difference counts elements, not bytes.

**Q20.** A void * pointer:
(a) can be dereferenced directly (b) must be cast before dereferencing (c) can't hold addresses (d) is the same as NULL
**Answer: (b).**

**Q21.** `int *p; *p = 5;` (p uninitialised) is:
(a) safe (b) undefined behaviour: a wild pointer (c) a compile error (d) sets p to 5
**Answer: (b).**

**Q22.** A pointer to a function taking two ints and returning int:
(a) int *fp(int, int); (b) int (*fp)(int, int); (c) int fp*(int, int); (d) (int *)fp(int, int);
**Answer: (b).** (a) declares a function returning int *.

**Q23.** `int *a[10];` declares:
(a) a pointer to an array of 10 ints (b) an array of 10 int pointers (c) a 2D array (d) invalid
**Answer: (b).** `int (*a)[10];` is a pointer to an array of 10 ints.

**Q24.** `printf("%d", a[2] == 2[a]);` prints:
(a) 0 (b) 1 (c) compile error (d) garbage
**Answer: (b).** Both mean *(a + 2).

**Q25.** `int a[5] = {1, 2, 3, 4, 5}; int *p = a + 4;` p[−2] = ?
(a) 2 (b) 3 (c) 4 (d) error
**Answer: (b).** *(a + 2).

**Q26.** `char s[] = "ISRO";` *(s + 1) = ?
(a) 'I' (b) 'S' (c) 'R' (d) 'O'
**Answer: (b).**

**Q27.** `printf("%s", s + 2);` with s = "ISRO" prints:
(a) RO (b) SRO (c) R (d) ISRO
**Answer: (a).**

**Q28.** Swapping two ints in a function needs:
(a) passing values (b) passing their addresses (c) returning both (d) globals only
**Answer: (b).** `void swap(int *x, int *y)`.

**Q29.** A NULL pointer:
(a) points to address of a valid variable (b) points nowhere and is safe to test against (c) is the same as an uninitialised pointer (d) can be dereferenced safely
**Answer: (b).**

**Q30.** `int x = 5, *p = &x, **q = &p;` **q = ?
(a) address of x (b) address of p (c) 5 (d) error
**Answer: (c).**
