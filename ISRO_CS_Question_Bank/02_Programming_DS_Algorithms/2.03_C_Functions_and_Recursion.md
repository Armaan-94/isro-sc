# 2.3 C Functions and Recursion

**Notes:** [03 C Functions and Recursion](../../PDSA_ISRO_Notes/03_C_Functions_and_Recursion.md)

> 26 questions. For recursion, draw the call tree or write the values bottom-up.

---

**Q1.** Default return type of a function with no declared type (pre-C99)?
(a) void (b) float (c) int (d) always an error
**Answer: (c).**

**Q2.** How can a C function give two values back to its caller?
(a) return (a, b); (b) return a; return b; (c) pass pointers and write through them (d) impossible
**Answer: (c).** (a) returns only b; (b) never reaches the second return.

**Q3.** rec(5) where rec(x) = x == 1 ? 1 : x * rec(x − 1)?
(a) 5 (b) 24 (c) 120 (d) 15
**Answer: (c).** 5!.

**Q4.** x(6)?
```c
int x(int n) { if (n < 3) return 1; return x(n-1) + x(n-1) + 1; }
```
(a) 15 (b) 21 (c) 31 (d) 63
**Answer: (c).** 1, 3, 7, 15, 31 for n = 2..6.

**Q5.** Output?
```c
void junk(int i, int j) { i = i * i; j = j * j; }
int main() { int i = 5, j = 2; junk(i, j); printf("%d %d", i, j); }
```
(a) 25 4 (b) 5 2 (c) 25 2 (d) 5 4
**Answer: (b).** Call by value.

**Q6.** C's parameter passing:
(a) true call-by-reference (b) only call-by-value; references are simulated with pointers (c) arrays and structs by reference only (d) both identical
**Answer: (b).** (An array argument decays to a pointer, which is itself passed by value.)

**Q7.** Tail recursion means:
(a) last function in the file (b) the recursive call is the final action (c) uses a for loop (d) no base case
**Answer: (b).** `return x * rec(x − 1);` is not tail-recursive.

**Q8.** Effect of:
```c
void display() { printf("Hi"); main(); }
int main() { display(); }
```
(a) compile error (b) prints once (c) recurses until stack overflow (d) ignored
**Answer: (c).** main can be called recursively in C.

**Q9.** Indirect recursion:
(a) A calls A (b) A calls B, B calls A (c) a loop (d) no stack used
**Answer: (b).**

**Q10.** Why is the function in Q4 slow for large n?
(a) large frames (b) x(n − 1) is computed twice: ~2ⁿ calls (c) addition in recursion (d) it's O(n)
**Answer: (b).** Storing the result once would make it O(n).

**Q11.** fun(5)?
```c
int fun(int n) { if (n <= 0) return 0; return n + fun(n - 1); }
```
(a) 10 (b) 15 (c) 5 (d) 120
**Answer: (b).**

**Q12.** Naive fib(n) with base cases fib(0) and fib(1). Total calls for fib(5)?
(a) 9 (b) 15 (c) 8 (d) 25
**Answer: (b).** C(n) = 1 + C(n − 1) + C(n − 2), C(0) = C(1) = 1: 1, 1, 3, 5, 9, 15.

**Q13.** Output of f(3)?
```c
void f(int n) { if (n == 0) return; printf("%d", n); f(n - 1); }
```
(a) 123 (b) 321 (c) 3210 (d) 0123
**Answer: (b).** Prints before recursing.

**Q14.** Output of g(3)?
```c
void g(int n) { if (n == 0) return; g(n - 1); printf("%d", n); }
```
(a) 123 (b) 321 (c) 3 (d) 1
**Answer: (a).** Prints while unwinding.

**Q15.** f(5)?
```c
int f(int n) { if (n <= 1) return 1; return f(n - 1) + f(n - 2); }
```
(a) 5 (b) 8 (c) 13 (d) 3
**Answer: (b).** 1, 1, 2, 3, 5, 8 for n = 0..5.

**Q16.** (GATE 2007) f(5)?
```c
int f(int n) {
    static int r = 0;
    if (n <= 0) return 1;
    if (n > 3) { r = n; return f(n - 2) + 2; }
    return f(n - 1) + r;
}
```
(a) 5 (b) 7 (c) 9 (d) 18
**Answer: (d).** r becomes 5 and stays (static). f(0) = 1, f(1) = 6, f(2) = 11, f(3) = 16, f(5) = f(3) + 2 = 18.

**Q17.** fun(5)?
```c
int fun(int n) { if (n == 0) return 0; return (n % 2) + 10 * fun(n / 2); }
```
(a) 5 (b) 101 (c) 110 (d) 11
**Answer: (b).** It builds the binary digits of n as a decimal number.

**Q18.** Output of f(3)?
```c
void f(int n) { if (n > 0) { f(n - 1); printf("%d", n); f(n - 1); } }
```
(a) 123 (b) 1213121 (c) 3121213 (d) 321
**Answer: (b).** f(1) = "1", f(2) = "121", f(3) = "121" + "3" + "121". It prints 2ⁿ − 1 numbers.

**Q19.** gcd(48, 18) using gcd(a, b) = b == 0 ? a : gcd(b, a % b)?
(a) 3 (b) 6 (c) 9 (d) 18
**Answer: (b).** (48, 18) → (18, 12) → (12, 6) → (6, 0).

**Q20.** Recursive sum of digits of 1234?
(a) 4 (b) 10 (c) 1234 (d) 24
**Answer: (b).**

**Q21.** Multiplications for power(x, n) = x * power(x, n − 1), power(x, 0) = 1, with n = 10?
(a) 4 (b) 10 (c) 5 (d) 1024
**Answer: (b).** Fast exponentiation (squaring) needs only O(log n).

**Q22.** Each recursive call gets:
(a) the caller's variables (b) its own stack frame with its own parameters and locals (c) heap memory (d) global storage
**Answer: (b).** A static local is shared across all calls, which is why Q16 works the way it does.

**Q23.** Missing base case in recursion leads to:
(a) a compile error (b) stack overflow at runtime (c) infinite output only (d) nothing
**Answer: (b).**

**Q24.** Main purpose of a function prototype:
(a) allocate memory (b) let the compiler check calls against the declared types before the definition (c) speed up execution (d) make a function inline
**Answer: (b).**

**Q25.** In standard C, can a function be defined inside another function?
(a) yes (b) no (c) only main (d) only static ones
**Answer: (b).**

**Q26.** Compared to an equivalent loop, recursion usually:
(a) uses less memory (b) uses more stack memory and call overhead (c) is always faster (d) can't express loops
**Answer: (b).**
