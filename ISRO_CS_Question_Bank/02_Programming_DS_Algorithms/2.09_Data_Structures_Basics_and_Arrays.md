# 2.9 Data Structure Basics and Arrays (Address Calculation)

**Notes:** [09 Data Structures Basics and Arrays](../../PDSA_ISRO_Notes/09_Data_Structures_Basics_and_Arrays.md)

> 26 questions. Formulae used: 1D: B + W(k − L). Row-major: B + W[cols(i − L₁) + (j − L₂)]. Column-major: B + W[rows(j − L₂) + (i − L₁)].

---

**Q1.** a[−6..6], base 3500, W = 4. Address of a[3]?
(a) 3512 (b) 3536 (c) 3524 (d) 3548
**Answer: (b).** 3500 + 4 × 9.

**Q2.** Same array. Address of a[0]?
(a) 3500 (b) 3524 (c) 3520 (d) 3528
**Answer: (b).** 3500 + 4 × 6.

**Q3.** VAL[1..15][1..10], base 1500, W = 4, row-major. Address of VAL[12][9]?
(a) 1972 (b) 2024 (c) 1968 (d) 1980
**Answer: (a).** 1500 + 4[10 × 11 + 8].

**Q4.** Same array, column-major. VAL[12][9]?
(a) 1972 (b) 2024 (c) 1996 (d) 2000
**Answer: (b).** 1500 + 4[15 × 8 + 11].

**Q5.** Storage for an n × n tridiagonal matrix (non-zeros only)?
(a) n² (b) n(n + 1)/2 (c) 3n − 2 (d) 2n − 1
**Answer: (c).**

**Q6.** Storage for an n × n Toeplitz matrix?
(a) n (b) 2n − 1 (c) n(n + 1)/2 (d) n²
**Answer: (b).** One value per diagonal.

**Q7.** Lower triangular, n = 8, 0-indexed, row-major, base 1000, W = 4. Address of A[5][3]?
(a) 1072 (b) 1084 (c) 1088 (d) 1076
**Answer: (a).** Index = 5 × 6/2 + 3 = 18.

**Q8.** A symmetric matrix needs as much storage as a triangular one because:
(a) it's smaller (b) one triangle including the diagonal determines it (c) it has more non-zeros (d) no relation
**Answer: (b).** n(n + 1)/2.

**Q9.** Non-linear data structure:
(a) stack (b) queue (c) tree (d) linked list
**Answer: (c).** Also graphs.

**Q10.** a[0..9], base 100, W = 2. Address of a[5]?
(a) 105 (b) 110 (c) 112 (d) 120
**Answer: (b).**

**Q11.** int A[10][20] (0-based), base 0, W = 4, row-major. Address of A[3][5]?
(a) 212 (b) 260 (c) 65 (d) 240
**Answer: (b).** (3 × 20 + 5) × 4.

**Q12.** Same array, column-major. A[3][5]?
(a) 212 (b) 260 (c) 53 (d) 220
**Answer: (a).** (5 × 10 + 3) × 4.

**Q13.** Elements in A[−3..3][2..6]?
(a) 30 (b) 35 (c) 28 (d) 42
**Answer: (b).** 7 rows × 5 columns.

**Q14.** A[2][3][4] (0-based), row-major, W = 1, base 0. Address of A[1][2][3]?
(a) 23 (b) 17 (c) 24 (d) 29
**Answer: (a).** 1 × (3 × 4) + 2 × 4 + 3.

**Q15.** Lower triangular, n = 6, base 1000, W = 4, 0-indexed row-major. A[4][2]?
(a) 1040 (b) 1048 (c) 1052 (d) 1056
**Answer: (b).** Index = 10 + 2 = 12.

**Q16.** Upper triangular, n = 6, base 2000, W = 2, 0-indexed row-major. A[2][4]?
(a) 2022 (b) 2026 (c) 2030 (d) 2013
**Answer: (b).** Elements before row 2: 6 + 5 = 11; offset 4 − 2 = 2 → index 13.

**Q17.** Storage for an n × n diagonal matrix?
(a) 1 (b) n (c) 2n (d) n²
**Answer: (b).**

**Q18.** Inserting at the front of an array holding n elements costs:
(a) O(1) (b) O(log n) (c) O(n) (d) O(n²)
**Answer: (c).** Every element shifts right.

**Q19.** Accessing a[i]:
(a) O(1) (b) O(log n) (c) O(n) (d) O(i)
**Answer: (a).** Address is computed directly.

**Q20.** A sparse matrix with t non-zeros in triplet form (with a header row) uses:
(a) 3t (b) 3(t + 1) (c) t² (d) 2t
**Answer: (b).** Each row stores (row, column, value); the header stores dimensions and t.

**Q21.** Elements strictly below the main diagonal of an n × n matrix?
(a) n(n + 1)/2 (b) n(n − 1)/2 (c) n² − n (d) n
**Answer: (b).**

**Q22.** An array is classified as:
(a) primitive (b) derived (non-primitive) (c) non-linear (d) heterogeneous
**Answer: (b).**

**Q23.** A heterogeneous structure:
(a) array (b) struct (c) stack of ints (d) matrix
**Answer: (b).**

**Q24.** In row-major order, the row offset is multiplied by:
(a) number of rows (b) number of columns (c) element size only (d) the lower bound
**Answer: (b).** In column-major, the column offset is multiplied by the number of rows.

**Q25.** Main advantage of arrays over linked lists:
(a) dynamic size (b) O(1) random access and cache-friendliness (c) cheap insertion (d) no wasted memory ever
**Answer: (b).**

**Q26.** A[1..5][1..4] stored column-major, base 0, W = 1. Address of A[3][2]?
(a) 7 (b) 9 (c) 6 (d) 10
**Answer: (a).** 5 × (2 − 1) + (3 − 1) = 7.
