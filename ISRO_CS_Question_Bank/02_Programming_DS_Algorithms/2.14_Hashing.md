# 2.14 Hashing

> 24 questions. Remember: open addressing = closed hashing (everything inside the table); chaining = open hashing.

---

**Q1.** (GATE 2014) 9 slots, h(k) = k mod 9, chaining. Keys 5, 28, 19, 15, 20, 33, 12, 17, 10. Maximum, minimum and average chain lengths?
(a) 3, 0, 1 (b) 3, 3, 3 (c) 4, 0, 1 (d) 3, 0, 2
**Answer: (a).** Slot 1 gets 28, 19, 10; slots 0, 4, 7 empty; 9 keys / 9 slots.

**Q2.** "Open addressing" means:
(a) external linked lists (b) all elements stored in the table via probing (c) dynamic hash function (d) unlimited size
**Answer: (b).**

**Q3.** Uses a second hash function for the probe step:
(a) linear probing (b) quadratic probing (c) double hashing (d) chaining
**Answer: (c).**

**Q4.** Primary clustering is a weakness of:
(a) chaining (b) linear probing (c) double hashing (d) AVL
**Answer: (b).** Quadratic probing suffers secondary clustering.

**Q5.** Why choose a prime table size in the division method?
(a) less memory (b) avoids systematic collisions from common factors (c) C requires it (d) removes chaining
**Answer: (b).**

**Q6.** Under open addressing, a deleted slot is marked "deleted" (not empty) because:
(a) hash rules (b) an empty mark would cut probe sequences and make searches stop early (c) saves memory (d) deletion is illegal
**Answer: (b).**

**Q7.** In chaining, load factor α can be:
(a) ≤ 0.5 (b) greater than 1 (c) never above 1 (d) exactly 1
**Answer: (b).**

**Q8.** Best cache performance but most clustering:
(a) chaining (b) double hashing (c) linear probing (d) quadratic probing
**Answer: (c).**

**Q9.** Size 10, h(k) = k mod 10, linear probing. Insert 12, 22, 32, 15, 25. Where is 25?
(a) 5 (b) 6 (c) 7 (d) 8
**Answer: (b).** 12→2, 22→3, 32→4, 15→5, 25→6.

**Q10.** Size 10, h(k) = k mod 10, quadratic probing (h + i²). Insert 15, 25, 35. Where is 35?
(a) 6 (b) 7 (c) 8 (d) 9
**Answer: (d).** 15→5; 25: 5 taken → 6; 35: 5, 6 taken → 5 + 4 = 9.

**Q11.** Size 13, h₁(k) = k mod 13, h₂(k) = 7 − (k mod 7). Insert 18, then 44. Where is 44?
(a) 5 (b) 6 (c) 10 (d) 12
**Answer: (c).** 18→5; 44→5 collides; h₂ = 7 − 2 = 5 → (5 + 5) mod 13 = 10.

**Q12.** Open addressing with α = 0.5. Expected probes for an unsuccessful search (uniform hashing)?
(a) 1 (b) 1.5 (c) 2 (d) 4
**Answer: (c).** 1/(1 − α).

**Q13.** Same with α = 0.9?
(a) 2 (b) 5 (c) 9 (d) 10
**Answer: (d).** Performance collapses as the table fills.

**Q14.** Chaining: expected chain length?
(a) 1 (b) α = n/m (c) n (d) log n
**Answer: (b).** Successful search ≈ 1 + α/2 comparisons.

**Q15.** Two keys hashed uniformly into 10 slots. Probability of no collision?
(a) 1/10 (b) 9/10 (c) 1/2 (d) 1
**Answer: (b).**

**Q16.** 30 keys in a table of 100 slots. Load factor?
(a) 0.3 (b) 3.3 (c) 0.7 (d) 30
**Answer: (a).**

**Q17.** Worst-case search time in a hash table:
(a) O(1) (b) O(log n) (c) O(n) (d) O(n²)
**Answer: (c).** If every key collides. The O(1) figure is the average case.

**Q18.** Rehashing is done when:
(a) the table is empty (b) the load factor crosses a threshold: grow the table and reinsert everything (c) a key is deleted (d) never
**Answer: (b).**

**Q19.** Mid-square hashing:
(a) squares the key and takes middle digits (b) divides by a prime (c) adds digits (d) uses two functions
**Answer: (a).** Folding splits the key into parts and adds them.

**Q20.** Average search in a hash table vs a balanced BST:
(a) O(1) vs O(log n) (b) O(log n) vs O(1) (c) both O(1) (d) both O(n)
**Answer: (a).**

**Q21.** Hashing is a poor choice when you need:
(a) exact-key lookup (b) range queries or sorted order (c) insertions (d) deletions
**Answer: (b).** Hashing scatters keys; use a BST or B-tree.

**Q22.** In open addressing, the maximum number of keys is:
(a) unlimited (b) the table size m (c) m² (d) m/2
**Answer: (b).**

**Q23.** A good hash function should be:
(a) slow and complex (b) fast and spread keys uniformly (c) always map to slot 0 (d) depend on insertion order
**Answer: (b).**

**Q24.** Quadratic probing can fail to find an empty slot even when one exists because:
(a) it only visits some slots (b) it visits all slots (c) clustering never happens (d) it uses a second hash
**Answer: (a).** With a prime m and α ≤ 0.5 an empty slot is guaranteed to be found.
