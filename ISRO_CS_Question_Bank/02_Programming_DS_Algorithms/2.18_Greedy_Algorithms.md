# 2.18 Greedy Algorithms

> 24 questions. Greedy works when a locally best choice is always part of some optimal solution (greedy-choice property + optimal substructure).

---

**Q1.** Greedy generally fails for:
(a) fractional knapsack (b) Huffman (c) 0/1 knapsack (d) optimal merge
**Answer: (c).** Needs DP.

**Q2.** Frequencies M1 = 12, M2 = 4, M3 = 45, M4 = 17, M5 = 23. Total Huffman bits?
(a) 303 (b) 206 (c) 224 (d) 101
**Answer: (b).** Code lengths 4, 4, 1, 3, 2.

**Q3.** Two encodings of the same word, one the bit-complement of the other, can both be valid Huffman codes because:
(a) only one can be (b) the 0/1 labels on branches are arbitrary; lengths are what matter (c) Huffman is random (d) repeated letters
**Answer: (b).**

**Q4.** Building a Huffman code for n symbols with a min-heap:
(a) O(n) (b) O(n log n) (c) O(n²) (d) O(n log² n)
**Answer: (b).**

**Q5.** Files of 18, 3, 15, 12, 10, 11, 7, 9 pages, merged optimally. Total record moves?
(a) 162 (b) 200 (c) 247 (d) 300
**Answer: (c).** 10 + 19 + 21 + 27 + 37 + 48 + 85.

**Q6.** W = 20; items (profit, weight): (25, 18), (24, 15), (15, 10). Fractional knapsack optimum?
(a) 28.2 (b) 31 (c) 31.5 (d) 34
**Answer: (c).** Ratios 1.39, 1.6, 1.5: take (24, 15), then half of (15, 10).

**Q7.** Jobs (profit, deadline): T1 (100, 2), T2 (10, 1), T3 (27, 2), T4 (15, 1). Maximum profit?
(a) 100 (b) 115 (c) 127 (d) 152
**Answer: (c).** T3 in slot 1, T1 in slot 2.

**Q8.** Fractional knapsack must sort by:
(a) profit (b) weight (c) profit/weight ratio (d) index
**Answer: (c).**

**Q9.** Frequencies a = 5, b = 9, c = 12, d = 13, e = 16, f = 45. Total Huffman bits?
(a) 224 (b) 300 (c) 241 (d) 200
**Answer: (a).** Lengths: f 1; c, d, e 3; a, b 4.

**Q10.** Same data. Bits saved over a fixed 3-bit code?
(a) 56 (b) 76 (c) 100 (d) 24
**Answer: (b).** 300 − 224.

**Q11.** Average code length for Q2's data?
(a) about 2.04 bits (b) 3 bits (c) 1.5 bits (d) 2.5 bits
**Answer: (a).** 206/101.

**Q12.** In Huffman coding, more frequent symbols get:
(a) longer codes (b) shorter codes (c) equal codes (d) no codes
**Answer: (b).**

**Q13.** Huffman codes are prefix-free, meaning:
(a) all codes have equal length (b) no code is a prefix of another (c) codes start with 0 (d) codes are sorted
**Answer: (b).** So decoding is unambiguous.

**Q14.** Activity selection is solved greedily by choosing the activity with the earliest:
(a) start time (b) finish time (c) duration (d) index
**Answer: (b).**

**Q15.** Activities (start, finish): (1, 4), (3, 5), (0, 6), (5, 7), (3, 9), (5, 9), (6, 10), (8, 11), (8, 12), (2, 14), (12, 16). Maximum non-overlapping activities?
(a) 3 (b) 4 (c) 5 (d) 6
**Answer: (b).** (1, 4), (5, 7), (8, 11), (12, 16).

**Q16.** Coins {1, 3, 4}, amount 6. Greedy (largest first) vs optimal number of coins?
(a) 2 vs 2 (b) 3 vs 2 (c) 3 vs 3 (d) 4 vs 2
**Answer: (b).** Greedy 4 + 1 + 1; optimal 3 + 3. Greedy works for standard currency systems but not in general.

**Q17.** Files 20, 30, 10, 5, 30 merged optimally. Total cost?
(a) 205 (b) 190 (c) 215 (d) 95
**Answer: (a).** 5 + 10 = 15; 15 + 20 = 35; 30 + 30 = 60; 35 + 60 = 95. Total 15 + 35 + 60 + 95.

**Q18.** Jobs (profit, deadline): a (100, 2), b (19, 1), c (27, 2), d (25, 1), e (15, 3). Maximum profit?
(a) 127 (b) 142 (c) 152 (d) 167
**Answer: (b).** a → slot 2, c → slot 1, e → slot 3.

**Q19.** W = 50; items (value, weight): (60, 10), (100, 20), (120, 30). Fractional knapsack optimum?
(a) 220 (b) 240 (c) 280 (d) 180
**Answer: (b).** 60 + 100 + (20/30) × 120.

**Q20.** Same items, 0/1 knapsack optimum?
(a) 160 (b) 180 (c) 220 (d) 240
**Answer: (c).** 100 + 120. Greedy by ratio would take 60 + 100 = 160.

**Q21.** Greedy algorithms among these:
(a) Prim, Kruskal, Dijkstra, Huffman (b) Floyd-Warshall (c) Bellman-Ford (d) LCS
**Answer: (a).** The others are dynamic programming.

**Q22.** In a Huffman tree, the two least frequent symbols:
(a) are siblings at the deepest level (b) are at the root (c) get different lengths (d) are merged last
**Answer: (a).**

**Q23.** Huffman builds the tree:
(a) top-down (b) bottom-up (c) randomly (d) by sorting codes
**Answer: (b).** Shannon-Fano is top-down and not always optimal.

**Q24.** Fixed-length code size for 5 symbols?
(a) 2 bits (b) 3 bits (c) 5 bits (d) 4 bits
**Answer: (b).** ⌈log₂ 5⌉.
