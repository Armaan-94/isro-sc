# 2.6 Dynamic Memory Allocation, Macros and File Handling

> 26 questions. For macros, expand the text literally first, then apply precedence.

---

**Q1.** Output?
```c
#define abc(x) x*x
int a = 64 / abc(4);
```
(a) 4 (b) 16 (c) 64 (d) 1
**Answer: (c).** 64/4*4 = (64/4)*4.

**Q2.** Output?
```c
#define mno pqr
printf("mno");
```
(a) pqr (b) mno (c) error (d) nothing
**Answer: (b).** No substitution inside string literals.

**Q3.** Allocates and zero-initialises:
(a) malloc (b) calloc (c) realloc (d) free
**Answer: (b).**

**Q4.** Using a pointer after free() is a:
(a) memory leak (b) dangling pointer (c) segment table (d) buffer overflow
**Answer: (b).**

**Q5.** fopen mode that erases existing content on opening:
(a) "r" (b) "a" (c) "w" (d) "a+"
**Answer: (c).** "w+" also truncates.

**Q6.** int f1 = 10, f12 = 20; `#define fun(i, j) i##j`. fun(f1, 2) = ?
(a) 10 (b) 20 (c) 12 (d) error
**Answer: (b).** Token pasting gives the identifier f12.

**Q7.** Function that resets the file pointer to the start:
(a) fseek only (b) ftell (c) rewind (d) feof
**Answer: (c).** Equivalent to fseek(fp, 0, SEEK_SET).

**Q8.** A macro vs a function:
(a) macros are type-checked (b) macros are textual substitution with no call overhead or type checks (c) functions are always faster (d) no difference
**Answer: (b).**

**Q9.** After `#define int char`, `int a = 10, *p = &a;` declares:
(a) int and int * (b) char and char * (c) error (d) unchanged
**Answer: (b).** So sizeof(a) = 1.

**Q10.** `#define SQ(x) x*x`; SQ(2 + 3) = ?
(a) 25 (b) 11 (c) 10 (d) 13
**Answer: (b).** 2 + 3*2 + 3.

**Q11.** `#define SQ(x) ((x)*(x))`; SQ(2 + 3) = ?
(a) 25 (b) 11 (c) 10 (d) 13
**Answer: (a).** Parenthesise parameters and the whole body.

**Q12.** `#define MAX(a, b) ((a) > (b) ? (a) : (b))`, i = 5, j = 3. After `int m = MAX(i++, j);`, m and i are:
(a) 5, 6 (b) 6, 7 (c) 5, 7 (d) 6, 6
**Answer: (b).** i++ appears twice in the expansion: the comparison uses 5 (i → 6), then the result uses 6 (i → 7).

**Q13.** malloc on failure returns:
(a) −1 (b) NULL (c) 0 bytes of garbage (d) aborts
**Answer: (b).**

**Q14.** realloc(ptr, newsize):
(a) always extends in place (b) may move the block, so assign the returned pointer (c) frees ptr only (d) zero-fills the new part
**Answer: (b).**

**Q15.** Memory leak:
(a) using freed memory (b) allocated memory that is never freed and becomes unreachable (c) writing past an array (d) stack overflow
**Answer: (b).**

**Q16.** free(NULL):
(a) crashes (b) is a safe no-op (c) frees everything (d) is a compile error
**Answer: (b).**

**Q17.** calloc(5, 4) allocates:
(a) 5 bytes (b) 9 bytes (c) 20 zeroed bytes (d) 20 bytes of garbage
**Answer: (c).**

**Q18.** Memory from malloc lives on:
(a) the stack (b) the heap (c) registers (d) the code segment
**Answer: (b).** It persists until freed.

**Q19.** `#include <stdio.h>` vs `#include "my.h"`:
(a) identical (b) <> searches system directories; "" searches the current directory first (c) "" is for C++ only (d) <> is deprecated
**Answer: (b).**

**Q20.** `#ifdef DEBUG ... #endif` provides:
(a) runtime checks (b) conditional compilation (c) a loop (d) a macro function
**Answer: (b).**

**Q21.** File size can be found by:
(a) fseek(fp, 0, SEEK_END) then ftell(fp) (b) feof(fp) (c) rewind(fp) (d) fclose(fp)
**Answer: (a).**

**Q22.** fgetc returns type int (not char) because:
(a) it's faster (b) it must be able to return EOF (−1), distinct from every valid character (c) characters are ints anyway (d) a historical error
**Answer: (b).**

**Q23.** fopen("missing.txt", "r") on a non-existent file returns:
(a) a new empty file (b) NULL (c) EOF (d) a crash
**Answer: (b).** Always check for NULL.

**Q24.** Writing raw struct data to a file is done with:
(a) fprintf (b) fputs (c) fwrite (d) fputc
**Answer: (c).** Read back with fread.

**Q25.** Macros are processed:
(a) at runtime (b) by the preprocessor before compilation (c) by the linker (d) by the loader
**Answer: (b).**

**Q26.** Mode "a+" allows:
(a) reading and appending; existing content kept (b) write only (c) read only (d) truncation
**Answer: (a).**
