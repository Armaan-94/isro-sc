# 2.10 Stacks: Expression Conversion, Evaluation and Recursion

**Notes:** [10 Stacks Expressions Recursion](../../PDSA_ISRO_Notes/10_Stacks_Expressions_Recursion.md)

> 28 questions. Precedence used: ^ (right-associative) > * / > + − (left-associative).

---

**Q1.** Push order 1, 2, 3, 4, 5. Impossible pop sequence?
(a) 3, 5, 4, 2, 1 (b) 2, 4, 3, 5, 1 (c) 4, 3, 5, 2, 1 (d) 5, 4, 3, 1, 2
**Answer: (d).** After popping 5, 4, 3, the stack is [1, 2] with 2 on top; 1 can't come out first.

**Q2.** Postfix of A + B * C − D?
(a) A B C * + D − (b) A B + C * D − (c) A B C + * D − (d) A B * C + D −
**Answer: (a).**

**Q3.** Evaluate postfix 6 2 3 * + 5 −.
(a) 5 (b) 7 (c) 13 (d) 19
**Answer: (b).** 2 × 3 = 6; 6 + 6 = 12; 12 − 5 = 7.

**Q4.** Minimum moves for Tower of Hanoi with 5 disks?
(a) 10 (b) 25 (c) 31 (d) 32
**Answer: (c).** 2ⁿ − 1.

**Q5.** fun(3)?
```c
void fun(int x) { if (x > 0) { printf("%d", x); fun(x - 1); } }
```
(a) 123 (b) 321 (c) 3210 (d) 0123
**Answer: (b).**

**Q6.** fun(3)?
```c
void fun(int x) { if (x > 0) { fun(x - 1); printf("%d", x); } }
```
(a) 123 (b) 321 (c) 3210 (d) 0123
**Answer: (a).** Prints while unwinding.

**Q7.** fun(4, 3)?
```c
int fun(int x, int y) { if (y == 0) return 0; return x + fun(x, y - 1); }
```
(a) 7 (b) 12 (c) 64 (d) −1
**Answer: (b).** Adds x to itself y times: x × y.

**Q8.** The recursive call is the last action of the function. This is:
(a) head recursion (b) tail recursion (c) indirect (d) mutual
**Answer: (b).**

**Q9.** Infinite recursion crashes because:
(a) cache overflow (b) every call pushes a stack frame until the stack is exhausted (c) no locals allowed (d) compile error
**Answer: (b).**

**Q10.** fun(4, 3)?
```c
int fun(int x, int y) { if (x == 0) return y; return fun(x - 1, x + y); }
```
(a) 7 (b) 10 (c) 13 (d) 12
**Answer: (c).** (4, 3) → (3, 7) → (2, 10) → (1, 12) → (0, 13).

**Q11.** Postfix of (A + B) * (C − D)?
(a) A B + C D − * (b) A B C D + − * (c) A B + * C D − (d) + A B − C D *
**Answer: (a).**

**Q12.** Postfix of A * (B + C) / D?
(a) A B C + * D / (b) A B * C + D / (c) A B C + D / * (d) A B C * + D /
**Answer: (a).**

**Q13.** Postfix of A + B * C ^ D?
(a) A B C D ^ * + (b) A B C * D ^ + (c) A B + C D ^ * (d) A B C D * ^ +
**Answer: (a).** ^ binds tightest.

**Q14.** Prefix of (A + B) * C?
(a) * + A B C (b) + * A B C (c) A B + C * (d) * A + B C
**Answer: (a).**

**Q15.** Evaluate postfix 5 3 + 8 2 − *.
(a) 48 (b) 30 (c) 64 (d) 16
**Answer: (a).** (5 + 3) × (8 − 2).

**Q16.** Evaluate prefix − * 2 3 4.
(a) 2 (b) −2 (c) 10 (d) 14
**Answer: (a).** (2 × 3) − 4.

**Q17.** Evaluate postfix 8 2 3 ^ / 2 3 * + 5 1 * −.
(a) 1 (b) 2 (c) 3 (d) 7
**Answer: (b).** 2³ = 8; 8/8 = 1; 2 × 3 = 6; 1 + 6 = 7; 5 × 1 = 5; 7 − 5 = 2.

**Q18.** Maximum stack depth while evaluating 6 2 3 * + 5 −?
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (b).** [6, 2, 3] before the first operator.

**Q19.** Maximum operator-stack size while converting a + b * c − d / e to postfix?
(a) 1 (b) 2 (c) 3 (d) 4
**Answer: (b).** [+, *] is the deepest; when − arrives both are popped.

**Q20.** Number of distinct pop sequences possible when pushing 1, 2, 3 in order (pops interleaved freely)?
(a) 3 (b) 5 (c) 6 (d) 4
**Answer: (b).** Catalan number C₃. Only 3, 1, 2 is impossible out of the 3! = 6 orders.

**Q21.** Stacks are NOT the natural choice for:
(a) function calls (b) balanced-parenthesis checking (c) BFS (d) undo operations
**Answer: (c).** BFS uses a queue; DFS uses a stack.

**Q22.** Two stacks share an array of size n, growing from opposite ends. Overflow occurs when:
(a) top1 = n/2 (b) top1 = top2 − 1 (c) top2 = 0 (d) top1 = n
**Answer: (b).** No space is wasted until they meet.

**Q23.** Total recursive calls made by the standard Tower of Hanoi recursion for n = 5 (counting calls with n = 0)?
(a) 31 (b) 32 (c) 63 (d) 64
**Answer: (c).** 2ⁿ⁺¹ − 1.

**Q24.** Push 1, push 2, pop, push 3, push 4, pop, pop, push 5. Top of stack and popped sequence?
(a) 5; popped 2, 4, 3 (b) 1; popped 2, 3, 4 (c) 5; popped 4, 3, 2 (d) 3; popped 2, 4, 5
**Answer: (a).** Final stack [1, 5].

**Q25.** A queue built with two stacks has amortised cost per operation:
(a) O(1) (b) O(log n) (c) O(n) (d) O(n²)
**Answer: (a).** Each element moves between the stacks at most once.

**Q26.** Which string is balanced?
(a) (() (b) ([)] (c) {[()]} (d) )(
**Answer: (c).**

**Q27.** Stack overflow (array implementation) means:
(a) pop on empty (b) push when top = N − 1 (c) top = −1 (d) peek on full
**Answer: (b).** Pop on empty is underflow.

**Q28.** Postfix and prefix need no parentheses because:
(a) operators are always binary (b) operator position fixes the order of evaluation (c) they only use + and * (d) they are evaluated right to left
**Answer: (b).**
