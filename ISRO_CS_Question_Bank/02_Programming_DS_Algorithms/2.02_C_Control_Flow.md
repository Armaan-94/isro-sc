# 2.2 C Control Flow: Conditionals, Loops and Switch

> 26 questions. Trace every line; most marks are lost to a stray semicolon or a missing break.

---

**Q1.** Output?
```c
int i;
for (i = 5; i <= 10; i++);
    printf("%d", i);
```
(a) 5 6 7 8 9 10 (b) nothing (c) 11 (d) infinite loop
**Answer: (c).** The `;` is the loop body. printf runs once after the loop.

**Q2.** Output?
```c
int i = 1;
while (i <= 3) {
    printf("%d ", i);
}
```
(a) 1 2 3 (b) 1 printed forever (c) nothing (d) error
**Answer: (b).** i never changes.

**Q3.** Output?
```c
int i = 0;
do { printf("%d ", i); i++; } while (i < 0);
```
(a) nothing (b) 0 (c) infinite (d) error
**Answer: (b).** do-while runs at least once.

**Q4.** Output?
```c
for (i = 1; i <= 3; i++) {
    if (i == 2) continue;
    printf("%d ", i);
}
```
(a) 1 2 3 (b) 1 3 (c) 1 (d) infinite
**Answer: (b).**

**Q5.** (GATE 2015) How many times does printf execute?
```c
int i, j, k = 0;
j = 2 * 3 / 4 + 2.0 / 5 + 8 / 5;
k -= --j;
for (i = 0; i < 5; i++) {
    switch (i + k) {
        case 1:
        case 2: printf("%d", i + k);
        case 3: printf("%d", i + k);
        default: printf("%d", i + k);
    }
}
```
(a) 8 (b) 9 (c) 10 (d) 11
**Answer: (c).** j = 1 + 0.4 + 1 = 2.4 → 2; --j = 1; k = −1. i + k = −1, 0, 1, 2, 3 → prints 1, 1, 3, 3, 2.

**Q6.** (GATE 2012) Output?
```c
char inchar = 'A';
switch (inchar) {
    case 'A': printf("choice A\n");
    case 'B': printf("choice B ");
    case 'C':
    case 'D':
    case 'E':
    default: printf("No Choice");
}
```
(a) No Choice (b) choice A (c) choice A, choice B, No Choice (d) nothing
**Answer: (c).** No breaks: falls through everything.

**Q7.** break inside a switch inside a for loop:
(a) exits the loop (b) exits only the switch (c) exits both (d) error
**Answer: (b).**

**Q8.** Output?
```c
for (i = 1, j = 2; i <= 2 && j <= 3; i++, j++)
    printf("%d-%d ", i, j);
```
(a) 1-2 (b) 1-2 2-3 (c) 1-2 2-3 3-4 (d) error
**Answer: (b).**

**Q9.** a = 5, b = −1. Output?
```c
if (a > 0)
    if (b > 0) printf("both positive");
    else printf("a positive, b not");
```
(a) nothing (b) both positive (c) a positive, b not (d) error
**Answer: (c).** else binds to the nearest unmatched if.

**Q10.** switch can be faster than a long if-else ladder because:
(a) less memory always (b) a jump table gives near-constant-time dispatch (c) no break needed (d) if-else can't use integers
**Answer: (b).**

**Q11.** Illegal case label (a, b are variables)?
(a) case 5: (b) case 'A': (c) case a + b: (d) case 3 + 7:
**Answer: (c).** Labels must be compile-time constants.

**Q12.** continue inside a for loop:
(a) exits the loop (b) skips the rest of the body, runs the increment, re-tests (c) restarts from init (d) no effect
**Answer: (b).**

**Q13.** How many iterations: `for (i = 0; i < 10; i += 3)`?
(a) 3 (b) 4 (c) 5 (d) 10
**Answer: (b).** i = 0, 3, 6, 9.

**Q14.** How many times does the inner body run?
```c
for (i = 0; i < 3; i++)
    for (j = 0; j <= i; j++)
        count++;
```
(a) 3 (b) 6 (c) 9 (d) 4
**Answer: (b).** 1 + 2 + 3.

**Q15.** Output?
```c
int i = 3;
while (i--) printf("%d ", i);
```
(a) 3 2 1 (b) 2 1 0 (c) 3 2 1 0 (d) 2 1
**Answer: (b).** The test uses the old value; printing uses the decremented one.

**Q16.** Output?
```c
switch (3) {
    default: printf("D");
    case 1: printf("1");
}
```
(a) D (b) 1 (c) D1 (d) nothing
**Answer: (c).** No match → default; no break → falls into case 1.

**Q17.** Output?
```c
int x = 0;
if (x = 0) printf("A"); else printf("B");
```
(a) A (b) B (c) error (d) AB
**Answer: (b).** The assignment's value is 0, which is false.

**Q18.** `if (x = 5)` is:
(a) a compile error (b) always true (c) always false (d) true only if x was 5
**Answer: (b).** Assignment evaluates to 5.

**Q19.** Output?
```c
for (i = 0; i < 5; i++) { if (i == 3) break; printf("%d ", i); }
```
(a) 0 1 2 (b) 0 1 2 3 (c) 0 1 2 4 (d) 3
**Answer: (a).**

**Q20.** After `int i = 0; for (; i < 3;) i++;`, i = ?
(a) 2 (b) 3 (c) 4 (d) 0
**Answer: (b).**

**Q21.** How many times is "Hi" printed?
```c
for (i = 1; i <= 10; i *= 2) printf("Hi");
```
(a) 3 (b) 4 (c) 5 (d) 10
**Answer: (b).** i = 1, 2, 4, 8.

**Q22.** `switch (2.5) { ... }` in C is:
(a) valid (b) a compile error (c) rounds to 2 (d) runtime error
**Answer: (b).** Only integral types.

**Q23.** A statement placed before the first case label in a switch:
(a) runs every time (b) never runs (c) is a compile error (d) runs only for default
**Answer: (b).** It's unreachable.

**Q24.** `do { ... } while (0);` executes its body:
(a) 0 times (b) once (c) forever (d) error
**Answer: (b).**

**Q25.** Loop that is guaranteed to run its body at least once:
(a) for (b) while (c) do-while (d) none
**Answer: (c).**

**Q26.** A widely accepted use of goto is:
(a) replacing all loops (b) jumping out of deeply nested loops (c) calling functions (d) jumping into another function
**Answer: (b).** goto can't leave the current function.
