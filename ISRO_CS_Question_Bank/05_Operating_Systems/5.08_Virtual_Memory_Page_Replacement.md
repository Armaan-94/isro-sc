# 5.8 Virtual Memory and Page Replacement

**Notes:** [08 Virtual Memory and Page Replacement](../../OS_ISRO_Notes/08_Virtual_Memory_and_Page_Replacement.md)

> 26 questions. String S1 = 7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2. String S2 = 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5. Frames start empty.

---

**Q1.** S1, 3 frames, FIFO faults?
(a) 7 (b) 9 (c) 10 (d) 13
**Answer: (c).**

**Q2.** S1, 3 frames, OPT faults?
(a) 5 (b) 7 (c) 9 (d) 10
**Answer: (b).**

**Q3.** S1, 3 frames, LRU faults?
(a) 7 (b) 8 (c) 9 (d) 10
**Answer: (c).**

**Q4.** Can show Belady's anomaly:
(a) LRU (b) OPT (c) FIFO (d) LRU and OPT
**Answer: (c).**

**Q5.** S2, FIFO with 3 frames and with 4 frames. Faults?
(a) 9 and 10 (b) 10 and 9 (c) 9 and 8 (d) 8 and 10
**Answer: (a).** More frames, more faults: Belady's anomaly.

**Q6.** S2, LRU with 3 frames. Faults?
(a) 8 (b) 9 (c) 10 (d) 12
**Answer: (c).**

**Q7.** S2, OPT with 3 frames. Faults?
(a) 6 (b) 7 (c) 8 (d) 9
**Answer: (b).**

**Q8.** Memory access 200 ns, fault service 10 ms, p = 0.0005. EAT?
(a) 200 ns (b) about 5200 ns (c) 5000 ns (d) 10000 ns
**Answer: (b).**

**Q9.** Memory access 100 ns, fault service 8 ms, p = 0.001. EAT?
(a) about 8.1 µs (b) 100 ns (c) 800 ns (d) 8 ms
**Answer: (a).** 99.9 + 8000 ns.

**Q10.** Memory 100 ns, fault service 8 ms. Maximum fault rate for EAT ≤ 200 ns?
(a) 10⁻³ (b) about 1.25 × 10⁻⁵ (c) 10⁻² (d) 0.5
**Answer: (b).** p × 8,000,000 ≤ 100.

**Q11.** Falling CPU utilisation as processes are added; the scheduler adds more. This is:
(a) correct (b) thrashing; reduce multiprogramming (c) a fast disk (d) impossible
**Answer: (b).**

**Q12.** Stack algorithms (never Belady):
(a) FIFO, LFU (b) LRU, OPT (c) MFU, FIFO (d) LFU, MFU
**Answer: (b).**

**Q13.** Global replacement is common because:
(a) isolation (b) better overall throughput (c) less memory (d) no thrashing
**Answer: (b).**

**Q14.** LFU wrongly keeps a page that:
(a) was never used (b) was heavily used long ago (c) is in an empty table (d) is short
**Answer: (b).**

**Q15.** Too large a working-set window Δ:
(a) misses locality (b) spans several localities (c) guarantees thrashing (d) no effect
**Answer: (b).**

**Q16.** Pure demand paging: minimum number of faults for a reference string?
(a) 0 (b) number of distinct pages referenced (c) string length (d) number of frames
**Answer: (b).** Every page faults at least once on first use.

**Q17.** The dirty (modify) bit lets the OS:
(a) skip writing an unmodified victim back to disk (b) find LRU (c) count references (d) mark invalid pages
**Answer: (a).**

**Q18.** Page-fault handling order:
(a) trap, check validity, find frame, read from disk, update table, restart instruction (b) restart first (c) update table before reading (d) kill the process
**Answer: (a).**

**Q19.** Virtual memory allows:
(a) programs larger than physical memory (b) no page tables (c) faster RAM (d) fewer processes
**Answer: (a).**

**Q20.** Copy-on-write in fork():
(a) parent and child share pages until one writes, then that page is copied (b) everything is copied immediately (c) no sharing (d) only code is copied
**Answer: (a).**

**Q21.** LRU can be implemented with:
(a) counters (timestamps) or a stack of page numbers (b) a FIFO queue only (c) random numbers (d) the dirty bit only
**Answer: (a).**

**Q22.** The clock (second-chance) algorithm approximates:
(a) LRU using a reference bit (b) OPT exactly (c) FIFO without modification (d) LFU
**Answer: (a).**

**Q23.** A reference string 1, 2, 3, 1, 2, 3 with 3 frames and FIFO. Faults?
(a) 3 (b) 4 (c) 6 (d) 0
**Answer: (a).** All three fit.

**Q24.** Same string with 2 frames, FIFO?
(a) 3 (b) 4 (c) 5 (d) 6
**Answer: (d).** Each new page evicts the one needed next.

**Q25.** Same string with 2 frames, OPT?
(a) 3 (b) 4 (c) 5 (d) 6
**Answer: (b).** 1F, 2F, 3F (evict 2, whose next use is later than 1's), 1 hit, 2F (evict 1, never used again), 3 hit.

**Q26.** Thrashing happens when:
(a) allocated frames fall below the working set (b) the TLB is large (c) the disk is fast (d) CPU utilisation is high
**Answer: (a).**
