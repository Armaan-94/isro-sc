# 5.11 Unix: Kernel, Commands and Shell Scripting

**Notes:** [11 Unix OS and Shell Scripting](../../OS_ISRO_Notes/11_Unix_OS_and_Shell_Scripting.md)

> 26 questions. Permission digits: r = 4, w = 2, x = 1, for owner, group, others.

---

**Q1.** A line of ls -l starts with d. It is a:
(a) regular file (b) directory (c) symbolic link (d) socket
**Answer: (b).** "-" regular, "l" symlink, "c" character device, "b" block device, "p" pipe, "s" socket.

**Q2.** The target of a symbolic link is deleted. The link:
(a) deletes itself (b) becomes broken (c) becomes a regular file (d) still works
**Answer: (b).**

**Q3.** Loops while its condition is false:
(a) for (b) while (c) until (d) case
**Answer: (c).**

**Q4.** A shell function does `return 25`. The caller:
(a) gets 25 as a value (b) can't compile (c) sees 25 only as the exit status in $? (d) can't use return
**Answer: (c).** Use echo and $(...) to return data.

**Q5.** Tests that a path is a regular file:
(a) -e (b) -d (c) -f (d) -s
**Answer: (c).**

**Q6.** -rw-r--r-- means:
(a) owner rw, group r, others r (b) owner r, group rw (c) directory (d) everyone executes
**Answer: (a).**

**Q7.** The pipe | :
(a) overwrites a file (b) appends (c) passes one command's output as the next's input (d) reads from a file
**Answer: (c).**

**Q8.** chmod 755 gives:
(a) rwxr-xr-x (b) rwxrwxrwx (c) rw-r--r-- (d) rwx------
**Answer: (a).**

**Q9.** Octal for rwxr-x---?
(a) 750 (b) 755 (c) 740 (d) 770
**Answer: (a).**

**Q10.** chmod 644 gives:
(a) rw-r--r-- (b) rwxr--r-- (c) rw-rw-r-- (d) r--r--r--
**Answer: (a).**

**Q11.** umask 022. Default permissions of a new regular file (base 666)?
(a) 644 (b) 755 (c) 622 (d) 666
**Answer: (a).** Directories (base 777) get 755.

**Q12.** Counts lines in a file:
(a) wc -l (b) wc -w (c) grep -n (d) cat -l
**Answer: (a).**

**Q13.** grep -v pattern prints:
(a) matching lines (b) non-matching lines (c) count only (d) line numbers
**Answer: (b).** -c counts matches, -i ignores case.

**Q14.** $# holds:
(a) the script name (b) the number of arguments (c) the exit status (d) the PID
**Answer: (b).** $0 script name, $? exit status, $$ PID.

**Q15.** echo $((5 + 3 * 2)) prints:
(a) 16 (b) 11 (c) 13 (d) 5+3*2
**Answer: (b).**

**Q16.** expr 10 / 3 prints:
(a) 3.33 (b) 3 (c) 4 (d) error
**Answer: (b).** Integer arithmetic.

**Q17.** cmd > file vs cmd >> file:
(a) both append (b) > overwrites, >> appends (c) > appends (d) identical
**Answer: (b).**

**Q18.** kill -9 PID sends:
(a) SIGTERM (b) SIGKILL, which can't be caught (c) SIGHUP (d) SIGSTOP
**Answer: (b).** Plain kill sends SIGTERM (15).

**Q19.** nice with a higher niceness value:
(a) raises priority (b) lowers priority (c) kills (d) stops
**Answer: (b).**

**Q20.** Creates a symbolic link:
(a) ln (b) ln -s (c) cp -s (d) mv -s
**Answer: (b).** Plain ln makes a hard link.

**Q21.** The first 5 lines of a file:
(a) head -n 5 file (b) tail -5 file (c) cat -5 file (d) more 5 file
**Answer: (a).**

**Q22.** Numeric sort:
(a) sort -n (b) sort -r (c) sort -u (d) sort
**Answer: (a).** -r reverses; -u removes duplicates.

**Q23.** A Unix filename is stored in:
(a) the inode (b) the directory entry (c) the superblock (d) the boot block
**Answer: (b).**

**Q24.** The shell is:
(a) the kernel (b) a command interpreter between user and kernel (c) a compiler (d) a file system
**Answer: (b).**

**Q25.** The innermost layer of Unix that talks to hardware:
(a) shell (b) kernel (c) utilities (d) applications
**Answer: (b).**

**Q26.** Variable assignment in a shell script:
(a) name = "Alice" (b) name="Alice" (c) $name="Alice" (d) set name Alice only
**Answer: (b).** No spaces around =.
