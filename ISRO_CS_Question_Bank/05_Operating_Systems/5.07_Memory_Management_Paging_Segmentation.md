# 5.7 Memory Management: Contiguous Allocation, Paging, Segmentation

**Notes:** [07 Memory Management](../../OS_ISRO_Notes/07_Memory_Management.md)

> 28 questions. TLB EAT = h(t + m) + (1 − h)(t + 2m) for single-level paging.

---

**Q1.** Internal and external fragmentation occur respectively in:
(a) variable, fixed (b) fixed-size schemes (paging), variable-size contiguous schemes (c) always together (d) neither
**Answer: (b).**

**Q2.** Logical space 2²⁰ bytes, page size 2¹² bytes. Page-number bits?
(a) 8 (b) 12 (c) 20 (d) 32
**Answer: (a).**

**Q3.** TLB 10 ns, memory 90 ns, hit ratio 90%. EAT?
(a) 90 (b) 100 (c) 109 (d) 190 ns
**Answer: (c).** 0.9 × 100 + 0.1 × 190.

**Q4.** Segmentation vs paging:
(a) segmentation is physical fixed-size (b) segmentation is the user's logical, variable-size view; paging is physical, fixed-size (c) identical (d) paging has external fragmentation
**Answer: (b).**

**Q5.** Segment with limit 212, base 880. Offset 212?
(a) valid, 1092 (b) invalid: offset must be < limit (c) valid, 880 (d) invalid base
**Answer: (b).**

**Q6.** Multilevel paging needs more memory accesses because:
(a) it doesn't (b) each level of table is a separate access (c) no page table (d) TLB only
**Answer: (b).**

**Q7.** Inverted page table size depends on:
(a) logical pages (b) the number of physical frames (c) number of processes (d) TLB size
**Answer: (b).**

**Q8.** Processes of 20K, 30K, 50K share 40 frames proportionally. Frames for the 30K process?
(a) 8 (b) 10 (c) 12 (d) 15
**Answer: (c).**

**Q9.** A page fault occurs when:
(a) the page is in the TLB (b) the page's entry is marked invalid (not in memory) (c) a cache miss (d) the relocation register overflows
**Answer: (b).**

**Q10.** Page size 1 KB, logical address 5000, page 4 → frame 7. Physical address?
(a) 7168 (b) 8072 (c) 5904 (d) 7904
**Answer: (b).** Offset 5000 − 4096 = 904; 7 × 1024 + 904.

**Q11.** TLB 20 ns, memory 100 ns, hit ratio 80%. EAT?
(a) 120 (b) 140 (c) 160 (d) 220 ns
**Answer: (b).** 0.8 × 120 + 0.2 × 220.

**Q12.** TLB 20 ns, memory 100 ns. Hit ratio needed for EAT = 130 ns?
(a) 0.8 (b) 0.85 (c) 0.9 (d) 0.95
**Answer: (c).** 120h + 220(1 − h) = 130.

**Q13.** 32-bit logical address, 4 KB pages, 4-byte page-table entries. Single-level page table size?
(a) 1 MB (b) 4 MB (c) 4 KB (d) 16 MB
**Answer: (b).** 2²⁰ entries × 4 B.

**Q14.** 64 MB physical memory, 4 KB frames. Bits for a frame number?
(a) 12 (b) 14 (c) 16 (d) 26
**Answer: (b).** 2²⁶/2¹² = 2¹⁴ frames.

**Q15.** 32-bit address, 4 KB pages, 4-byte entries, two-level paging with each inner table filling one page. Address split (outer, inner, offset)?
(a) 10, 10, 12 (b) 8, 12, 12 (c) 12, 8, 12 (d) 16, 4, 12
**Answer: (a).** One page holds 4096/4 = 1024 entries → 10 bits.

**Q16.** Partitions 100, 500, 200, 300, 600 KB (in order); requests 212, 417, 112, 426 KB. With first fit, which request can't be placed?
(a) 212 (b) 417 (c) 112 (d) 426
**Answer: (d).** 212 → 500 (288 left), 417 → 600 (183 left), 112 → 288 (176 left); no hole ≥ 426.

**Q17.** Same data with best fit:
(a) all four placed (b) 426 waits (c) 417 waits (d) 212 waits
**Answer: (a).** 212 → 300, 417 → 500, 112 → 200, 426 → 600.

**Q18.** Same data with worst fit, which waits?
(a) 212 (b) 417 (c) 112 (d) 426
**Answer: (d).** 212 → 600 (388), 417 → 500 (83), 112 → 388 (276).

**Q19.** Process of 72,766 bytes, page size 2048 bytes. Internal fragmentation?
(a) 1086 bytes (b) 962 bytes (c) 0 (d) 2048 bytes
**Answer: (b).** 35 full pages = 71,680; remainder 1086 needs a 36th page wasting 2048 − 1086.

**Q20.** Base (relocation) register 1400, limit 500, logical address 450. Physical address?
(a) 450 (b) 1850 (c) 1900 (d) trap
**Answer: (b).** 450 < 500, so 1400 + 450.

**Q21.** Same registers, logical address 520:
(a) 1920 (b) trap: addressing error (c) 520 (d) 1400
**Answer: (b).**

**Q22.** External fragmentation is solved by:
(a) compaction or non-contiguous allocation (paging) (b) larger pages (c) TLB (d) more processes
**Answer: (a).**

**Q23.** Paging eliminates:
(a) internal fragmentation (b) external fragmentation (c) page tables (d) the TLB
**Answer: (b).** The last page still causes internal fragmentation.

**Q24.** Larger page size gives:
(a) smaller page table, more internal fragmentation (b) larger table, less fragmentation (c) no effect (d) external fragmentation
**Answer: (a).**

**Q25.** Without a TLB, each data reference with single-level paging needs how many memory accesses?
(a) 1 (b) 2 (c) 3 (d) 0
**Answer: (b).** Page table, then data.

**Q26.** Three-level paging, no TLB. Memory accesses per reference?
(a) 2 (b) 3 (c) 4 (d) 6
**Answer: (c).** Three tables plus the data.

**Q27.** The MMU translates:
(a) physical to logical (b) logical (virtual) to physical addresses (c) disk to memory (d) cache to registers
**Answer: (b).**

**Q28.** Segmentation suffers from:
(a) internal fragmentation only (b) external fragmentation (c) no fragmentation (d) thrashing always
**Answer: (b).**
