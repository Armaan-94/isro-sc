# 5.12 Linux: Kernel, Job Scheduling and Memory Management

**Notes:** [12 Linux OS](../../OS_ISRO_Notes/12_Linux_OS.md)

> 22 questions. Crontab fields: minute, hour, day-of-month, month, day-of-week.

---

**Q1.** Linux kernel type:
(a) microkernel (b) monolithic (with loadable modules) (c) exokernel (d) hybrid only
**Answer: (b).**

**Q2.** A one-time job tonight at 11 PM:
(a) cron (b) at (c) anacron (d) crond
**Answer: (b).**

**Q3.** A laptop often off at night needs missed daily jobs run later:
(a) cron (b) at (c) anacron (d) batch
**Answer: (c).**

**Q4.** */15 * * * * runs:
(a) every 15 hours (b) every 15 minutes (c) 3:15 PM daily (d) on the 15th
**Answer: (b).**

**Q5.** Belady's anomaly:
(a) LRU (b) OPT (c) FIFO (d) clock
**Answer: (c).**

**Q6.** Clock algorithm, page with R = 1:
(a) evicted (b) R cleared, second chance, pointer moves on (c) swapped out (d) stop
**Answer: (b).**

**Q7.** Current default slab allocator:
(a) buddy (b) SLAB (c) SLOB (d) SLUB
**Answer: (d).**

**Q8.** Low vm.swappiness means:
(a) swap aggressively (b) prefer reclaiming cache over swapping (c) swap disabled (d) swap that percentage
**Answer: (b).**

**Q9.** 0 2 * * * /backup.sh runs:
(a) every 2 minutes (b) daily at 2:00 AM (c) on the 2nd of each month (d) every 2 hours
**Answer: (b).**

**Q10.** 30 9 * * 1-5 runs:
(a) 9:30 AM Monday to Friday (b) 9:30 PM weekends (c) every 30 minutes (d) on days 1–5 of the month
**Answer: (a).**

**Q11.** 0 */2 * * * runs:
(a) every 2 minutes (b) at minute 0 of every second hour (c) twice a day (d) on day 2
**Answer: (b).**

**Q12.** A one-time job that runs when system load allows:
(a) at (b) batch (c) cron (d) anacron
**Answer: (b).**

**Q13.** Lists the current user's cron jobs:
(a) crontab -e (b) crontab -l (c) crontab -r (d) atq
**Answer: (b).** -e edits, -r removes all; atq lists at jobs.

**Q14.** Buddy allocator, 64 KB free block, request 13 KB. Block allocated and internal fragmentation?
(a) 16 KB, 3 KB (b) 13 KB, 0 (c) 32 KB, 19 KB (d) 64 KB, 51 KB
**Answer: (a).** Round up to a power of two; 64 → 32 → 16 (two splits).

**Q15.** The buddy system mainly reduces:
(a) external fragmentation of physically contiguous memory (b) internal fragmentation (c) TLB misses (d) swapping
**Answer: (a).** It causes internal fragmentation through power-of-two rounding.

**Q16.** NRU evicts from the lowest non-empty class. Class 0 is:
(a) R = 0, M = 0 (b) R = 1, M = 1 (c) R = 0, M = 1 (d) R = 1, M = 0
**Answer: (a).** Not referenced, not modified.

**Q17.** Accessing memory outside the process's valid regions causes:
(a) a page fault that loads data (b) a segmentation fault (c) a TLB hit (d) swapping
**Answer: (b).**

**Q18.** Uninitialised global variables live in:
(a) text (b) data (c) BSS (d) stack
**Answer: (c).**

**Q19.** The stack grows ___ and the heap grows ___ (typical layout):
(a) down, up (b) up, down (c) both up (d) both down
**Answer: (a).**

**Q20.** Shows free and used memory:
(a) free -h (b) df -h (c) du -h (d) top only
**Answer: (a).** df shows disk space per file system; du shows directory sizes.

**Q21.** Swap file vs swap partition:
(a) file is resizable and easier to manage (b) file must be contiguous (c) identical in all respects (d) partition is resizable at runtime
**Answer: (a).**

**Q22.** The dirty bit in a PTE indicates:
(a) the page was written since loading (b) the page is invalid (c) the page is shared (d) the page is in the TLB
**Answer: (a).**
