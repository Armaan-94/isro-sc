# 5.13 Distributed Systems

**Notes:** [13 Distributed Systems](../../OS_ISRO_Notes/13_Distributed_Systems.md)

> 22 questions.

---

**Q1.** Single point of failure by design:
(a) Ricart-Agrawala (b) Suzuki-Kasami (c) centralized (d) token-based
**Answer: (c).**

**Q2.** Suzuki-Kasami, requester already holds the token. Messages?
(a) N (b) N − 1 (c) 0 (d) 2N
**Answer: (c).** Otherwise N (N − 1 requests + 1 token).

**Q3.** A detected deadlock that no longer exists:
(a) livelock (b) phantom deadlock (c) starvation (d) Byzantine failure
**Answer: (b).**

**Q4.** Byzantine agreement is harder than crash consensus because:
(a) more processes (b) faulty processes may lie or send conflicting messages (c) no agreement needed (d) single site
**Answer: (b).**

**Q5.** 2PC: coordinator crashes after all participants voted YES. Participants:
(a) commit on their own (b) abort on their own (c) must block and wait (d) auto-abort
**Answer: (c).** 3PC reduces this blocking.

**Q6.** Broadcast timestamped requests and wait for all replies:
(a) centralized (b) Ricart-Agrawala (c) Suzuki-Kasami (d) token ring
**Answer: (b).**

**Q7.** No global clock because:
(a) each node has its own local clock and no shared memory (b) no clocks (c) shared CPU (d) messages remove time
**Answer: (a).**

**Q8.** Messages per critical-section entry in Ricart-Agrawala (N processes)?
(a) N (b) 2(N − 1) (c) 3(N − 1) (d) 3
**Answer: (b).** N − 1 requests and N − 1 replies.

**Q9.** Lamport's distributed mutual exclusion messages per entry?
(a) 2(N − 1) (b) 3(N − 1) (c) N (d) 0
**Answer: (b).** Request, reply and release to everyone.

**Q10.** Centralized mutual exclusion messages per entry?
(a) 1 (b) 2 (c) 3 (d) N
**Answer: (c).** Request, grant, release.

**Q11.** Lamport clock rule on receiving a message with timestamp t (local clock L):
(a) L = t (b) L = max(L, t) + 1 (c) L = L + 1 only (d) L = min(L, t)
**Answer: (b).**

**Q12.** P2's clock is 1; it receives a message stamped 3. New clock?
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (c).** max(1, 3) + 1.

**Q13.** Lamport clocks guarantee:
(a) if a → b then L(a) < L(b) (b) if L(a) < L(b) then a → b (c) global real time (d) no ties
**Answer: (a).** The converse needs vector clocks.

**Q14.** Vector clocks can detect:
(a) causality and concurrency between events (b) real time (c) deadlocks only (d) network speed
**Answer: (a).**

**Q15.** Processes needed to tolerate f Byzantine faults:
(a) 2f + 1 (b) 3f + 1 (c) f + 1 (d) 4f
**Answer: (b).** For f = 1: 4 processes.

**Q16.** Bully election algorithm elects:
(a) the process with the highest ID among those alive (b) the lowest ID (c) a random process (d) the oldest
**Answer: (a).**

**Q17.** A token-based mutual exclusion risk:
(a) token loss or duplication (b) too many coordinators (c) clock drift only (d) none
**Answer: (a).**

**Q18.** 2PC phases:
(a) voting, then commit/abort (b) lock, unlock (c) prepare, read (d) request, release
**Answer: (a).**

**Q19.** A distributed system communicates by:
(a) shared memory (b) message passing (c) a shared clock (d) a single bus
**Answer: (b).**

**Q20.** Checkpointing helps by:
(a) letting processes roll back to a saved consistent state after failure (b) speeding messages (c) avoiding deadlock (d) synchronising clocks
**Answer: (a).**

**Q21.** Replication improves:
(a) availability and fault tolerance, at the cost of consistency effort (b) only consistency (c) only speed of writes (d) nothing
**Answer: (a).**

**Q22.** Transparency in distributed systems means:
(a) users see the system as a single computer, not as many machines (b) all code is open (c) no security (d) every node sees all memory
**Answer: (a).**
