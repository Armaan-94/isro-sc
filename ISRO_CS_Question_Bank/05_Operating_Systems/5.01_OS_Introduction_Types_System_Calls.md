# 5.1 Introduction to OS: Types, Structure and System Calls

**Notes:** [01 Introduction to OS](../../OS_ISRO_Notes/01_Introduction_to_OS.md)

> 26 questions, including the fork() counting questions that appear almost every year.

---

**Q1.** Primary goal of an OS:
(a) efficiency at all costs (b) convenience, with efficiency secondary (c) minimum memory (d) throughput only
**Answer: (b).**

**Q2.** Multitasking and time-sharing are:
(a) unrelated (b) essentially the same: multiprogramming plus fast switching (c) unrelated eras (d) single vs multi CPU
**Answer: (b).**

**Q3.** In SMP, processors are:
(a) master-slave (b) peers running the same OS (c) only one runs the kernel (d) not communicating
**Answer: (b).**

**Q4.** A pacemaker needs a:
(a) soft real-time OS (b) hard real-time OS (c) batch OS (d) time-sharing OS
**Answer: (b).**

**Q5.** Speedup with N processors is:
(a) exactly N (b) more than N (c) less than N, due to overhead (d) 1
**Answer: (c).**

**Q6.** Moves most services into user-space servers:
(a) monolithic (b) layered (c) microkernel (d) simple
**Answer: (c).** More reliable, slower (IPC overhead).

**Q7.** A system call:
(a) is like a normal function call (b) traps into kernel mode, then returns to user mode (c) permanently sets kernel mode (d) terminates the program
**Answer: (b).**

**Q8.** "Get/set time" and "get file attributes" belong to:
(a) process control (b) device management (c) information maintenance (d) communication
**Answer: (c).**

**Q9.** Mode bit value for kernel mode (common convention):
(a) 0 (b) 1 (c) 2 (d) −1
**Answer: (a).** User mode = 1.

**Q10.** Which instruction should be privileged?
(a) add two registers (b) read the time of day (c) disable interrupts (d) a function call
**Answer: (c).** Also I/O instructions, setting the timer, changing memory-management registers.

**Q11.** How many times is "hello" printed?
```c
for (i = 0; i < 3; i++) fork();
printf("hello");
```
(a) 3 (b) 6 (c) 7 (d) 8
**Answer: (d).** 2³ processes.

**Q12.** In Q11, how many child processes are created?
(a) 3 (b) 7 (c) 8 (d) 6
**Answer: (b).** 2ⁿ − 1.

**Q13.** `fork(); fork(); printf("A");` prints A how many times?
(a) 2 (b) 3 (c) 4 (d) 8
**Answer: (c).**

**Q14.** Total processes (including the original) after `if (fork() && fork()) fork();`?
(a) 3 (b) 4 (c) 5 (d) 8
**Answer: (b).** The first child gets 0 and stops; the parent forks again; that child gets 0 and stops; the parent forks a third time.

**Q15.** Total processes after `fork() || fork();`?
(a) 2 (b) 3 (c) 4 (d) 1
**Answer: (b).** The parent short-circuits; only the first child calls the second fork.

**Q16.** fork() returns, in the child:
(a) the child's PID (b) 0 (c) −1 (d) the parent's PID
**Answer: (b).** The parent gets the child's PID; −1 means failure.

**Q17.** exec() family calls:
(a) create a new process (b) replace the current process image with a new program (c) terminate (d) wait for a child
**Answer: (b).** PID stays the same.

**Q18.** The bootstrap program is stored in:
(a) RAM (b) ROM/firmware (c) the cache (d) the swap area
**Answer: (b).**

**Q19.** Spooling overlaps:
(a) I/O of one job with computation of another, using disk as a buffer (b) two CPUs (c) cache and RAM (d) compilation and linking
**Answer: (a).** e.g. print spooling.

**Q20.** Multiprogramming increases:
(a) CPU utilisation (b) response time of each job (c) memory per job (d) the number of CPUs
**Answer: (a).**

**Q21.** Monolithic kernel vs microkernel:
(a) monolithic is faster but less modular (b) microkernel is faster (c) same (d) monolithic is more reliable
**Answer: (a).**

**Q22.** In a layered OS, layer i may use services of:
(a) any layer (b) only lower layers (c) only higher layers (d) none
**Answer: (b).**

**Q23.** A distributed OS gives users:
(a) a single-system image over loosely coupled machines (b) shared physical memory (c) one CPU (d) no network
**Answer: (a).**

**Q24.** A trap differs from a hardware interrupt because it is:
(a) caused by an external device (b) generated by the running program (system call or error) (c) maskable only (d) slower
**Answer: (b).**

**Q25.** Asymmetric multiprocessing:
(a) all peers (b) a master CPU controls slave CPUs (c) no OS (d) GPUs only
**Answer: (b).**

**Q26.** The interface programmers use to request OS services is:
(a) the API (e.g., POSIX, Win32), which invokes system calls (b) the BIOS only (c) the compiler (d) the shell only
**Answer: (a).**
