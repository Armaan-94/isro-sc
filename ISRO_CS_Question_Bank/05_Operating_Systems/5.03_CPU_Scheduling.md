# 5.3 CPU Scheduling Algorithms

**Notes:** [03 CPU Scheduling Algorithms](../../OS_ISRO_Notes/03_CPU_Scheduling_Algorithms.md)

> 30 questions. TAT = CT − AT; WT = TAT − BT; Response = first run − AT.
> Set A: P1 (AT 0, BT 5), P2 (1, 3), P3 (2, 8), P4 (3, 6).

---

**Q1.** Set A, FCFS. Average waiting time?
(a) 4.25 (b) 5.0 (c) 5.75 (d) 6.5
**Answer: (c).** WT 0, 4, 6, 13.

**Q2.** Set A, FCFS. Average turnaround time?
(a) 10.75 (b) 11.25 (c) 10.5 (d) 14.75
**Answer: (b).** TAT 5, 7, 14, 19.

**Q3.** FCFS is:
(a) preemptive (b) free of convoy effect (c) non-preemptive and subject to the convoy effect (d) needs burst times
**Answer: (c).**

**Q4.** SRTF is optimal but impractical because:
(a) context switches only (b) it needs future burst times (c) deadlock (d) it can't preempt
**Answer: (b).**

**Q5.** Set A, SJF (non-preemptive). Average WT?
(a) 5.0 (b) 5.25 (c) 5.75 (d) 6.0
**Answer: (b).** Order P1, P2, P4, P3; WT 0, 4, 12, 5.

**Q6.** Set A, SRTF. Average TAT?
(a) 10.5 (b) 10.75 (c) 11.25 (d) 14.75
**Answer: (a).** CT P2 = 4, P1 = 8, P4 = 14, P3 = 22.

**Q7.** Set A, SRTF. Average WT?
(a) 4.5 (b) 5.0 (c) 5.25 (d) 5.75
**Answer: (b).** WT 3, 0, 12, 5.

**Q8.** Set A, Round Robin with quantum 4. Average WT?
(a) 5.75 (b) 7.5 (c) 9.25 (d) 10
**Answer: (c).** CT P2 = 7, P1 = 16, P3 = 20, P4 = 22. Worse than FCFS here.

**Q9.** Set A, RR q = 4. Response time of P3?
(a) 2 (b) 5 (c) 7 (d) 9
**Answer: (b).** First runs at 7; arrived at 2.

**Q10.** Starvation of low-priority processes is fixed by:
(a) smaller quantum (b) aging (c) FCFS (d) larger quantum
**Answer: (b).**

**Q11.** RR with n = 5 processes, q = 3. Maximum wait between two turns of a process?
(a) 3 (b) 12 (c) 15 (d) 5
**Answer: (b).** (n − 1)q.

**Q12.** RR with a huge quantum behaves like:
(a) SRTF (b) FCFS (c) priority (d) deadlock
**Answer: (b).**

**Q13.** HRRN response ratio:
(a) BT/WT (b) (WT + BT)/BT (c) WT − BT (d) BT/(WT + BT)
**Answer: (b).**

**Q14.** A job has waited 10 units and needs 5 units of CPU. Its response ratio?
(a) 2 (b) 3 (c) 0.5 (d) 15
**Answer: (b).** (10 + 5)/5.

**Q15.** Multilevel queue vs multilevel feedback queue:
(a) same (b) MLQ lets jobs move (c) MLFQ lets jobs move between queues; MLQ is fixed (d) MLQ always preemptive
**Answer: (c).**

**Q16.** P1 (0, 4, priority 2), P2 (1, 3, 1), P3 (2, 1, 3), P4 (3, 5, 4); non-preemptive, lower number = higher priority. WT of P3?
(a) 1 (b) 5 (c) 6 (d) 3
**Answer: (b).** Order P1, P2, P3, P4; P3 runs 7–8.

**Q17.** Same data. Average WT?
(a) 3.25 (b) 3.5 (c) 4 (d) 2.75
**Answer: (a).** 0, 3, 5, 5.

**Q18.** The most general, configurable algorithm:
(a) priority (b) RR (c) multilevel feedback queue (d) HRRN
**Answer: (c).**

**Q19.** P1 = 24, P2 = 3, P3 = 3, all arriving at 0, FCFS in that order. Average WT?
(a) 3 (b) 17 (c) 27 (d) 10
**Answer: (b).** 0, 24, 27.

**Q20.** Same jobs, SJF. Average WT?
(a) 3 (b) 6 (c) 17 (d) 9
**Answer: (a).** Order P2, P3, P1: 0, 3, 6.

**Q21.** Same jobs, RR with q = 4. Average WT?
(a) 3 (b) 5.67 (c) 17 (d) 7
**Answer: (b).** P1 runs 0–4, P2 4–7, P3 7–10, P1 10–30. WT: P1 6, P2 4, P3 7.

**Q22.** P1 (0, 8), P2 (1, 4), P3 (2, 9), P4 (3, 5), SRTF. Average WT?
(a) 6.5 (b) 7.75 (c) 5 (d) 8
**Answer: (a).** P1 0–1, P2 1–5, P4 5–10, P1 10–17, P3 17–26. WT 9, 0, 15, 2.

**Q23.** Exponential averaging with α = 0.5, τ₀ = 10, actual bursts 6 then 4. Predicted τ₂?
(a) 5 (b) 6 (c) 7 (d) 8
**Answer: (b).** τ₁ = 0.5·6 + 0.5·10 = 8; τ₂ = 0.5·4 + 0.5·8 = 6.

**Q24.** RR quantum 4 ms, context switch 1 ms, all processes CPU-bound. CPU utilisation?
(a) 75% (b) 80% (c) 90% (d) 100%
**Answer: (b).** 4/(4 + 1).

**Q25.** Set A finishes all 4 processes at time 22. Throughput?
(a) 4/22 per unit time (b) 22/4 (c) 1/4 (d) 4
**Answer: (a).**

**Q26.** Scheduling algorithms affect:
(a) I/O time (b) time spent waiting in the ready queue (c) burst time (d) arrival time
**Answer: (b).**

**Q27.** Best for interactive time-sharing systems:
(a) FCFS (b) Round Robin (c) SJF (d) LJF
**Answer: (b).** Good response time.

**Q28.** Gives the minimum average waiting time among non-preemptive algorithms:
(a) FCFS (b) SJF (c) priority (d) LJF
**Answer: (b).**

**Q29.** Which algorithm can't cause starvation?
(a) SJF (b) priority without aging (c) Round Robin (d) SRTF
**Answer: (c).**

**Q30.** Smaller RR quantum generally:
(a) improves response time but increases context-switch overhead (b) reduces switches (c) equals FCFS (d) has no effect
**Answer: (a).**
