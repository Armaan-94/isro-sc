# ISRO Scientist/Engineer 'SC' (Computer Science): Question Bank

This folder is questions only, as you asked. There is no theory here. It has **2,307 multiple-choice questions** in 91 topic files, and every answer comes with a short explanation that shows the fastest correct method. The topic numbering follows the original *ISRO_CS_Question_Bank.pdf*.

**How to use it**
1. Read the matching chapter in the notes folders first (OS, DBMS, CN, PDSA).
2. Cover the answers and attempt a whole file with a timer: about 40 seconds for a conceptual question and about 90 seconds for a numerical one.
3. Mark every miss, re-read only that idea, and come back to the file two days later.

Each file opens with a one-line formula reminder wherever numericals depend on one, so you can do the arithmetic without flipping back to the notes.

## Corrections to the original PDF

Every answer here was checked by hand. Where the source PDF was wrong, this bank uses the corrected version:

- **Matrix chain (M1 10×100, M2 100×20, M3 20×5, M4 5×80):** the optimal cost 19000 comes from **(M1(M2M3))M4**, not M1((M2M3)M4).
- **"Distinct edge weights ⇒ unique shortest path"** is false. Two different paths can still have equal totals (1 + 4 = 2 + 3). Distinct weights do make the **MST** unique.
- **Control link vs access link in recursion:** for a function nested in g that calls itself, the control link points to the previous call, but the access link points to g's activation record. They are not the same.
- **Binary search for 47 in the 10-element example** probes 4 elements (31, 58, 40, 47), not 3.
- **Banker's algorithm (Silberschatz data):** P0's request (0, 2, 0) is safe on the original state. It becomes unsafe only after P1's request (1, 0, 2) has been granted.
