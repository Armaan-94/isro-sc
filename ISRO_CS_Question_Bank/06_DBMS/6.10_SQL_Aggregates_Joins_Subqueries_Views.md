# 6.10 SQL: Aggregates, Joins, Set Operations, Subqueries and Views

> 26 questions. Emp.sal holds 100, 200, NULL, 300 unless stated.

---

**Q1.** Always equal, even with NULLs:
(a) COUNT(*) and COUNT(sal) (b) COUNT(sal) and SUM/AVG (c) AVG(sal) and SUM(sal)/COUNT(sal) (d) COUNT(*) and SUM
**Answer: (c).**

**Q2.** WHERE vs HAVING:
(a) interchangeable (b) WHERE filters rows before grouping; HAVING filters groups after (c) HAVING only with * (d) WHERE allows aggregates
**Answer: (b).**

**Q3.** LIKE '___%' matches:
(a) exactly 3 chars (b) at least 3 chars (c) at most 3 (d) exactly 4
**Answer: (b).**

**Q4.** Keeps duplicates:
(a) UNION (b) INTERSECT (c) UNION ALL (d) EXCEPT
**Answer: (c).**

**Q5.** A correlated subquery is slower because:
(a) disk space (b) it re-runs for each outer row (c) no WHERE (d) more rows
**Answer: (b).**

**Q6.** View with AVG and GROUP BY is:
(a) updatable (b) not updatable (c) DELETE only (d) a base table
**Answer: (b).**

**Q7.** No row lost from either table:
(a) inner (b) natural (c) full outer join (d) Cartesian
**Answer: (c).**

**Q8.** PL/SQL component that returns a value and can be used in SELECT:
(a) procedure (b) trigger (c) function (d) block
**Answer: (c).**

**Q9.** LIKE 'A%' AND LIKE '%n' returns names that:
(a) start with A or end with n (b) start with A and end with n (c) contain both (d) are "An"
**Answer: (b).**

**Q10.** A BEFORE INSERT trigger:
(a) runs after (b) needs manual call (c) fires automatically before the insert (d) runs only via EXEC
**Answer: (c).**

**Q11.** COUNT(*) and COUNT(sal)?
(a) 4, 4 (b) 4, 3 (c) 3, 3 (d) 3, 4
**Answer: (b).**

**Q12.** SUM(sal) and AVG(sal)?
(a) 600, 150 (b) 600, 200 (c) 600, NULL (d) NULL, NULL
**Answer: (b).** NULLs are ignored.

**Q13.** SUM(sal)/COUNT(*)?
(a) 200 (b) 150 (c) NULL (d) 600
**Answer: (b).** Differs from AVG because COUNT(*) counts the NULL row.

**Q14.** Second-highest salary:
(a) SELECT MAX(sal) FROM Emp WHERE sal < (SELECT MAX(sal) FROM Emp) (b) SELECT MAX(sal) - 1 FROM Emp (c) SELECT sal FROM Emp ORDER BY sal (d) SELECT MIN(sal) FROM Emp
**Answer: (a).**

**Q15.** `WHERE x NOT IN (SELECT y FROM T)` where T.y contains a NULL. Result?
(a) normal rows (b) no rows (c) all rows (d) error
**Answer: (b).** x <> NULL is unknown, so NOT IN is never true. NOT EXISTS avoids this.

**Q16.** sal > ALL (SELECT sal FROM Emp WHERE dept = 10) means greater than:
(a) the minimum of that set (b) the maximum of that set (c) any one value (d) the average
**Answer: (b).** > ANY means greater than the minimum.

**Q17.** R = {1, 2, 2, 3}, S = {3, 4}. Rows in R UNION S and R UNION ALL S?
(a) 4 and 6 (b) 6 and 4 (c) 4 and 4 (d) 5 and 6
**Answer: (a).**

**Q18.** Same R, S. R INTERSECT S and R EXCEPT S?
(a) {3} and {1, 2} (b) {3} and {1, 2, 2} (c) {} and {1, 2, 3} (d) {3, 4} and {1}
**Answer: (a).** Set operations remove duplicates.

**Q19.** R LEFT JOIN S where R has 3 rows: minimum result rows?
(a) 0 (b) 3 (c) |S| (d) 12
**Answer: (b).**

**Q20.** A column in SELECT that isn't in GROUP BY must:
(a) be inside an aggregate function (b) be a key (c) be NULL (d) be ordered
**Answer: (a).**

**Q21.** Aggregate in WHERE (e.g., WHERE AVG(sal) > 100):
(a) allowed (b) an error; use HAVING (c) ignored (d) same as HAVING
**Answer: (b).**

**Q22.** Execution order with grouping:
(a) FROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY (b) SELECT first (c) HAVING before WHERE (d) GROUP BY last
**Answer: (a).**

**Q23.** NATURAL JOIN can go wrong when:
(a) tables share an extra same-named column that isn't a join key (b) no common columns (c) keys exist (d) NULLs exist
**Answer: (a).** Use JOIN ... USING or ON.

**Q24.** A view stores:
(a) a copy of the data (b) only its defining query (c) an index (d) a trigger
**Answer: (b).** A materialised view stores data.

**Q25.** EXISTS (subquery) is true when:
(a) the subquery returns at least one row (b) it returns NULL (c) it returns 0 (d) it returns exactly one row
**Answer: (a).**

**Q26.** SELECT dept, COUNT(*) FROM Emp GROUP BY dept HAVING COUNT(*) > 2 returns:
(a) departments with more than 2 employees (b) all departments (c) employees in big departments (d) an error
**Answer: (a).**
