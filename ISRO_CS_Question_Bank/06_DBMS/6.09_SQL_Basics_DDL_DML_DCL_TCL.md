# 6.9 SQL Basics: SELECT/WHERE, DDL, DML, DCL, TCL

> 26 questions.

---

**Q1.** Which can be rolled back?
(a) all of DELETE, TRUNCATE, DROP (b) only DELETE (c) only TRUNCATE (d) none
**Answer: (b).**

**Q2.** WHERE salary = NULL returns:
(a) rows with NULL salary (b) rows with 0 (c) no rows (d) a syntax error
**Answer: (c).** Use IS NULL.

**Q3.** Logical execution order:
(a) SELECT, FROM, WHERE (b) WHERE, FROM, SELECT (c) FROM, WHERE, SELECT (d) FROM, SELECT, WHERE
**Answer: (c).**

**Q4.** CHAR(10) storing 'Cat' occupies:
(a) 3 (b) 10 characters, space-padded (c) 0 (d) error
**Answer: (b).**

**Q5.** Removes specific rows with WHERE and can be rolled back:
(a) TRUNCATE (b) DROP (c) DELETE (d) ALTER
**Answer: (c).**

**Q6.** SELECT DISTINCT name, city returns:
(a) unique names (b) unique cities (c) unique (name, city) pairs (d) all rows
**Answer: (c).**

**Q7.** GRANT and REVOKE:
(a) DDL (b) DML (c) DCL (d) TCL
**Answer: (c).**

**Q8.** DDL commands:
(a) can be rolled back (b) auto-commit (c) affect data only (d) need COMMIT
**Answer: (b).**

**Q9.** A column alias:
(a) renames permanently (b) lasts only for the query (c) needs ALTER (d) only for tables
**Answer: (b).**

**Q10.** Currency should use:
(a) FLOAT (b) DECIMAL(p, s) (c) VARCHAR (d) BOOLEAN
**Answer: (b).** Exact values.

**Q11.** WHERE marks BETWEEN 40 AND 60 includes:
(a) 41–59 (b) 40–60 inclusive (c) 40–59 (d) 41–60
**Answer: (b).**

**Q12.** name LIKE 'a%' matches names that:
(a) end with a (b) start with a (c) contain a (d) are exactly "a%"
**Answer: (b).** % = any sequence; _ = exactly one character.

**Q13.** name LIKE '_a%' matches names whose:
(a) first letter is a (b) second letter is a (c) last letter is a (d) length is 2
**Answer: (b).**

**Q14.** WHERE dept IN ('CS', 'IT') is equivalent to:
(a) dept = 'CS' AND dept = 'IT' (b) dept = 'CS' OR dept = 'IT' (c) dept LIKE 'CS%IT' (d) NOT NULL
**Answer: (b).**

**Q15.** ORDER BY default direction:
(a) ascending (b) descending (c) random (d) insertion order
**Answer: (a).**

**Q16.** 5 + NULL evaluates to:
(a) 5 (b) 0 (c) NULL (d) error
**Answer: (c).**

**Q17.** A PRIMARY KEY column is implicitly:
(a) UNIQUE and NOT NULL (b) NULL allowed (c) a foreign key (d) indexed only
**Answer: (a).**

**Q18.** A UNIQUE column (without NOT NULL):
(a) can contain NULLs (b) can't contain NULLs (c) is a primary key (d) allows duplicates
**Answer: (a).** Most systems allow multiple NULLs.

**Q19.** CHECK (age >= 18) is a:
(a) domain/check constraint (b) foreign key (c) trigger (d) index
**Answer: (a).**

**Q20.** Adds a column to an existing table:
(a) ALTER TABLE ... ADD (b) UPDATE (c) INSERT COLUMN (d) MODIFY TABLE
**Answer: (a).**

**Q21.** Rolls back only part of a transaction:
(a) COMMIT (b) ROLLBACK TO SAVEPOINT (c) TRUNCATE (d) REVOKE
**Answer: (b).**

**Q22.** TRUNCATE vs DELETE without WHERE:
(a) TRUNCATE is faster, can't be rolled back and doesn't fire row triggers (b) identical (c) DELETE removes the structure (d) TRUNCATE supports WHERE
**Answer: (a).**

**Q23.** DROP TABLE:
(a) removes rows only (b) removes the table structure and data (c) is DML (d) can be rolled back
**Answer: (b).**

**Q24.** SQL keywords are:
(a) case-insensitive (b) case-sensitive (c) uppercase only (d) lowercase only
**Answer: (a).**

**Q25.** SELECT maps to which RA operator, WHERE to which?
(a) projection, selection (b) selection, projection (c) join, union (d) rename, division
**Answer: (a).**

**Q26.** The only mandatory clauses of a SELECT query (standard form):
(a) SELECT and FROM (b) SELECT, FROM, WHERE (c) SELECT only (d) FROM and WHERE
**Answer: (a).**
