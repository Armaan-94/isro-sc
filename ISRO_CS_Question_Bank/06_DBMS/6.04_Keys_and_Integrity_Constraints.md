# 6.4 Keys and Integrity Constraints

**Notes:** [04 Keys and Integrity Constraints](../../DBMS_ISRO_Notes/04_Keys_and_Integrity_Constraints.md)

> 22 questions. Finding candidate keys: attributes that never appear on any right-hand side must be in every key; start from them and add attributes until the closure covers R.

---

**Q1.** Super key vs candidate key:
(a) identical (b) every candidate key is a super key; a super key need not be minimal (c) every super key is a candidate key (d) at most one super key
**Answer: (b).**

**Q2.** A UNIQUE NOT NULL column not chosen as primary key is a:
(a) foreign key (b) alternate key (c) secondary key (d) composite key
**Answer: (b).**

**Q3.** Entity integrity requires:
(a) FKs reference existing rows (b) primary key attributes are never NULL (c) atomic values (d) every table has an FK
**Answer: (b).**

**Q4.** R(W, X, Y, Z), F = {X→W, WZ→XY, Y→WXZ}. A candidate key?
(a) {X} (b) {W} (c) {Y} (d) {Z}
**Answer: (c).** Y⁺ = WXYZ.

**Q5.** ON DELETE SET NULL means:
(a) delete rejected (b) children deleted too (c) children keep their rows, FK set to NULL (d) nothing
**Answer: (c).**

**Q6.** RESTRICT / NO ACTION:
(a) allow deletion (b) block deleting a referenced parent while children exist (c) set NULL (d) cascade
**Answer: (b).**

**Q7.** A prime attribute is:
(a) in the primary key only (b) in at least one candidate key (c) never in an FK (d) at most one per relation
**Answer: (b).**

**Q8.** T(A, B), B references A, ON DELETE CASCADE. Rows (1, 2), (2, 3), (3, 5), (5, 9), (6, 2). Delete the row with A = 3. Rows left?
(a) 4 (b) 3 (c) 1 (d) 0
**Answer: (c).** (3, 5) goes; then (2, 3) (B = 3); then (1, 2) and (6, 2) (B = 2). Only (5, 9) remains.

**Q9.** R(A, B, C, D) with candidate key A only. Number of super keys?
(a) 4 (b) 8 (c) 15 (d) 16
**Answer: (b).** Any superset of A: 2³.

**Q10.** R(A, B, C, D) with candidate keys A and B. Super keys?
(a) 8 (b) 12 (c) 16 (d) 14
**Answer: (b).** 8 + 8 − 4 (sets containing both).

**Q11.** R(A, B, C, D) with candidate keys AB and CD. Super keys?
(a) 7 (b) 8 (c) 6 (d) 4
**Answer: (a).** 4 supersets of AB + 4 of CD − 1 (ABCD).

**Q12.** R(A₁, ..., Aₙ) with candidate key A₁ only. Super keys?
(a) 2ⁿ (b) 2ⁿ⁻¹ (c) n (d) 2ⁿ − 1
**Answer: (b).**

**Q13.** R(A, B, C, D, E), F = {A→B, BC→E, ED→A}. Candidate keys?
(a) ACD only (b) ACD, BCD, CDE (c) CD (d) ABCDE
**Answer: (b).** C and D never appear on a right side, so every key contains CD; adding A, B or E each completes the closure.

**Q14.** In Q13, how many prime attributes?
(a) 2 (b) 3 (c) 4 (d) 5
**Answer: (d).** A, B, C, D, E all appear in some key.

**Q15.** R(A, B, C, D), F = {AB→C, C→D, D→A}. Candidate keys?
(a) AB only (b) AB, BC, BD (c) B only (d) AB, CD
**Answer: (b).** B never appears on a right side; B with any of A, C, D reaches everything.

**Q16.** A foreign key value may be:
(a) NULL (unless declared NOT NULL) or a value present in the referenced key (b) any value (c) never NULL (d) only the PK of its own table
**Answer: (a).**

**Q17.** A foreign key can reference:
(a) only another table (b) its own table too (self-referencing) (c) only a non-key column (d) only views
**Answer: (b).**

**Q18.** A table can have how many primary keys?
(a) one (b) two (c) many (d) none required
**Answer: (a).** But many candidate keys.

**Q19.** Inserting a child row whose FK value doesn't exist in the parent violates:
(a) entity integrity (b) referential integrity (c) domain constraint (d) key constraint
**Answer: (b).**

**Q20.** Inserting a value "abc" into an INT column violates:
(a) domain constraint (b) referential integrity (c) entity integrity (d) none
**Answer: (a).**

**Q21.** A key made of two or more attributes:
(a) composite key (b) alternate key (c) foreign key (d) surrogate key
**Answer: (a).**

**Q22.** A system-generated meaningless identifier (e.g., auto-increment ID) is a:
(a) natural key (b) surrogate key (c) foreign key (d) secondary key
**Answer: (b).**
