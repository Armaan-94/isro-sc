# 6.1 DBMS Basics, Architecture and Languages

**Notes:** [01 DBMS Basics Architecture Languages](../../DBMS_ISRO_Notes/01_DBMS_Basics_Architecture_Languages.md)

> 22 questions.

---

**Q1.** NOT a problem of file-based systems:
(a) redundancy (b) access difficulty (c) built-in concurrency control (d) data isolation
**Answer: (c).** File systems lack it; DBMSs provide it.

**Q2.** Adding an index without changing the conceptual schema or applications is:
(a) logical data independence (b) physical data independence (c) view change (d) schema-instance separation
**Answer: (b).**

**Q3.** The instance of a database is:
(a) its design (b) the data at a given moment (c) DBA rights (d) the query language
**Answer: (b).**

**Q4.** GRANT and REVOKE belong to:
(a) DDL (b) DML (c) DCL (d) TCL
**Answer: (c).**

**Q5.** OLAP is characterised by:
(a) small DB, short queries (b) large historical data, complex queries, batch updates (c) daily transactions (d) full normalisation
**Answer: (b).**

**Q6.** Network vs hierarchical model:
(a) one parent only (b) a child can have multiple parents (c) no parent-child links (d) objects only
**Answer: (b).**

**Q7.** In 3-tier architecture, business logic sits in:
(a) the client (b) the database (c) a middle application server (d) split randomly
**Answer: (c).**

**Q8.** Causes an implicit commit:
(a) UPDATE (b) DELETE (c) CREATE TABLE (d) INSERT
**Answer: (c).** DDL.

**Q9.** TRUNCATE is classified as:
(a) DML (b) DDL (c) DCL (d) TCL
**Answer: (b).** It can't usually be rolled back; DELETE (DML) can.

**Q10.** SAVEPOINT belongs to:
(a) DDL (b) DML (c) DCL (d) TCL
**Answer: (d).** With COMMIT and ROLLBACK.

**Q11.** Three-schema levels from lowest to highest:
(a) physical, conceptual, external (b) external, conceptual, physical (c) conceptual, physical, view (d) view, physical, logical
**Answer: (a).**

**Q12.** Harder to achieve:
(a) physical data independence (b) logical data independence (c) both equal (d) neither exists
**Answer: (b).** Applications depend more on the logical structure.

**Q13.** End users interact with the:
(a) internal level (b) conceptual level (c) external (view) level (d) disk directly
**Answer: (c).**

**Q14.** A schema is to an instance as:
(a) a variable's type is to its current value (b) a value is to a type (c) a file is to a folder (d) RAM is to disk
**Answer: (a).**

**Q15.** Metadata (data about the database structure) is stored in the:
(a) data dictionary / system catalog (b) log file (c) buffer (d) index only
**Answer: (a).**

**Q16.** SQL is:
(a) procedural (b) non-procedural (declarative): you state what, not how (c) a host language (d) assembly
**Answer: (b).**

**Q17.** In 2-tier client-server, application logic is mostly in:
(a) the client (b) a middle tier (c) the network (d) the disk
**Answer: (a).**

**Q18.** Which is NOT a DBA function?
(a) schema definition (b) granting authorisation (c) writing end-user application UI code (d) backups
**Answer: (c).**

**Q19.** OLTP systems are typically:
(a) normalised, with many short transactions (b) denormalised (c) historical (d) read-only
**Answer: (a).**

**Q20.** The most widely used data model:
(a) hierarchical (b) network (c) relational (d) object-oriented
**Answer: (c).**

**Q21.** JDBC and ODBC are:
(a) APIs for applications to access databases (b) query optimisers (c) storage engines (d) DDL commands
**Answer: (a).**

**Q22.** A crash mid-update leaving data half-changed is a problem of:
(a) atomicity (b) isolation (c) redundancy (d) security
**Answer: (a).** Simultaneous-access corruption is a concurrency problem.
