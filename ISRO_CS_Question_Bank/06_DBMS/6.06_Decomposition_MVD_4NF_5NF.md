# 6.6 Decomposition, Multivalued Dependency, 4NF and 5NF

> 22 questions. Lossless test for R → R₁, R₂: the common attributes must be a key of R₁ or of R₂.

---

**Q1.** Lossless requires the common attributes to:
(a) be non-empty only (b) be a key of R (c) determine all of R₁ or all of R₂ (d) be R₁'s PK
**Answer: (c).**

**Q2.** "BCNF decomposition is always lossless and dependency-preserving":
(a) true (b) false: always lossless, not always dependency-preserving (c) DP, not lossless (d) false both
**Answer: (b).**

**Q3.** MVD X →→ Y is trivial when:
(a) both empty (b) Y ⊆ X or X ∪ Y = R (c) X is a key (d) Y prime
**Answer: (b).**

**Q4.** Can a BCNF relation violate 4NF?
(a) no (b) yes, through independent multivalued facts (c) 4NF is weaker (d) only with composite keys
**Answer: (b).**

**Q5.** The Supplier–Part–Project example motivates:
(a) 2NF (b) BCNF (c) 4NF (d) 5NF
**Answer: (d).**

**Q6.** R(A, B, C), F = {A→B, B→C, C→A} into R₁(A, B), R₂(B, C). Lossless?
(a) yes: B → A, so B is a key of R₁ (b) no (c) empty intersection (d) can't say
**Answer: (a).**

**Q7.** Dependency preservation is sometimes sacrificed because:
(a) impossible (b) checking an FD that spans tables would need a join (c) 1NF only (d) MVDs
**Answer: (b).**

**Q8.** R(A, B, C, D), F = {A→B, C→D}; R₁(A, B), R₂(C, D). Lossless?
(a) yes (b) no: no common attribute (c) only if A→C (d) always
**Answer: (b).**

**Q9.** R(A, B, C), F = {A→B}; R₁(A, B), R₂(A, C). Lossless?
(a) yes: A→B makes A a key of R₁ (b) no (c) can't say (d) only if B→C
**Answer: (a).**

**Q10.** R(A, B, C), F = {A→B}; R₁(A, B), R₂(B, C). Lossless?
(a) yes (b) no: B determines neither side (c) yes, B is common (d) always
**Answer: (b).**

**Q11.** R(A, B, C), F = {A→B, B→C}; R₁(A, B), R₂(A, C). Lossless and dependency-preserving?
(a) both (b) lossless, not DP (B→C is lost) (c) DP, not lossless (d) neither
**Answer: (b).**

**Q12.** Same R and F; R₁(A, B), R₂(B, C):
(a) both lossless and DP (b) lossless only (c) DP only (d) neither
**Answer: (a).** B→C makes B a key of R₂, and each FD lives in one table.

**Q13.** Decomposition algorithm that guarantees both lossless join and dependency preservation:
(a) BCNF decomposition (b) 3NF synthesis (c) 4NF decomposition (d) 1NF
**Answer: (b).**

**Q14.** Every FD X→Y also implies:
(a) the MVD X →→ Y (b) Y→X (c) nothing (d) a JD only
**Answer: (a).** Not the reverse.

**Q15.** 4NF requires:
(a) BCNF and no non-trivial MVDs (b) 3NF only (c) no FDs (d) 5NF
**Answer: (a).**

**Q16.** Student(S, Club, Phone) where clubs and phones are independent. Fix?
(a) (S, Club) and (S, Phone) (b) (Club, Phone) (c) keep as is (d) (S) and (Club, Phone)
**Answer: (a).**

**Q17.** A lossy decomposition, when rejoined, produces:
(a) fewer tuples (b) extra (spurious) tuples (c) the same tuples (d) no tuples
**Answer: (b).**

**Q18.** 5NF deals with:
(a) join dependencies (b) partial dependencies (c) transitive dependencies (d) MVDs only
**Answer: (a).** Also called project-join normal form.

**Q19.** Decomposition must always be:
(a) lossless (b) dependency-preserving (c) both always achievable in BCNF (d) neither
**Answer: (a).** Losing information is never acceptable.

**Q20.** The union of attributes of R₁ and R₂ must:
(a) equal the attributes of R (b) be a key (c) be empty (d) exclude keys
**Answer: (a).**

**Q21.** R(A, B, C, D), F = {AB→C, C→D}; R₁(A, B, C), R₂(C, D). Lossless and DP?
(a) both (b) lossless only (c) DP only (d) neither
**Answer: (a).** C is a key of R₂; each FD lies in one table.

**Q22.** R(A, B, C) with candidate key AB and F = {AB→C, C→B}, decomposed for BCNF into (C, B) and (A, C). Which FD is lost?
(a) C→B (b) AB→C (c) none (d) both
**Answer: (b).** No table contains A, B and C together.
