# 6.5 Normalization (1NF to BCNF)

> 24 questions. Test for every non-trivial X→Y: BCNF needs X to be a super key; 3NF also accepts Y prime; 2NF fails only if a non-prime attribute depends on part of a composite key.

---

**Q1.** A single-attribute candidate key means R can never violate:
(a) 3NF (b) BCNF (c) 2NF (d) 1NF
**Answer: (c).**

**Q2.** R(A, B, C, D), F = {A→BC, C→D}. Highest normal form?
(a) 1NF (b) 2NF (c) 3NF (d) BCNF
**Answer: (b).** Key A; C→D is transitive.

**Q3.** R(A, B, C), F = {AB→C, C→A}:
(a) BCNF (b) 3NF, not BCNF (c) 2NF, not 3NF (d) not 1NF
**Answer: (b).** Keys AB, BC; all attributes prime; C is not a super key.

**Q4.** 3NF plus which condition guarantees BCNF?
(a) more than 3 attributes (b) all candidate keys are single attributes (c) no FKs (d) 5NF
**Answer: (b).**

**Q5.** Any two-attribute relation is in:
(a) 1NF only (b) 2NF only (c) 3NF only (d) BCNF
**Answer: (d).**

**Q6.** R(A, B, C, D, E, F, G, H), F = {CH→G, A→BC, B→CFH, E→A, F→EG}. Highest normal form?
(a) 1NF (b) 2NF (c) 3NF (d) BCNF
**Answer: (a).** D is in no FD; key AD; A→BC is a partial dependency.

**Q7.** No non-trivial FDs at all. R is:
(a) unnormalised (b) in BCNF (c) 1NF only (d) 2NF only
**Answer: (b).**

**Q8.** Direct 3NF test:
(a) no composite keys (b) every LHS is a super key (c) every LHS is a super key or every RHS attribute is prime (d) every attribute is a key
**Answer: (c).**

**Q9.** R(A, B, C, D), F = {AB→C, C→D}. Highest normal form?
(a) 1NF (b) 2NF (c) 3NF (d) BCNF
**Answer: (b).** Key AB; no attribute depends on A or B alone; C→D is transitive.

**Q10.** R(A, B, C, D), F = {AB→CD, B→C}. Highest normal form?
(a) 1NF (b) 2NF (c) 3NF (d) BCNF
**Answer: (a).** Non-prime C depends on part of the key AB.

**Q11.** R(A, B, C), F = {A→B, B→A}. Highest normal form?
(a) 2NF (b) 3NF (c) BCNF (d) 1NF
**Answer: (b).** Keys AC and BC; all attributes prime; A is not a super key.

**Q12.** R(A, B, C, D), F = {A→B, B→C, C→D, D→A}. Highest normal form?
(a) 2NF (b) 3NF (c) BCNF (d) 1NF
**Answer: (c).** Every single attribute is a key.

**Q13.** R(A, B, C, D, E), F = {A→B, BC→E, ED→A}. Highest normal form?
(a) 2NF (b) 3NF (c) BCNF (d) 1NF
**Answer: (b).** Keys ACD, BCD, CDE: every attribute is prime, but A→B has a non-key left side.

**Q14.** A table with a column holding several phone numbers in one cell violates:
(a) 1NF (b) 2NF (c) 3NF (d) BCNF
**Answer: (a).** Values must be atomic.

**Q15.** Partial dependency:
(a) a non-prime attribute depends on a proper subset of a candidate key (b) a non-prime depends on another non-prime (c) a key depends on a non-key (d) a trivial FD
**Answer: (a).** (b) is a transitive dependency.

**Q16.** If every attribute of R is prime, R is at least in:
(a) 1NF (b) 2NF (c) 3NF (d) BCNF
**Answer: (c).**

**Q17.** Normalisation primarily removes:
(a) redundancy and update anomalies (b) indexes (c) keys (d) queries
**Answer: (a).**

**Q18.** R(Student, Course, Instructor), each instructor teaches one course; F = {(Student, Course)→Instructor, Instructor→Course}. Highest normal form?
(a) 2NF (b) 3NF (c) BCNF (d) 1NF
**Answer: (b).** Keys (Student, Course) and (Student, Instructor). Instructor→Course: Course is prime, but Instructor is not a super key.

**Q19.** BCNF vs 3NF:
(a) BCNF is stricter (b) 3NF is stricter (c) identical (d) unrelated
**Answer: (a).**

**Q20.** R(A, B, C), F = {A→B, B→C}. Highest normal form?
(a) 1NF (b) 2NF (c) 3NF (d) BCNF
**Answer: (b).** Key A; B→C is transitive.

**Q21.** Order of normal forms by strictness:
(a) 1NF ⊃ 2NF ⊃ 3NF ⊃ BCNF ⊃ 4NF ⊃ 5NF (as sets of relations) (b) reverse (c) BCNF weakest (d) unordered
**Answer: (a).** Each higher form is a subset of the lower one.

**Q22.** R(A, B, C, D), F = {A→B, C→D}. Key and normal form?
(a) AC; 1NF (b) A; 2NF (c) AC; 3NF (d) ABCD; BCNF
**Answer: (a).** A→B is partial on key AC.

**Q23.** Denormalisation is sometimes done to:
(a) speed up read-heavy queries by avoiding joins (b) remove redundancy (c) enforce keys (d) reach BCNF
**Answer: (a).** Common in data warehouses.

**Q24.** Transitive dependency A→B→C, where A is the key and B, C non-prime, violates:
(a) 2NF (b) 3NF (c) 1NF (d) nothing
**Answer: (b).**
