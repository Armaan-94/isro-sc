# 6.3 Relational Model and Functional Dependencies

> 24 questions. Closure X⁺: start with X, keep adding right-hand sides of FDs whose left sides are covered.

---

**Q1.** R(A, B, C, D, E) has 5 columns. This number is the:
(a) cardinality (b) domain (c) degree (arity) (d) instance
**Answer: (c).** Rows = cardinality.

**Q2.** Deleting the last employee of a branch also loses the branch's details. This is a:
(a) insertion anomaly (b) deletion anomaly (c) update anomaly (d) referential violation
**Answer: (b).**

**Q3.** R(A, B, C, D), F = {A→B, B→C, AB→D}. A⁺?
(a) AB (b) ABC (c) ABCD (d) A
**Answer: (c).**

**Q4.** Armstrong's three basic axioms:
(a) union, decomposition, composition (b) reflexivity, augmentation, transitivity (c) pseudotransitivity, union, reflexivity (d) augmentation, composition, decomposition
**Answer: (b).**

**Q5.** An FD that holds on one sample instance:
(a) is proven (b) may be a coincidence (c) is invalid (d) is a key
**Answer: (b).** An instance can only disprove an FD.

**Q6.** Minimal cover of F = {AC→BD, A→C, B→C, D→C}:
(a) {A→B, A→C, B→C, A→D} (b) {A→B, A→D, A→C, B→D} (c) {A→B, A→D, A→C, B→C} (d) {A→B, A→D, D→C, B→C}
**Answer: (d).** C is extraneous in AC; A→C is redundant via A→B→C.

**Q7.** X⁺ = R and no proper subset has this property. X is a:
(a) foreign key (b) candidate key (c) trivial FD (d) discriminator
**Answer: (b).**

**Q8.** F₁ and F₂ are equivalent when:
(a) same count (b) F₁⁺ = F₂⁺ (c) F₁ ⊆ F₂ (d) different relations
**Answer: (b).**

**Q9.** R(A, B, C, D, E), F = {A→B, B→C, C→D, D→E}. A⁺?
(a) AB (b) ABC (c) ABCDE (d) A
**Answer: (c).**

**Q10.** R(A, B, C, D, E), F = {AB→C, C→D, D→E}. C⁺?
(a) C (b) CD (c) CDE (d) ABCDE
**Answer: (c).**

**Q11.** F = {A→B, B→C}. Is A→C implied?
(a) yes, by transitivity (b) no (c) only if C→A (d) can't say
**Answer: (a).**

**Q12.** AB→A is:
(a) trivial (b) non-trivial (c) invalid (d) a key
**Answer: (a).** Right side ⊆ left side.

**Q13.** Tuples (A = 1, B = x) and (A = 1, B = y) exist. Then:
(a) A→B holds (b) A→B is violated (c) B→A is violated (d) nothing
**Answer: (b).**

**Q14.** F₁ = {A→B, B→C}, F₂ = {A→B, B→C, A→C}. They are:
(a) equivalent (b) not equivalent (c) F₂ weaker (d) unrelated
**Answer: (a).** A→C is implied by F₁.

**Q15.** A table with 5 columns and 10 rows has degree and cardinality:
(a) 5 and 10 (b) 10 and 5 (c) 50 and 1 (d) 5 and 5
**Answer: (a).**

**Q16.** Pseudotransitivity: X→Y and WY→Z imply:
(a) WX→Z (b) X→Z (c) W→Z (d) Y→Z
**Answer: (a).**

**Q17.** X→Y and X→Z imply X→YZ by:
(a) union (b) decomposition (c) augmentation (d) reflexivity
**Answer: (a).**

**Q18.** X→Y implies XZ→YZ by:
(a) augmentation (b) transitivity (c) union (d) reflexivity
**Answer: (a).**

**Q19.** Armstrong's axioms are:
(a) sound and complete (b) sound only (c) complete only (d) neither
**Answer: (a).**

**Q20.** Can't add a new course until a student enrols in it. This is a:
(a) deletion anomaly (b) insertion anomaly (c) update anomaly (d) join anomaly
**Answer: (b).**

**Q21.** A department's phone stored in 100 employee rows must be changed everywhere. This is a:
(a) update (modification) anomaly (b) insertion anomaly (c) deletion anomaly (d) none
**Answer: (a).**

**Q22.** R(A, B, C, D), F = {AB→C, C→D, D→A}. Is B a key?
(a) yes (b) no: B⁺ = B (c) only with C (d) can't say
**Answer: (b).**

**Q23.** In the relational model, row order:
(a) matters (b) doesn't matter (c) must be sorted (d) defines keys
**Answer: (b).** Same for column order.

**Q24.** In a minimal cover, every right-hand side is:
(a) a single attribute (b) a key (c) empty (d) the whole relation
**Answer: (a).**
