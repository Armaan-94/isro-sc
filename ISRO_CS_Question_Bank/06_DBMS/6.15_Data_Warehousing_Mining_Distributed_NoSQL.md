# 6.15 Data Warehousing, Data Mining, Distributed Databases and NoSQL

> 24 questions.

---

**Q1.** NOT an Inmon property of a data warehouse:
(a) subject-oriented (b) volatile (c) integrated (d) time-variant
**Answer: (b).** It is non-volatile.

**Q2.** Snowflake vs star schema:
(a) no fact table (b) snowflake normalises dimensions (more joins) (c) star slower (d) identical
**Answer: (b).**

**Q3.** City level → country level:
(a) drill-down (b) roll-up (c) dice (d) pivot
**Answer: (b).**

**Q4.** Classification vs clustering:
(a) classification unsupervised (b) classification uses predefined labels; clustering finds groups without labels (c) same (d) clustering needs labels
**Answer: (b).**

**Q5.** Support{A, B} = 40%, support{A} = 50%. Confidence(A → B)?
(a) 40% (b) 50% (c) 80% (d) 90%
**Answer: (c).**

**Q6.** Apriori relies on:
(a) supersets of frequent sets are frequent (b) subsets of frequent sets are frequent (c) sampling (d) sorting
**Answer: (b).**

**Q7.** Rows split by region, all columns kept:
(a) vertical fragmentation (b) horizontal fragmentation (c) replication (d) star schema
**Answer: (b).**

**Q8.** With partitions inevitable, CAP trades off:
(a) C and P (b) A and P (c) C and A (d) nothing
**Answer: (c).**

**Q9.** Best for relationship-heavy data (social networks):
(a) key-value (b) document (c) column-family (d) graph database
**Answer: (d).**

**Q10.** 100 transactions; 40 contain milk; 20 contain both milk and bread. Support and confidence of milk → bread?
(a) 20%, 50% (b) 40%, 50% (c) 20%, 20% (d) 50%, 20%
**Answer: (a).**

**Q11.** ETL stands for:
(a) extract, transform, load (b) enter, test, launch (c) evaluate, track, log (d) export, transfer, link
**Answer: (a).**

**Q12.** Fixing one dimension to a single value:
(a) slice (b) dice (c) roll-up (d) pivot
**Answer: (a).** Dice filters on two or more dimensions.

**Q13.** Year → quarter → month:
(a) roll-up (b) drill-down (c) slice (d) pivot
**Answer: (b).**

**Q14.** k-means clustering requires:
(a) the number of clusters k in advance (b) class labels (c) a dendrogram (d) no parameters
**Answer: (a).** Hierarchical clustering doesn't need k.

**Q15.** In KDD, data mining comes:
(a) first (b) after cleaning, integration, selection and transformation (c) last (d) before cleaning
**Answer: (b).** Followed by pattern evaluation and knowledge presentation.

**Q16.** BASE stands for:
(a) basically available, soft state, eventual consistency (b) basic, atomic, strict, exact (c) batch, async, stable, eventual (d) none
**Answer: (a).**

**Q17.** MongoDB is a:
(a) key-value store (b) document store (c) graph database (d) column store
**Answer: (b).** Redis: key-value; Cassandra/HBase: column-family; Neo4j: graph.

**Q18.** Column-family stores excel at:
(a) aggregate queries over columns (b) graph traversal (c) row-by-row OLTP updates (d) joins
**Answer: (a).**

**Q19.** Vertical fragmentation requires each fragment to include:
(a) the primary key, for lossless rejoining (b) all rows of one region (c) no keys (d) only numeric columns
**Answer: (a).**

**Q20.** The star schema's central table is the:
(a) fact table (b) dimension table (c) lookup table (d) log table
**Answer: (a).**

**Q21.** A data mart is:
(a) a subject- or department-specific subset of a warehouse (b) an OLTP database (c) a NoSQL store (d) an index
**Answer: (a).**

**Q22.** Multiple fact tables sharing dimension tables form a:
(a) star schema (b) snowflake schema (c) fact constellation (galaxy) schema (d) flat file
**Answer: (c).**

**Q23.** Location transparency means:
(a) users don't need to know where data is stored (b) data is public (c) all sites identical (d) no network
**Answer: (a).**

**Q24.** Outlier analysis finds:
(a) data objects that differ strongly from the rest (b) frequent itemsets (c) clusters (d) trends
**Answer: (a).**
