# 6.2 ER Modeling

> 24 questions. Minimum tables: one per strong and weak entity, one per M:N or n-ary relationship, one per multivalued attribute. 1:1 and 1:N relationships fold into an existing table as a foreign key.

---

**Q1.** Primary key of a weak entity:
(a) its discriminator only (b) the owner's key only (c) owner's key + discriminator (d) none
**Answer: (c).**

**Q2.** Total participation means:
(a) max cardinality 1 (b) min cardinality 0 (c) min cardinality ≥ 1 (d) M:N
**Answer: (c).**

**Q3.** An M:N relationship becomes:
(a) an FK on either side (b) a new table keyed by both entities' keys (c) an FK on the many side (d) a merged table
**Answer: (b).**

**Q4.** Two 1:N relationships fanning out from one entity hide which staff belong to which department. This is a:
(a) chasm trap (b) fan trap (c) anomaly (d) weak entity problem
**Answer: (b).**

**Q5.** A chasm trap is fixed by:
(a) a discriminator (b) a direct relationship between the two entities (c) making strong (d) removing the third entity
**Answer: (b).**

**Q6.** Multivalued attribute "phones" becomes:
(a) comma-separated column (b) a separate table keyed by (owner key, phone) (c) dropped (d) one table per phone
**Answer: (b).**

**Q7.** Binary 1:1, one side total participation. Put the foreign key:
(a) anywhere (b) on the total-participation side (c) in a new table (d) nowhere
**Answer: (b).** No NULL foreign keys.

**Q8.** A ternary relationship becomes:
(a) three binary relationships (b) one table keyed by all three entities' keys (c) ignored (d) a weak entity
**Answer: (b).**

**Q9.** ER diagrams don't show individual entities because:
(a) they don't exist (b) ER models the schema (entity sets), not instances (c) relational only (d) discriminator needed
**Answer: (b).**

**Q10.** Strong entities E1, E2 with an M:N relationship. Minimum tables?
(a) 1 (b) 2 (c) 3 (d) 4
**Answer: (c).**

**Q11.** Same, but the relationship is 1:N. Minimum tables?
(a) 1 (b) 2 (c) 3 (d) 4
**Answer: (b).**

**Q12.** Same, but 1:1 with total participation on both sides. Minimum tables?
(a) 1 (b) 2 (c) 3 (d) 0
**Answer: (a).** Both can be merged into one table.

**Q13.** Strong A and B; weak C owned by A; M:N between A and B; B has one multivalued attribute. Minimum tables?
(a) 3 (b) 4 (c) 5 (d) 6
**Answer: (c).** A, B, C, A-B relationship, B's multivalued attribute.

**Q14.** Symbol for a weak entity set:
(a) double rectangle (b) double ellipse (c) dashed ellipse (d) diamond
**Answer: (a).** Identifying relationship: double diamond.

**Q15.** Symbol for a multivalued attribute:
(a) dashed ellipse (b) double ellipse (c) underlined ellipse (d) rectangle
**Answer: (b).** Derived attribute: dashed ellipse.

**Q16.** Age computed from date of birth is a:
(a) stored attribute (b) derived attribute (c) multivalued attribute (d) key
**Answer: (b).**

**Q17.** Name split into first and last is a:
(a) composite attribute (b) multivalued attribute (c) derived attribute (d) weak entity
**Answer: (a).**

**Q18.** A unary (recursive) relationship such as "employee supervises employee" is implemented by:
(a) a self-referencing foreign key in the same table (1:N case) (b) a new database (c) a weak entity (d) nothing
**Answer: (a).** An M:N recursive relationship would need a new table.

**Q19.** The identifying relationship of a weak entity is always:
(a) M:N (b) many-to-one from weak to owner, with total participation of the weak entity (c) 1:1 partial (d) unary
**Answer: (b).**

**Q20.** Degree of a relationship = number of:
(a) attributes (b) participating entity sets (c) tuples (d) keys
**Answer: (b).**

**Q21.** An attribute of a relationship (e.g., enrollment date of Student–Course) is called:
(a) descriptive attribute (b) key (c) derived (d) composite
**Answer: (a).**

**Q22.** Generalisation is:
(a) bottom-up: combining entity sets with common features into a higher-level set (b) top-down specialisation (c) aggregation (d) normalisation
**Answer: (a).** Specialisation is top-down.

**Q23.** Aggregation in ER is used to:
(a) treat a relationship as an entity so it can take part in another relationship (b) sum values (c) normalise (d) index
**Answer: (a).**

**Q24.** The ER model was proposed by:
(a) Codd (b) Peter Chen (c) Boyce (d) Armstrong
**Answer: (b).** Codd proposed the relational model.
