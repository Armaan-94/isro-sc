# 1.5 CPU Organization, Instruction Cycle and Addressing Modes

> 30 questions, including instruction-format and performance numericals.

---

**Q1.** Which register holds the address of the next instruction?
(a) IR (b) PC (c) MAR (d) AC
**Answer: (b).** IR holds the current instruction.

**Q2.** Order of the basic instruction cycle:
(a) execute → fetch → decode (b) fetch → execute → decode (c) fetch → decode → execute (d) decode → fetch → execute
**Answer: (c).**

**Q3.** In immediate addressing the operand is:
(a) at an address in a register (b) part of the instruction (c) reached via a pointer in memory (d) always in the accumulator
**Answer: (b).**

**Q4.** Compared with direct addressing, indirect addressing needs:
(a) fewer memory accesses (b) one extra memory access (c) none (d) the same
**Answer: (b).** First fetch the pointer, then the operand.

**Q5.** Defining feature of RISC:
(a) large variable-length instruction set (b) load/store architecture (c) multi-cycle instructions (d) heavy microcode
**Answer: (b).** ALU operations work only on registers.

**Q6.** Indexed addressing effective address:
(a) PC + offset (b) base (in instruction) + index register (c) register contents (d) address stored at an address
**Answer: (b).** Ideal for arrays.

**Q7.** Relative addressing uses:
(a) stack pointer (b) PC + offset (c) two indirections (d) a fixed address
**Answer: (b).** Supports position-independent branches.

**Q8.** Register-indirect addressing: memory accesses to get the operand (excluding instruction fetch)?
(a) 0 (b) 1 (c) 2 (d) can't say
**Answer: (b).** The address is already in a register.

**Q9.** True of CISC:
(a) fixed-length instructions (b) one cycle per instruction (c) many instructions operate directly on memory (d) fewer addressing modes than RISC
**Answer: (c).**

**Q10.** The MBR/MDR holds:
(a) next instruction's address (b) data moving between CPU and memory (c) the opcode only (d) condition flags
**Answer: (b).** MAR holds the address.

**Q11.** A 32-bit instruction has a 6-bit opcode and two 5-bit register fields. Bits left for an immediate operand?
(a) 14 (b) 16 (c) 18 (d) 21
**Answer: (b).** 32 − 6 − 5 − 5.

**Q12.** 16-bit instructions, 6-bit address fields. 15 two-address instructions exist. Maximum one-address instructions (expanding opcode)?
(a) 16 (b) 32 (c) 64 (d) 128
**Answer: (c).** Two-address leaves 4 opcode bits (16 patterns); 1 unused pattern × 2⁶ = 64.

**Q13.** Auto-increment/auto-decrement modes are most useful for:
(a) constants (b) stepping through arrays and stacks (c) branching (d) I/O
**Answer: (b).**

**Q14.** Base-register addressing mainly supports:
(a) program relocation (b) immediate constants (c) interrupts (d) pipelining
**Answer: (a).**

**Q15.** Zero-address instructions are used in:
(a) register machines (b) stack machines (c) accumulator machines (d) RISC only
**Answer: (b).** Operands are implicitly on top of the stack.

**Q16.** Hardwired vs microprogrammed control:
(a) hardwired is faster, microprogrammed is more flexible (b) the reverse (c) both equally fast (d) hardwired is easier to modify
**Answer: (a).**

**Q17.** Horizontal microprogramming has:
(a) wide control words, little encoding, more parallelism (b) narrow, highly encoded words (c) no control memory (d) only one micro-op per word
**Answer: (a).** Vertical microcode is narrow and encoded, needing decoders.

**Q18.** Instruction mix: 40% ALU (1 cycle), 30% load (3), 20% store (2), 10% branch (2). CPI?
(a) 1.7 (b) 1.9 (c) 2.0 (d) 2.1
**Answer: (b).** 0.4 + 0.9 + 0.4 + 0.2.

**Q19.** 10⁹ instructions, CPI 2, clock 2 GHz. Execution time?
(a) 0.5 s (b) 1 s (c) 2 s (d) 4 s
**Answer: (b).** IC × CPI / f.

**Q20.** Clock 2 GHz, CPI 2. MIPS rating?
(a) 500 (b) 1000 (c) 2000 (d) 4000
**Answer: (b).** f/(CPI × 10⁶).

**Q21.** 40% of execution time is sped up 4×. Overall speedup (Amdahl's law)?
(a) 1.43 (b) 1.6 (c) 2.5 (d) 4
**Answer: (a).** 1/(0.6 + 0.4/4) = 1/0.7.

**Q22.** Maximum speedup if 20% of a program is strictly sequential?
(a) 2 (b) 4 (c) 5 (d) unlimited
**Answer: (c).** 1/0.2.

**Q23.** Little-endian storage of 0x12345678: byte at the lowest address?
(a) 0x12 (b) 0x34 (c) 0x56 (d) 0x78
**Answer: (d).** Little-endian puts the least significant byte first.

**Q24.** Indexed mode: base 2000, index register 50. Effective address?
(a) 1950 (b) 2050 (c) 2000 (d) 100000
**Answer: (b).**

**Q25.** PC-relative branch: updated PC 1000, offset −20. Target?
(a) 980 (b) 1020 (c) 1000 (d) 20
**Answer: (a).**

**Q26.** Which register is not visible to the programmer?
(a) accumulator (b) general-purpose register (c) MAR (d) stack pointer
**Answer: (c).**

**Q27.** The Von Neumann bottleneck arises because:
(a) instructions and data share one memory/bus (b) the ALU is slow (c) there are too few registers (d) of caching
**Answer: (a).** Harvard architecture separates instruction and data memories.

**Q28.** A 5-bit register field can address how many registers?
(a) 5 (b) 16 (c) 32 (d) 64
**Answer: (c).**

**Q29.** Which flag records that a signed result went out of range?
(a) carry (b) zero (c) overflow (d) parity
**Answer: (c).** Carry is for unsigned out-of-range.

**Q30.** At the end of each instruction cycle, the CPU:
(a) flushes the cache (b) checks for pending interrupts (c) resets the PC (d) reloads the OS
**Answer: (b).**
