# 1.4 Sequential Circuits: Latches, Flip-Flops, Counters and Registers

> 30 questions.

---

**Q1.** The key difference between a latch and a flip-flop:
(a) latches don't store data (b) latches are level-triggered, flip-flops edge-triggered (c) the reverse (d) none
**Answer: (b).**

**Q2.** SR flip-flop with S = 1, R = 1:
(a) toggles (b) holds (c) invalid state (d) resets
**Answer: (c).**

**Q3.** JK flip-flop with J = K = 1 at the clock edge:
(a) holds (b) toggles (c) invalid (d) resets
**Answer: (b).** This is how JK fixes SR's forbidden input.

**Q4.** D flip-flop next state:
(a) Q' (b) D at the clock edge (c) undefined (d) always 0
**Answer: (b).**

**Q5.** Main drawback of a ripple (asynchronous) counter:
(a) more flip-flops (b) cumulative propagation delay (c) can't count in binary (d) can only count up
**Answer: (b).** Each stage is clocked by the previous one.

**Q6.** Minimum flip-flops for a mod-10 counter?
(a) 3 (b) 4 (c) 5 (d) 10
**Answer: (b).** ⌈log₂ 10⌉ = 4.

**Q7.** With n flip-flops, ring and Johnson counters give:
(a) n and 2n states (b) 2n and n (c) 2ⁿ each (d) n each
**Answer: (a).**

**Q8.** Serial-in, parallel-out register:
(a) SISO (b) SIPO (c) PISO (d) PIPO
**Answer: (b).**

**Q9.** A T flip-flop from a JK flip-flop:
(a) J = K = T (b) J = 1, K = 0 (c) J = 0, K = 1 (d) impossible
**Answer: (a).**

**Q10.** Minimum flip-flops for a mod-6 counter?
(a) 2 (b) 3 (c) 4 (d) 6
**Answer: (b).**

**Q11.** Characteristic equation of the JK flip-flop:
(a) Q⁺ = JQ' + K'Q (b) Q⁺ = J + K'Q (c) Q⁺ = J ⊕ K (d) Q⁺ = JK + Q
**Answer: (a).**

**Q12.** Characteristic equation of the T flip-flop:
(a) Q⁺ = T (b) Q⁺ = T ⊕ Q (c) Q⁺ = TQ (d) Q⁺ = T + Q
**Answer: (b).**

**Q13.** Characteristic equation of the SR flip-flop (with SR = 0):
(a) Q⁺ = S + R'Q (b) Q⁺ = S'R + Q (c) Q⁺ = S ⊕ R (d) Q⁺ = SR'
**Answer: (a).**

**Q14.** The race-around condition in a level-triggered JK flip-flop occurs when:
(a) J = K = 0 (b) J = K = 1 and the clock pulse is longer than the propagation delay (c) J ≠ K (d) the clock is edge-triggered
**Answer: (b).** The output toggles repeatedly within one pulse. Master-slave or edge triggering fixes it.

**Q15.** Modulus of a 4-bit binary ripple counter?
(a) 4 (b) 8 (c) 16 (d) 15
**Answer: (c).**

**Q16.** A 4-bit ripple counter with 10 ns per flip-flop. Maximum clock frequency?
(a) 100 MHz (b) 25 MHz (c) 40 MHz (d) 10 MHz
**Answer: (b).** Settling time 4 × 10 = 40 ns.

**Q17.** A synchronous counter: flip-flop delay 10 ns, gate delay 5 ns. Maximum frequency?
(a) 100 MHz (b) 66.7 MHz (c) 50 MHz (d) 25 MHz
**Answer: (b).** 1/(10 + 5) ns. Independent of the number of bits.

**Q18.** States in a 4-flip-flop Johnson counter?
(a) 4 (b) 8 (c) 16 (d) 15
**Answer: (b).**

**Q19.** Unused states in a 4-bit Johnson counter?
(a) 4 (b) 8 (c) 12 (d) 0
**Answer: (b).** 2⁴ − 8.

**Q20.** A mod-10 counter is driven by 10 kHz. Output frequency?
(a) 100 kHz (b) 1 kHz (c) 10 kHz (d) 5 kHz
**Answer: (b).** A mod-N counter divides the frequency by N.

**Q21.** An 8 MHz clock drives a ripple counter. Frequency at the third flip-flop's output?
(a) 4 MHz (b) 2 MHz (c) 1 MHz (d) 8/3 MHz
**Answer: (c).** Each stage halves it: 8 → 4 → 2 → 1.

**Q22.** Clock pulses to load 4 bits into a 4-bit SIPO register?
(a) 1 (b) 2 (c) 4 (d) 8
**Answer: (c).** One bit per clock.

**Q23.** JK excitation for Q: 0 → 1?
(a) J = 1, K = X (b) J = X, K = 1 (c) J = 0, K = X (d) J = 1, K = 1
**Answer: (a).** Either "set" (K = 0) or "toggle" (K = 1) works.

**Q24.** T excitation for Q: 1 → 0?
(a) T = 0 (b) T = 1 (c) T = X (d) impossible
**Answer: (b).**

**Q25.** SR excitation for Q: 1 → 1?
(a) S = X, R = 0 (b) S = 0, R = X (c) S = 1, R = 1 (d) S = 0, R = 1
**Answer: (a).**

**Q26.** Flip-flops needed to count from 0 to 1000?
(a) 9 (b) 10 (c) 11 (d) 1000
**Answer: (b).** 1001 states ≤ 1024.

**Q27.** In a cross-coupled NOR SR latch, the forbidden input is:
(a) S = R = 0 (b) S = 1, R = 0 (c) S = R = 1 (d) S = 0, R = 1
**Answer: (c).** For a NAND latch (active-low inputs) the forbidden input is S' = R' = 0.

**Q28.** Setup time is the minimum time the input must be stable:
(a) after the clock edge (b) before the clock edge (c) during the whole clock high (d) after power-up
**Answer: (b).** Hold time is the time after the edge.

**Q29.** States of an n-bit binary counter?
(a) n (b) 2n (c) 2ⁿ (d) n²
**Answer: (c).**

**Q30.** A sequential circuit is:
(a) combinational logic + memory (b) memory only (c) combinational only (d) a clock only
**Answer: (a).** Outputs depend on present inputs and stored state.
