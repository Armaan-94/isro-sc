# 1.3 Combinational Circuits

> 28 questions on adders, multiplexers, decoders, encoders and comparators.

---

**Q1.** A half adder differs from a full adder because it:
(a) has no carry output (b) has no carry-in (c) works only for 1-bit numbers (d) uses only NAND gates
**Answer: (b).** Half adder: 2 inputs. Full adder: 3 inputs (A, B, Cin).

**Q2.** Compared to a ripple-carry adder, a carry look-ahead adder is:
(a) slower and smaller (b) faster but uses more gates (c) identical (d) slower and larger
**Answer: (b).** It computes carries in parallel using generate/propagate logic.

**Q3.** Select lines for a 16:1 MUX?
(a) 2 (b) 4 (c) 8 (d) 16
**Answer: (b).** 2⁴ = 16.

**Q4.** A demultiplexer:
(a) selects one of many inputs (b) routes one input to one of many outputs (c) compares numbers (d) detects the highest-priority input
**Answer: (b).**

**Q5.** A 3-to-8 decoder with a valid input activates:
(a) all 8 outputs (b) exactly one output (c) three outputs (d) none without enable
**Answer: (b).**

**Q6.** A plain (non-priority) encoder gives an ambiguous output when:
(a) no input is active (b) exactly one is active (c) more than one is active (d) select lines are grounded
**Answer: (c).** That's why priority encoders exist.

**Q7.** A 2ⁿ:1 MUX can implement any function of n variables because:
(a) each data input corresponds to one minterm and can be tied to that row's output (b) it simplifies internally (c) it has more outputs than a decoder (d) it only handles 2 inputs
**Answer: (a).**

**Q8.** A 4-to-16 decoder's output stage needs:
(a) 16 AND gates, no OR (b) 4 AND, 16 OR (c) 16 OR, 4 AND (d) 8 AND, 8 OR
**Answer: (a).** Each output is one minterm of the 4 inputs.

**Q9.** Outputs of a magnitude comparator:
(a) sum, carry, borrow (b) A > B, A = B, A < B (c) enable, select, data (d) generate, propagate, kill
**Answer: (b).**

**Q10.** Worst-case delay of an n-bit ripple-carry adder grows as:
(a) log n (b) n (c) constant (d) n²
**Answer: (b).** Each stage waits for the previous carry.

**Q11.** Full adder sum and carry:
(a) A⊕B⊕C, AB + BC + CA (b) A⊕B, AB (c) ABC, A + B + C (d) A⊕B⊕C, ABC
**Answer: (a).**

**Q12.** A full adder is built from:
(a) 2 half adders and an OR gate (b) 2 half adders and an AND gate (c) 3 half adders (d) 1 half adder and an XOR
**Answer: (a).**

**Q13.** Borrow output of a half subtractor (A − B)?
(a) AB' (b) A'B (c) A⊕B (d) AB
**Answer: (b).** Borrow needed when A = 0 and B = 1.

**Q14.** Number of 2:1 MUXes needed to build an 8:1 MUX?
(a) 4 (b) 6 (c) 7 (d) 8
**Answer: (c).** A tree: 4 + 2 + 1. In general n − 1 two-input MUXes for n inputs.

**Q15.** Number of 2:1 MUXes for a 4:1 MUX?
(a) 2 (b) 3 (c) 4 (d) 1
**Answer: (b).**

**Q16.** Number of 2-to-4 decoders (with enable) to build a 4-to-16 decoder?
(a) 4 (b) 5 (c) 8 (d) 6
**Answer: (b).** 4 decoders produce the 16 outputs; 1 more decodes the two MSBs to enable them.

**Q17.** A 4:1 MUX with selects A (MSB), B and data inputs I₀ = 0, I₁ = 1, I₂ = 1, I₃ = 0 implements:
(a) AND (b) OR (c) XOR (d) XNOR
**Answer: (c).** Output is 1 for AB = 01 and 10.

**Q18.** A 16-bit ripple-carry adder; each full adder has carry delay 10 ns. Worst-case delay?
(a) 10 ns (b) 40 ns (c) 160 ns (d) 320 ns
**Answer: (c).** 16 × 10 ns.

**Q19.** A 4-input priority encoder with D₃ highest priority; D₁ and D₂ are both 1. Output?
(a) 01 (b) 10 (c) 11 (d) 00
**Answer: (b).** D₂ wins: code 10.

**Q20.** The 1-bit equality output (A = B) of a comparator is:
(a) XOR (b) XNOR (c) AND (d) NAND
**Answer: (b).**

**Q21.** A parity generator is built mainly from:
(a) AND gates (b) OR gates (c) XOR gates (d) NOR gates
**Answer: (c).**

**Q22.** Combinational circuits are characterised by:
(a) outputs depending only on present inputs (b) memory elements (c) a clock (d) feedback paths
**Answer: (a).**

**Q23.** A BCD-to-7-segment converter is a type of:
(a) encoder (b) decoder (c) multiplexer (d) counter
**Answer: (b).**

**Q24.** Select lines for a 1:32 DEMUX?
(a) 4 (b) 5 (c) 6 (d) 32
**Answer: (b).**

**Q25.** In carry look-ahead logic, Cᵢ₊₁ =
(a) Gᵢ + PᵢCᵢ (b) GᵢPᵢ + Cᵢ (c) Gᵢ ⊕ PᵢCᵢ (d) Pᵢ + GᵢCᵢ
**Answer: (a).** Gᵢ = AᵢBᵢ (generate), Pᵢ = Aᵢ ⊕ Bᵢ (propagate).

**Q26.** A 2ⁿ:1 MUX can implement any function of how many variables if one variable (and its complement) can be fed into the data inputs?
(a) n (b) n + 1 (c) 2n (d) 2ⁿ
**Answer: (b).** n variables go on the select lines; the last is used on the data lines.

**Q27.** Minimum 2-input NAND gates for a full adder?
(a) 7 (b) 8 (c) 9 (d) 10
**Answer: (c).**

**Q28.** A decoder with n inputs has at most:
(a) n outputs (b) 2n outputs (c) 2ⁿ outputs (d) n² outputs
**Answer: (c).**
