# 1.1 Number Systems, Codes and Binary Arithmetic

> 33 questions. Cover the answer, attempt the question, then check. The explanation shows the fastest correct method.

---

**Q1.** Binary 101110 in octal?
(a) 56 (b) 66 (c) 46 (d) 65
**Answer: (a).** Group in threes from the right: 101 | 110 = 5 | 6.

**Q2.** Range of 8-bit 2's complement numbers?
(a) −127 to +127 (b) −128 to +127 (c) −128 to +128 (d) −127 to +128
**Answer: (b).** −2ⁿ⁻¹ to 2ⁿ⁻¹ − 1. One zero, so one extra negative value.

**Q3.** In 1's complement, a number is negated by:
(a) adding 1 (b) flipping all bits (c) flipping all bits and adding 1 (d) reversing the bit order
**Answer: (b).** Flip-then-add-1 is the 2's complement rule.

**Q4.** Overflow in 2's complement addition happens when:
(a) a positive and a negative number are added (b) two same-sign operands give an opposite-sign result (c) the result is zero (d) any carry leaves the MSB
**Answer: (b).** Mixed-sign addition can never overflow. A carry out of the MSB alone is not overflow in 2's complement.

**Q5.** Which code is self-complementing (9's complement = bitwise NOT)?
(a) BCD (b) Gray (c) Excess-3 (d) ASCII
**Answer: (c).**

**Q6.** The defining property of Gray code:
(a) uses fewer bits than binary (b) exactly one bit changes between consecutive values (c) self-complementing (d) represents negatives directly
**Answer: (b).**

**Q7.** 8-bit 2's complement 11110110 in decimal?
(a) −10 (b) −6 (c) 246 (d) −118
**Answer: (a).** Invert → 00001001, add 1 → 00001010 = 10, so the value is −10.

**Q8.** Bits per hexadecimal digit?
(a) 2 (b) 3 (c) 4 (d) 8
**Answer: (c).** 16 = 2⁴.

**Q9.** Sign-magnitude and 1's complement share which weakness that 2's complement avoids?
(a) no fractions (b) two representations of zero (c) no negatives (d) more bits needed
**Answer: (b).** +0 and −0.

**Q10.** Converting Gray to binary, each bit after the MSB equals:
(a) XOR with the previous Gray bit (b) XOR of the Gray bit with the previous **binary** bit (c) XNOR with the next Gray bit (d) the Gray bit unchanged
**Answer: (b).** The conversion is cumulative.

**Q11.** (25)₁₀ in binary?
(a) 11001 (b) 10011 (c) 11010 (d) 10101
**Answer: (a).** 16 + 8 + 1.

**Q12.** (0.625)₁₀ in binary?
(a) 0.101 (b) 0.110 (c) 0.011 (d) 0.111
**Answer: (a).** Multiply by 2 repeatedly: 1.25 → 1, 0.5 → 0, 1.0 → 1.

**Q13.** (3A)₁₆ in decimal?
(a) 48 (b) 58 (c) 310 (d) 42
**Answer: (b).** 3 × 16 + 10.

**Q14.** (237)₈ in decimal?
(a) 159 (b) 237 (c) 167 (d) 149
**Answer: (a).** 2 × 64 + 3 × 8 + 7.

**Q15.** (1101.101)₂ in decimal?
(a) 13.625 (b) 13.5 (c) 11.625 (d) 13.375
**Answer: (a).** 13 + 0.5 + 0.125.

**Q16.** 11010110 in hexadecimal?
(a) D6 (b) 6D (c) C6 (d) D5
**Answer: (a).** 1101 | 0110.

**Q17.** Gray code of binary 1011?
(a) 1110 (b) 1101 (c) 1001 (d) 1111
**Answer: (a).** Keep MSB 1; then 1⊕0 = 1, 0⊕1 = 1, 1⊕1 = 0.

**Q18.** Binary equivalent of Gray code 1101?
(a) 1001 (b) 1011 (c) 1110 (d) 1000
**Answer: (a).** b₃ = 1; b₂ = 1⊕1 = 0; b₁ = 0⊕0 = 0; b₀ = 0⊕1 = 1.

**Q19.** BCD of decimal 59?
(a) 0101 1001 (b) 0011 1011 (c) 0101 1010 (d) 0111 1001
**Answer: (a).** Each decimal digit separately in 4 bits.

**Q20.** Excess-3 code of decimal 4?
(a) 0100 (b) 0111 (c) 0110 (d) 1000
**Answer: (b).** 4 + 3 = 7.

**Q21.** 2's complement of 01011000?
(a) 10100111 (b) 10101000 (c) 10100110 (d) 10101001
**Answer: (b).** Shortcut: copy bits from the right up to and including the first 1, then invert the rest.

**Q22.** −5 in 8-bit 2's complement?
(a) 10000101 (b) 11111010 (c) 11111011 (d) 11111101
**Answer: (c).** (a) is sign-magnitude, (b) is 1's complement.

**Q23.** Range of 8-bit 1's complement?
(a) −128 to 127 (b) −127 to 127 (c) −127 to 128 (d) 0 to 255
**Answer: (b).**

**Q24.** (121)_b = (144)₁₀. Base b?
(a) 9 (b) 11 (c) 12 (d) 13
**Answer: (b).** b² + 2b + 1 = (b + 1)² = 144 → b = 11.

**Q25.** Minimum bits to represent 1000 distinct values?
(a) 9 (b) 10 (c) 11 (d) 12
**Answer: (b).** 2⁹ = 512 < 1000 ≤ 1024 = 2¹⁰.

**Q26.** Largest unsigned value in 12 bits?
(a) 2047 (b) 4095 (c) 4096 (d) 1023
**Answer: (b).** 2¹² − 1.

**Q27.** 8-bit 2's complement: 01111111 + 00000001 = 10000000. This is:
(a) correct, +128 (b) overflow (c) −0 (d) underflow only in unsigned
**Answer: (b).** Two positives gave a negative (−128).

**Q28.** FF₁₆ as an 8-bit 2's complement number?
(a) 255 (b) −1 (c) −127 (d) −255
**Answer: (b).**

**Q29.** (1A)₁₆ + (17)₈ in decimal?
(a) 41 (b) 43 (c) 39 (d) 33
**Answer: (a).** 26 + 15.

**Q30.** IEEE 754 single precision bias?
(a) 128 (b) 127 (c) 1023 (d) 255
**Answer: (b).** 1 sign, 8 exponent, 23 fraction bits. Double precision uses bias 1023.

**Q31.** IEEE 754 single: sign 0, exponent 10000000, fraction all zeros. Value?
(a) 1.0 (b) 2.0 (c) 0.5 (d) 128.0
**Answer: (b).** (1.0) × 2^(128 − 127).

**Q32.** Standard ASCII uses how many bits per character?
(a) 6 (b) 7 (c) 8 (d) 16
**Answer: (b).** 'A' = 65, 'a' = 97, '0' = 48.

**Q33.** In which representation does adding two numbers need an end-around carry?
(a) 2's complement (b) 1's complement (c) unsigned binary (d) BCD
**Answer: (b).** A carry out of the MSB is added back to the LSB.
