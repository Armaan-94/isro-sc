# 1.7 I/O Organization, Interrupts, Bus and DMA

> 26 questions.

---

**Q1.** Main disadvantage of programmed I/O:
(a) needs a DMA controller (b) CPU wastes cycles polling (c) one byte at a time only (d) needs NMIs
**Answer: (b).**

**Q2.** During a DMA bulk transfer the CPU:
(a) moves every word (b) only sets up the transfer and gets one interrupt at the end (c) is never involved at all (d) polls the controller continuously
**Answer: (b).**

**Q3.** A non-maskable interrupt:
(a) can be disabled by software (b) is reserved for critical events and can't be disabled (c) occurs only on system calls (d) has the lowest priority
**Answer: (b).** e.g. power failure.

**Q4.** Vectored interrupts are faster than polled identification because:
(a) bigger data bus (b) the device supplies its ISR address (c) all other interrupts are disabled (d) no ISR is needed
**Answer: (b).**

**Q5.** A hardware interrupt differs from a software trap because it is:
(a) always higher priority (b) asynchronous (c) only for exceptions (d) non-maskable
**Answer: (b).** A trap is a deliberate, synchronous instruction.

**Q6.** Maximum addressable memory is determined by:
(a) data bus width (b) address bus width (c) control bus width (d) clock speed
**Answer: (b).**

**Q7.** Which bus is bidirectional?
(a) address (b) data (c) control (d) none
**Answer: (b).**

**Q8.** An exception is:
(a) a signal from an I/O device (b) a deliberate system call (c) an interrupt caused by an error during execution (d) a DMA completion
**Answer: (c).** Divide by zero, page fault, illegal opcode.

**Q9.** A higher-priority interrupt arrives during a lower-priority ISR. Typically:
(a) it waits (b) it preempts (nests inside) the current ISR (c) the CPU halts (d) it becomes a trap
**Answer: (b).**

**Q10.** 20-bit address bus. Maximum addressable memory (byte-addressable)?
(a) 20 KB (b) 1 MB (c) 1 GB (d) 20 MB
**Answer: (b).** 2²⁰ bytes.

**Q11.** 32-bit address bus, byte-addressable. Maximum memory?
(a) 32 MB (b) 4 GB (c) 2 GB (d) 16 GB
**Answer: (b).**

**Q12.** In cycle-stealing DMA:
(a) DMA takes the bus for one cycle at a time, interleaved with the CPU (b) DMA holds the bus for the whole block (c) the CPU stops permanently (d) no bus is used
**Answer: (a).** Burst mode holds the bus for the whole block.

**Q13.** In daisy-chain priority, the highest priority device is:
(a) farthest from the CPU (b) closest to the CPU (c) the one with the lowest address (d) random
**Answer: (b).** The grant signal reaches it first.

**Q14.** Memory-mapped I/O means:
(a) I/O devices share the memory address space and use normal load/store instructions (b) separate I/O instructions (IN/OUT) (c) DMA only (d) I/O through cache only
**Answer: (a).** Isolated (port-mapped) I/O uses separate instructions.

**Q15.** A device raises 1000 interrupts per second; each takes 100 µs to service. Fraction of CPU time used?
(a) 1% (b) 10% (c) 0.1% (d) 100%
**Answer: (b).** 1000 × 100 µs = 0.1 s per second.

**Q16.** A 1 GHz CPU polls a device 100 times per second, 400 cycles per poll. CPU fraction used?
(a) 0.004% (b) 0.04% (c) 0.4% (d) 4%
**Answer: (a).** 40,000 / 10⁹.

**Q17.** A 16-bit data bus at 10 MHz with one transfer per cycle. Bandwidth?
(a) 10 MB/s (b) 20 MB/s (c) 160 MB/s (d) 1.25 MB/s
**Answer: (b).** 2 bytes × 10⁷.

**Q18.** On an interrupt, the first thing saved is usually:
(a) the cache (b) the program counter (and status) (c) the disk buffer (d) the stack contents
**Answer: (b).**

**Q19.** In asynchronous data transfer, the two-wire control (request and acknowledge) is called:
(a) strobe (b) handshaking (c) polling (d) cycle stealing
**Answer: (b).** A strobe is a single control line.

**Q20.** A synchronous bus:
(a) uses a common clock for all transfers (b) uses handshaking only (c) has no clock (d) is always slower
**Answer: (a).**

**Q21.** An I/O processor (channel):
(a) executes I/O programs independently, offloading the CPU (b) is a cache (c) is a type of interrupt (d) replaces main memory
**Answer: (a).**

**Q22.** A 64K-word memory needs an address bus of:
(a) 8 bits (b) 16 bits (c) 32 bits (d) 64 bits
**Answer: (b).** 2¹⁶ = 64K.

**Q23.** The DMA controller needs which registers at minimum?
(a) address register, word count register, control register (b) only PC (c) IR and MAR (d) accumulator only
**Answer: (a).**

**Q24.** Interrupt latency is:
(a) time to execute the ISR (b) time from the interrupt request to the start of the ISR (c) DMA transfer time (d) bus cycle time
**Answer: (b).**

**Q25.** Best technique for transferring a large block from disk to memory:
(a) programmed I/O (b) interrupt-driven I/O per byte (c) DMA (d) polling
**Answer: (c).**

**Q26.** The control bus carries:
(a) data values (b) addresses (c) signals like read/write, interrupt request, bus grant (d) instructions only
**Answer: (c).**
