# 1.6 Memory Hierarchy and Cache

> 30 questions, with the address-split and AMAT numericals that ISRO loves.

---

**Q1.** Memory hierarchy from fastest to slowest:
(a) cache, registers, RAM, disk (b) registers, cache, RAM, disk (c) RAM, cache, registers, disk (d) registers, RAM, cache, disk
**Answer: (b).**

**Q2.** Spatial locality means:
(a) recently used data is reused soon (b) data near recently used data is used soon (c) cache is faster than RAM (d) random access
**Answer: (b).** (a) is temporal locality.

**Q3.** In a direct-mapped cache a block can go:
(a) anywhere (b) to exactly one line (c) to any line in one set (d) nowhere
**Answer: (b).** Line = block number mod number of lines.

**Q4.** No conflict misses but the costliest lookup:
(a) direct (b) fully associative (c) set-associative (d) all equal
**Answer: (b).**

**Q5.** A dirty bit is needed under:
(a) write-through (b) write-back (c) both (d) neither
**Answer: (b).**

**Q6.** Main drawback of write-through:
(a) data loss on crash (b) more memory traffic (c) can't be multi-level (d) needs a dirty bit
**Answer: (b).**

**Q7.** Belady's optimal replacement is:
(a) used in real caches (b) a theoretical benchmark needing future knowledge (c) the same as LRU (d) write-through only
**Answer: (b).**

**Q8.** Hit ratio 0.9, cache 10 ns, memory 100 ns (simultaneous access). Average access time?
(a) 19 ns (b) 91 ns (c) 55 ns (d) 100 ns
**Answer: (a).** 0.9 × 10 + 0.1 × 100.

**Q9.** In an n-way set-associative cache, a block:
(a) can go anywhere (b) maps to one set, any of its n lines (c) maps to one line (d) always goes to set 0
**Answer: (b).**

**Q10.** LRU evicts:
(a) the most recently used (b) the earliest loaded (c) the one unused for the longest time (d) a random block
**Answer: (c).**

**Q11.** 64 KB byte-addressable memory, 1 KB direct-mapped cache, 16-byte blocks. Tag, index, offset bits?
(a) 6, 6, 4 (b) 8, 4, 4 (c) 4, 6, 6 (d) 6, 4, 6
**Answer: (a).** 16-bit address; 64 lines → 6 index bits; 16 B → 4 offset bits; tag 16 − 10 = 6.

**Q12.** Same memory and cache, but 4-way set-associative. Tag bits?
(a) 6 (b) 8 (c) 10 (d) 4
**Answer: (b).** 64 lines / 4 = 16 sets → 4 index bits → tag = 16 − 4 − 4 = 8.

**Q13.** Same, fully associative. Tag bits?
(a) 6 (b) 10 (c) 12 (d) 16
**Answer: (c).** No index: 16 − 4.

**Q14.** Direct-mapped cache with 64 lines. Main memory block 300 goes to line:
(a) 4 (b) 44 (c) 36 (d) 12
**Answer: (b).** 300 mod 64 = 300 − 256.

**Q15.** 32-bit addresses, 32 KB direct-mapped cache, 64-byte blocks. Tag bits?
(a) 15 (b) 17 (c) 19 (d) 21
**Answer: (b).** 512 lines → 9 index, 6 offset → 32 − 15 = 17.

**Q16.** Hit time 1 ns, miss rate 5%, miss penalty 100 ns. AMAT?
(a) 5 ns (b) 6 ns (c) 6.05 ns (d) 100 ns
**Answer: (b).** 1 + 0.05 × 100.

**Q17.** L1 hit time 1 ns, L1 miss rate 10%; L2 hit time 10 ns, L2 local miss rate 20%; memory 100 ns. AMAT?
(a) 3 ns (b) 4 ns (c) 5 ns (d) 12 ns
**Answer: (b).** 1 + 0.1 × (10 + 0.2 × 100) = 1 + 3.

**Q18.** Hierarchical access (on a miss, memory is accessed after the cache): h = 0.9, Tc = 10 ns, Tm = 100 ns. Average?
(a) 19 ns (b) 20 ns (c) 11 ns (d) 29 ns
**Answer: (b).** 0.9 × 10 + 0.1 × (10 + 100).

**Q19.** Simultaneous access: Tc = 20 ns, Tm = 120 ns. Hit ratio needed for a 30 ns average?
(a) 0.8 (b) 0.85 (c) 0.9 (d) 0.95
**Answer: (c).** 20h + 120(1 − h) = 30.

**Q20.** Increasing associativity mainly reduces:
(a) compulsory misses (b) capacity misses (c) conflict misses (d) hit time
**Answer: (c).** It usually increases hit time slightly.

**Q21.** Larger block size, with cache size fixed, tends to:
(a) exploit spatial locality but raise the miss penalty (b) always lower miss rate (c) reduce compulsory misses to zero (d) reduce hit time
**Answer: (a).** Very large blocks also mean fewer lines, eventually raising misses.

**Q22.** Tag comparators in a 4-way set-associative cache?
(a) 1 (b) 4 (c) number of sets (d) number of lines
**Answer: (b).** All ways of the selected set are compared in parallel.

**Q23.** Direct-mapped cache with 4 lines; block sequence 0, 4, 0, 4. Misses?
(a) 2 (b) 3 (c) 4 (d) 1
**Answer: (c).** 0 and 4 both map to line 0 and keep evicting each other.

**Q24.** Same sequence in a 2-way set-associative cache (2 sets, LRU). Misses?
(a) 2 (b) 3 (c) 4 (d) 1
**Answer: (a).** Both fit in set 0; only the first two accesses miss.

**Q25.** The very first access to a block always causes a:
(a) conflict miss (b) compulsory (cold) miss (c) capacity miss (d) coherence miss
**Answer: (b).**

**Q26.** A 2-way set-associative cache with 128 lines has how many sets?
(a) 32 (b) 64 (c) 128 (d) 256
**Answer: (b).**

**Q27.** The valid bit in a cache line indicates:
(a) the line was modified (b) the line holds real data (c) the line is locked (d) LRU order
**Answer: (b).** Modified is the dirty bit.

**Q28.** Write-allocate means on a write miss:
(a) the block is loaded into the cache, then written (b) memory is written directly, cache untouched (c) the write is ignored (d) the cache is flushed
**Answer: (a).** Usually paired with write-back.

**Q29.** Memory interleaving improves:
(a) bandwidth by letting consecutive words come from different banks in parallel (b) hit ratio (c) capacity (d) latency of a single word
**Answer: (a).**

**Q30.** Temporal locality is best exploited by:
(a) large block size (b) keeping recently used data (e.g., LRU) (c) prefetching the next block (d) random replacement
**Answer: (b).**
